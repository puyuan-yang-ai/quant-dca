## 任务

请读取 `$ARGUMENTS` 指向的剧本推演文件，然后运行项目内的取数脚本获取标普500（SPY 等价于 ESM）最新的真实价格数据，与文件中记录的关键点位和剧本预测进行逐一比对，完成以下任务。

完成校验后，请直接**修改** `$ARGUMENTS` 指向的文件，严格遵循以下文档维护规则：

### 文档维护规则（重要 — 决定改哪些节、怎么改）

scenario_evolution.md 是"**当前最新的决策卡片**"，不是"判断演化的博物馆"。打开它的目的是盘前 30 秒内立刻知道当前怎么办，旧版本归档由 git 负责。

**§5（剧本）/ §6（概率表）/ §7（决策卡片）必须直接覆盖更新为最新结论**：

- 每个剧本前的状态标注（✅ / ⚠️ / ❌）直接改，不要并列保留旧状态。
- 主剧本切换时，§5 各剧本的核心定位、§6 概率表、§7 决策卡片**直接重写为最新版本**。
- **禁止**新增"v3/v4 版本对照表"、"历史概率表"、"版本演化历史"等并列归档结构。
- **禁止**在剧本下堆叠多版"状态说明"段落。
- 旧判断如果有反思价值，**写到当日 §8 日志的一条 bullet 里**就够了，不要在 §5-7 留存。

**§8（每日校验日志）只追加不覆盖**。每天追加一条 `### YYYYMMDD` 记录，包含：

- 当日真实数据（ES OHLC + VIX）
- 各剧本状态判定（✅ / ⚠️ / ❌）+ 一句话依据
- 与上一轮判断的**关键差异**（一两句话，不复制旧表格）
- 今日/明日行动建议

**单条日志控制在约 25 行以内**。避免在日志里再嵌入"对照表 + 反思段 + 决策树"等冗余结构——这些信息要么进 §5-7（最新结论），要么不要进文档（git 负责归档）。

### 1. 拉取最新市场数据

在项目根目录运行：

```bash
python scripts/fetch_es_for_mma.py --days 7
```

脚本输出：

- 最近 7 个交易日的 ES 期货真实 OHLC（ES=F，已验证与 ESM26 一致）
- 最新交易日摘要（收盘、日变化、日内振幅）
- 数据同步追加至 `data/es_daily.csv`

将脚本输出的 ES 点位直接与剧本中的 ESM 关键点位逐一对照，无需系数换算。

### 2. 剧本状态核查

将真实走势与文件中的主剧本、备选剧本逐一对照，明确给出每个剧本的当前状态：

- ✅ 仍然成立——价格走势与预测吻合，关键点位未被突破
- ⚠️ 需要修正——整体方向未变，但时间或点位出现偏差，说明具体偏差在哪里
- ❌ 已经失效——关键点位被突破或走势明显背离，说明失效的判断依据

### 3. 修正与更新

如果主剧本或关键观点需要修正，明确指出：

- 哪个判断需要修正
- 修正后的新判断是什么
- 当前最可能走的是哪个剧本，以及触发条件是什么

### 4. 今日行动建议

基于最新的剧本状态，给出今日盘前/盘中的关注重点：

- 今日需要重点盯盘的价格区间或时间窗口
- 是否需要调整已有仓位（持有、减仓、加仓、止损）
- 今日最值得关注的交易机会或风险点

### 输出要求

- 先在对话中输出"剧本状态报告"，再输出"今日行动建议"，结构清晰。
- 所有结论必须包含具体的"时间 + 点位"。
- 对主剧本是否仍然成立，必须给出明确的"✅ / ⚠️ / ❌"判断，不能模糊带过。
- 同步按上文【文档维护规则】更新 `$ARGUMENTS` 文件：§5-7 覆盖更新为最新结论，§8 追加当日日志（≤25 行）。
