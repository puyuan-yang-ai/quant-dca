## 任务

请读取 `$ARGUMENTS` 指向的剧本推演文件，然后运行项目内的取数脚本获取标普500（SPY 等价于 ESM）最新的真实价格数据，与文件中记录的关键点位和剧本预测进行逐一比对，完成以下任务。

**数据口径说明**：由于免费数据源不直接提供 ES=F 期货行情，本流程改用 Tiingo 的 SPY ETF + ratio 换算（当前 ratio = 10.06）推算 ESM 等价位。脚本输出的"ESM 等价位"可直接与 MMA 周报里的 ESM 点位对照，偏差通常 < 1 点。

完成校验后，请直接**修改** `$ARGUMENTS` 指向的文件：在每个剧本前标注最新状态（✅ / ⚠️ / ❌），追加当日校验记录（使用系统当前日期，格式 YYYYMMDD），保留全部历史记录，不覆盖原有内容。

### 1. 拉取最新市场数据

在项目根目录运行：

```bash
python scripts/fetch_spy_for_mma.py --days 7
```

脚本会输出：

- 最近 7 个交易日的 SPY 真实 OHLC
- 自动换算的 ESM 等价位（含当前 ratio 及最后校准日期）
- 最新交易日摘要（收盘、日变化、振幅）

将脚本输出的 **ESM 等价位** 直接与剧本中的 ESM 关键点位逐一对照。如果发现 ratio 偏差异常（同日 MMA 周报 ESM 高点 vs 脚本 ESM 等价高点偏差 > 30 点），请在校验记录中标注，并提醒用户运行月度校准（修改 `scripts/fetch_spy_for_mma.py` 顶部的 `ESM_SPY_RATIO`）。

### 2. 剧本状态核查

将真实走势与文件中的主剧本、备选剧本逐一对照，明确给出每个剧本的当前状态：

- ✅ 仍然成立——价格走势与预测吻合，关键点位未被突破
- ⚠️ 需要修正——整体方向未变，但时间或点位出现偏差，说明具体偏差在哪里
- ❌ 已经失效——关键点位被突破或走势明显背离，说明失效的判断依据

### 3. 修正与更新

如果主剧本或关键观点需要修正，明确指出：

- 哪个判断需要修正
- 修正后的新判断是什么
- 当前最可能走的是哪个剧本，以及触发条件是什么

### 4. 今日行动建议

基于最新的剧本状态，给出今日盘前/盘中的关注重点：

- 今日需要重点盯盘的价格区间或时间窗口
- 是否需要调整已有仓位（持有、减仓、加仓、止损）
- 今日最值得关注的交易机会或风险点

### 输出要求

- 先在对话中输出"剧本状态报告"，再输出"今日行动建议"，结构清晰。
- 所有结论必须包含具体的"时间 + 点位"。
- 对主剧本是否仍然成立，必须给出明确的"✅ / ⚠️ / ❌"判断，不能模糊带过。
- 同步将本次校验记录追加写入 `$ARGUMENTS` 文件，标明日期，保留历史。
