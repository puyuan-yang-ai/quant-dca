# 实验 1-A：Baseline 策略汇总

## 策略配置

| 模块 | 配置 |
|------|------|
| 档口设置 | 固定比例（2%/5%/10%） |
| 买入触发条件 | 每日无条件市价买入 + 挂单 |
| 仓位分布 | 固定金字塔（0.7/0.4/0.25/0.15） |
| 止盈策略 | 无 |

---

## 四种市场周期对比

| 指标 | bull | bear-bull | bear | bull-bear |
|------|------|-----------|------|-----------|
| **总收益率** | +157.32% | +150.34% | -58.93% | -69.57% |
| **年化收益率** | +71.73% | +44.03% | -59.23% | -38.01% |
| **最大回撤** | 39.17% | 59.09% | 59.09% | 82.38% |
| **夏普比率** | 0.61 | 0.27 | -0.25 | -0.31 |
| **收益回撤比** | 1.83 | 0.75 | -1.00 | -0.46 |
| **平均持仓成本** | $24.72 | $25.40 | $23.04 | $27.02 |
| **限价单触发率(跌2%)** | 63.4% | 66.8% | 75.3% | 64.2% |

---

## 关键发现

1. **最佳表现**：纯牛市（bull），夏普比率 0.61，收益回撤比 1.83
2. **最差表现**：牛市→熊市（bull-bear），最大回撤 82%，夏普比率 -0.31
3. **入场时机至关重要**：熊市开始定投（bear-bull）vs 牛市顶部开始（bull-bear），收益差 220%
4. **熊市限价单更活跃**：熊市跌2%触发率 75.3%，高于牛市 63.4%

---

## 策略弱点

- 无止盈机制，牛市利润全部暴露
- 无趋势过滤，牛市顶部继续高位加仓
- 最大回撤过大（最差 82%）
