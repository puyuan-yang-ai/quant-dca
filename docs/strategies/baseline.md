# Baseline 策略说明（多层次 DCA）

## 策略概述

本策略是一种**越跌越买**的金字塔加仓定投策略，每个交易日执行以下操作：

1. **市价单**：开盘后立即以开盘价买入固定股数
2. **限价挂单**：在开盘价下方设置多个限价买入单，价格越低买入越多

## 每日交易逻辑

```
开盘价 $50.00  ─────────────────────────  市价单成交：买入 0.7 股
              │
              │ -2%
$49.00 ───────┼─────────────────────────  限价单 A：买入 0.4 股
              │
              │ -5%
$47.50 ───────┼─────────────────────────  限价单 B：买入 0.25 股
              │
              │ -10%
$45.00 ───────┼─────────────────────────  限价单 C：买入 0.15 股
              │
              ▼
```

## 订单配置

| 订单类型 | 价格系数 | 买入股数 | 触发条件 |
|---------|---------|---------|---------|
| 市价单 | 1.00 | 0.70 | 每日必定成交 |
| 限价单 A | 0.98 | 0.40 | 当日最低价 ≤ 开盘价 × 0.98 |
| 限价单 B | 0.95 | 0.25 | 当日最低价 ≤ 开盘价 × 0.95 |
| 限价单 C | 0.90 | 0.15 | 当日最低价 ≤ 开盘价 × 0.90 |

## 挂单规则

- **基准价格**：所有限价挂单基于当日**开盘价**计算
- **有效期**：当日有效（Day Order），收盘后自动取消
- **成交判定**：若 `当日最低价 ≤ 挂单价`，则视为成交

## 手续费

- 费率：**1%**（碎股交易手续费）
- 计算方式：`实际支出 = 成交金额 × (1 + 0.01)`

## 策略优势

1. **降低择时风险**：无需判断市场顶底，坚持定投
2. **摊低成本**：下跌时自动加仓，降低平均持仓成本
3. **纪律性强**：规则明确，避免情绪化交易

## 适用场景

- ✅ 长期看涨但短期波动大的标的（如 SOXL）
- ✅ 牛熊周期交替的市场
- ❌ 长期下跌趋势（会持续加仓亏损）

## 代码实现

核心逻辑在 `baseline.py` 的 `execute_day()` 函数：

```python
def execute_day(open_price, low_price, fee_rate=0.01, orders=None):
    """
    执行单日交易逻辑
    
    Args:
        open_price: 当日开盘价（挂单基准价格）
        low_price: 当日最低价（判断限价单是否成交）
        fee_rate: 手续费率
        orders: 订单配置 [(价格系数, 股数), ...]
    
    Returns:
        成交订单列表
    """
```

## 配置方式

在 `config/*.yaml` 场景配置文件中修改：

```yaml
orders:
  - [1.00, 0.70]   # 市价单
  - [0.98, 0.40]   # 限价单 A（设为 0 可禁用）
  - [0.95, 0.25]   # 限价单 B
  - [0.90, 0.15]   # 限价单 C
```
