## 深度分析：在买点区间内进一步过滤

### 你的观察是对的

当前策略一旦满足"连续 N 天低于 EMA"的条件，就**每天都买**，直到回到 EMA 上方。这意味着一个买入窗口里可能连续买 20-30 天。在这些天里：

- **窗口前段**：刚跌破确认，可能还没跌到底
- **窗口中段**：通常是真正的低点区域（你在图上看到的）
- **窗口末段**：价格已经开始反弹回升，但还没回到 EMA → 还在买，但买在了相对高位

所以确实存在优化空间——**不是所有的买入日都是好的买入日**。

### 三种过滤思路（从安全到激进）

**思路 A：机械间隔（最安全，不加任何新指标）**

```
不是每天买，而是每 K 天买一次
例如 K=3：买一天，跳两天，买一天，跳两天...
```

| 优点 | 缺点 |
|------|------|
| 零过拟合风险，不依赖任何指标 | 不聪明——随机跳过，可能跳过好的也可能跳过坏的 |
| 减少交易次数 → 节省 1% 手续费 | 不能集中在低点附近 |
| 极其简单，手动执行无难度 | |

**思路 B：偏离度阈值（推荐，只加 1 个参数）**

```
只在 价格偏离 EMA 超过 X% 时才买
即：(EMA - Close) / EMA > X%
```

比如设 X=5%：价格必须低于 EMA 至少 5% 才触发买入。这自然地把买入集中在窗口的"深坑"部分。

| 优点 | 缺点 |
|------|------|
| 用现有指标，不引入新指标 | 新增 1 个参数（阈值 X），需要扫描 |
| 天然集中在低价区域 | X 选大了会错过太多机会 |
| 直觉清晰：跌得不够深就不买 | |

**思路 C：叠加 RSI / MACD / 布林带等（不推荐）**

| 优点 | 缺点 |
|------|------|
| 理论上可以更精确识别超卖 | 每个指标引入 1-2 个新参数 |
| | 3 年数据 + 多参数 = 严重过拟合风险 |
| | 策略变复杂，手动执行困难 |
| | 违背"简单有效"的核心原则 |

### 我的判断

**思路 B（偏离度阈值）是唯一值得尝试的方向。** 理由：

1. **不引入新指标**——偏离度 = (EMA - Close) / EMA，用的还是 EMA，不新增概念
2. **只加 1 个参数**——阈值 X，可以粗扫 3-5 个值（2%, 5%, 8%, 10%, 15%）
3. **逻辑自洽**——当前策略已经是"确认下跌才买"，偏离度阈值是"确认跌够深才买"，是同一思路的延伸
4. **有实操价值**——减少出手频率对手动执行者来说是大优势
5. **手续费节省**——当前每笔买入有 1% 手续费，少买一半就少交一半手续费

但也有明确的风险边界：
- **只做粗扫**（5 个阈值），不做精细搜索
- **必须样本外验证**
- 如果样本外不显著优于当前 SOTA，就放弃，保持现有策略

**思路 A 可以作为备选**——如果思路 B 没有带来改善，那就用机械间隔作为一个更简单的替代。

**思路 C 坚决不做**——我们已经在 3 个参数上花了大量搜索，再加复杂指标就是在过拟合的边缘试探。

### 总结

| 方向 | 推荐度 | 原因 |
|------|--------|------|
| 偏离度阈值 | 推荐尝试 | 1 个参数、用现有指标、逻辑自洽 |
| 机械间隔 | 备选 | 零风险但不聪明 |
| RSI/MACD/布林带 | 不推荐 | 参数爆炸、过拟合 |
