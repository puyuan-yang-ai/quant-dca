# 两套 SOTA 策略

## 策略参数对比

| 参数 | 旧 SOTA | 新 SOTA |
|------|---------|---------|
| EMA 周期 | 20 | 30 |
| 确认天数 N | 5 | 7 |
| 一档（限价单 A） | 跌 2% → 买 0.25 股 | 跌 1% → 买 0.25 股 |
| 二档（限价单 B） | 跌 5% → 买 0.40 股 | 跌 3% → 买 0.40 股 |
| 三档（限价单 C） | 跌 10% → 买 0.70 股 | 跌 7% → 买 0.70 股 |
| 市价单 | 开盘价 → 买 0.15 股 | 同左 |
| 止盈 | 不止盈 | 同左 |

---

## 旧 SOTA 伪代码（EMA20 + N=5 + 2%/5%/10%）

```
初始化:
    consecutive_below = 0
    EMA_PERIOD = 20
    N = 5
    TIERS = [2%, 5%, 10%]
    SHARES = [0.25, 0.40, 0.70]
    MARKET_SHARES = 0.15

每个交易日（收盘后）:
    计算 EMA20 = EMA(收盘价序列, 20)

    IF 今日收盘价 < EMA20:
        consecutive_below += 1
    ELSE:
        consecutive_below = 0    ← 归零

    IF consecutive_below >= N:   ← 连续 5 天低于 EMA20
        # 第二天开盘执行买入
        明日操作:
            1. 市价买入 0.15 股（开盘价成交）

            2. 挂限价单 A: 开盘价 × 0.98（跌2%）→ 买 0.25 股
            3. 挂限价单 B: 开盘价 × 0.95（跌5%）→ 买 0.40 股
            4. 挂限价单 C: 开盘价 × 0.90（跌10%）→ 买 0.70 股

            成交判定（当日收盘后）:
                市价单: 必定成交
                限价单 A: IF 当日最低价 <= 开盘价 × 0.98 → 成交
                限价单 B: IF 当日最低价 <= 开盘价 × 0.95 → 成交
                限价单 C: IF 当日最低价 <= 开盘价 × 0.90 → 成交

            未成交的限价单收盘后取消

    ELSE:
        不操作

    永远不卖出
```

## 新 SOTA 伪代码（EMA30 + N=7 + 1%/3%/7%）

```
初始化:
    consecutive_below = 0
    EMA_PERIOD = 30
    N = 7
    TIERS = [1%, 3%, 7%]
    SHARES = [0.25, 0.40, 0.70]
    MARKET_SHARES = 0.15

每个交易日（收盘后）:
    计算 EMA30 = EMA(收盘价序列, 30)

    IF 今日收盘价 < EMA30:
        consecutive_below += 1
    ELSE:
        consecutive_below = 0    ← 归零

    IF consecutive_below >= N:   ← 连续 7 天低于 EMA30
        # 第二天开盘执行买入
        明日操作:
            1. 市价买入 0.15 股（开盘价成交）

            2. 挂限价单 A: 开盘价 × 0.99（跌1%）→ 买 0.25 股
            3. 挂限价单 B: 开盘价 × 0.97（跌3%）→ 买 0.40 股
            4. 挂限价单 C: 开盘价 × 0.93（跌7%）→ 买 0.70 股

            成交判定（当日收盘后）:
                市价单: 必定成交
                限价单 A: IF 当日最低价 <= 开盘价 × 0.99 → 成交
                限价单 B: IF 当日最低价 <= 开盘价 × 0.97 → 成交
                限价单 C: IF 当日最低价 <= 开盘价 × 0.93 → 成交

            未成交的限价单收盘后取消

    ELSE:
        不操作

    永远不卖出
```

## 核心差异

| 维度 | 旧 SOTA | 新 SOTA | 影响 |
|------|---------|---------|------|
| 入场门槛 | EMA20 + 5天 | EMA30 + 7天 | 新策略更严格，空仓等待时间更长 |
| 档口间距 | 2%/5%/10%（宽） | 1%/3%/7%（窄） | 新策略限价单更容易成交，但抄底深度不如旧策略 |
| 信号频率 | 较高 | 较低 | 新策略买入天数更少，但每次入场的确定性更高 |
| 样本外 Sharpe | 略高 | 略低 | 旧策略空仓少，波动率分母更稳定 |
| 样本外收益 | 较低 | 较高 | 新策略因更精准的入场时机获得更高收益 |
| 样本外 Calmar | 较低 | 较高 | 新策略回撤控制更好 |
