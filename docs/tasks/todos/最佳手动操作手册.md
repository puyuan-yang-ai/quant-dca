# SOXL 最佳定投操作手册

## 策略配置

| 模块 | 配置 | 说明 |
|------|------|------|
| 档口 | 固定 2%/5%/10% | 波动率动态档口经交叉验证确认不优于固定 |
| 入场 | 连续 5 天确认 | N=1~10 参数扫描后 Sharpe 最优（N=5） |
| 仓位 | 正金字塔 | 跌越深买越多 |
| 止盈 | 不止盈 | 实验证明自动止盈反而有害 |

## 每日操作流程

### 你需要的工具

- 一个能看 SOXL 日 K 线的软件（看收盘价）
- 一条 **EMA 20 均线**（20 日指数移动平均）

### 每天收盘后做一件事：数天数

> **问自己：SOXL 收盘价已经连续几天低于 EMA20 了？**

---

### 情况一：还没连续 5 天低于 EMA20

**什么都不做。不买。**

- 今天收盘价在 EMA20 上方 → 不买
- 已经连续 2 天在下方 → 不买
- 连续 4 天在下方 → 还是不买
- 中途有 1 天收回 EMA20 上方 → 计数清零，重新开始数

---

### 情况二：已经连续 5 天（或以上）低于 EMA20 → 开仓

**第二天开盘时执行以下操作：**

```
1. 市价买入 0.15 股 SOXL（开盘价成交）

2. 同时挂三档限价单（基于当天开盘价）：
   - 限价单 A：开盘价 × 0.98（跌 2%）→ 买 0.25 股
   - 限价单 B：开盘价 × 0.95（跌 5%）→ 买 0.40 股
   - 限价单 C：开盘价 × 0.90（跌 10%）→ 买 0.70 股

3. 所有限价单当日有效，收盘后未成交的自动取消
```

**之后每天收盘继续检查：只要收盘价仍然低于 EMA20，第二天继续执行同样的买入操作。** 不需要重新数 5 天——首次满足 5 天条件后就进入持续买入状态，一直买到收盘价回到 EMA20 上方为止。

**仓位分布（正金字塔）**：市价单只买 0.15 股（少量试探），跌 2% 买 0.25 股，跌 5% 买 0.40 股，跌 10% 买 0.70 股（重仓抄底）。跌得越深买得越多。

---

### 情况三：收盘价回到 EMA20 上方 → 停止买入

连续低于天数归零 → **立刻停止买入**，等下一次连续 5 天信号再重新开仓。

---

### 不卖出

**永远不卖。** 持有到你自己决定退出为止。

实验证明：在 DCA 策略中，按规则自动止盈反而会大幅降低总收益（牛市收益从 252% 降到 64%），因为卖出后很难在更好的价位买回来。

---

## 一句话总结

> **等 SOXL 连续 5 天收在 EMA20 下方 → 开始每天买入（跌越深买越多）→ 只要还在 EMA20 下方就每天继续买 → 一旦收回 EMA20 上方就停手 → 等下次连续 5 天再开仓。只买不卖。**

---

## N 值选择说明

通过 N=1~10 的完整参数扫描：

| N | Composite Sharpe | Composite Calmar | 特点 |
|---|-----------------|-----------------|------|
| 1 | +0.088 | +0.399 | 信号太多，接近无条件买入 |
| 2 | +0.123 | +0.429 | |
| 3 | +0.099 | +0.442 | |
| 4 | +0.131 | +0.456 | |
| **5** | **+0.182** | +0.468 | **Sharpe 峰值** |
| 6 | +0.132 | +0.471 | |
| 7 | +0.111 | +0.485 | |
| 8 | +0.110 | +0.492 | |
| 9 | +0.095 | +0.529 | |
| 10 | +0.143 | +0.534 | Calmar 最高但信号极少 |

选择 N=5 的理由：Sharpe Ratio 在 N=5 处达到明确峰值（+0.1815），之后下降。虽然 Calmar 随 N 单调递增，但 N 过大会导致入场机会极少，在实际操作中长期空仓等待的心理压力较大。N=5 是风险调整收益和实操可行性的最佳平衡点。
