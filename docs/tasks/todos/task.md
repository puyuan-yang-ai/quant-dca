# 定投交易系统优化实验计划

## 实验总览

基于 baseline（每日定投 + 固定比例挂单）逐步优化，采用**逐层消融实验**策略，找到各模块最优配置。

### 模块拆解

| 模块 | 实验数量 | 方案 |
|------|----------|------|
| **档口设置** | 2个 | ① 固定比例（2%/5%/10%）<br>② 波动率动态（分位数+最大跌幅） |
| **买入触发条件** | 3个 | ① Baseline（每日市价买入+挂单）<br>② 均线过滤（下方→市价+挂单；上方→仅挂单）<br>③ 连续N天确认（N=2,3,4 参数扫描） |
| **仓位分布** | 2个 | ① 自适应（上涨倒金字塔 / 下跌正金字塔）<br>② 上涨不买，仅下跌正金字塔 |
| **止盈策略** | 2个 | ① 偏离度峰值止盈（动量衰竭信号，平50%）<br>② 趋势确认止盈（连续3天在均线上方，平25%） |

### 固定规则

- **利润分流**：止盈利润的 50% 分流到 SMH（不作为实验变量）
- **均线指标**：20日均线（TEMA待定）
- **趋势判断**：股价 < 20日均线 → 下跌趋势；股价 ≥ 20日均线 → 上涨趋势

## 第一阶段：档口设置实验

**目标**：验证波动率动态档口是否优于固定比例

| 编号 | 定投 | 档口设置 | 说明 |
|------|------|----------|------|
| 1-A | ✅ 每日定投 | 固定比例（2%/5%/10%） | Baseline |
| 1-B | ✅ 每日定投 | 波动率动态 | 波动率档口是否优于固定比例？ |
| 1-C | ❌ 无定投 | 波动率动态 | 取消定投后收益/回撤如何变化？ |

### Baseline 仓位配置（1-A）

| 档口 | 价格系数 | 股数 | 占比（若全成交） |
|------|----------|------|------------------|
| 市价单 | 1.00 | 0.70 | 46.7% |
| 一档 | 0.98（跌2%） | 0.40 | 26.7% |
| 二档 | 0.95（跌5%） | 0.25 | 16.7% |
| 三档 | 0.90（跌10%） | 0.15 | 10.0% |
| **合计** | - | 1.50 | 100% |

**结构特点**：倒金字塔（市价单占比最大，越远的档位股数越少）

### 波动率档口计算方法

**数据来源**：最近 14 个交易日

**步骤1：计算每日跌幅（基于昨日收盘价）**
```
每日跌幅 = max(0, (昨日收盘价 - 今日最低价) / 昨日收盘价) × 100%

说明：
- 基准使用"昨日收盘价"而非"今日开盘价"
- 原因1：挂单决策在昨日收盘后做，此时只有昨日收盘价
- 原因2：这样可以把跳空缺口的影响纳入计算
- 如果今日最低价 ≥ 昨日收盘价，则跌幅 = 0（没跌破昨收）
```

**步骤2：确定三档位置（分位数方法）**

| 档位 | 计算方法 | 预期成交率 | 说明 |
|------|----------|------------|------|
| **第一档** | 30%分位数 | 约70% | 常规波动，高频成交 |
| **第二档** | 60%分位数 | 约40% | 中等波动，中频成交 |
| **第三档** | 最大跌幅 × 90% | 约10% | 极端波动，低频成交，留10%余量 |

**举例**
```
假设14天跌幅数据（基于昨日收盘价，从小到大排序）：
[1.2%, 1.5%, 1.8%, 1.9%, 2.0%, 2.1%, 2.2%, 2.3%, 2.5%, 2.8%, 3.1%, 3.5%, 4.5%, 6.2%]
 ↑                   ↑                        ↑                              ↑
索引0               索引4                    索引8                          索引13

计算档位：
- 第一档 = 30%分位数 ≈ 索引4 = 2.0%
- 第二档 = 60%分位数 ≈ 索引8 = 2.5%
- 第三档 = 最大跌幅 × 90% = 6.2% × 90% = 5.6%

最终挂单位置（基于昨日收盘价）：
- 限价单A：昨日收盘价 × 0.980（跌2.0%）
- 限价单B：昨日收盘价 × 0.975（跌2.5%）
- 限价单C：昨日收盘价 × 0.944（跌5.6%）
```

### 对比：固定比例 vs 波动率动态

| 档位 | 固定比例 | 波动率动态（示例） | 预期成交率 |
|------|----------|-------------------|------------|
| 第一档 | 2% | 2.0%（30%分位数） | 约70% |
| 第二档 | 5% | 2.5%（60%分位数） | 约40% |
| 第三档 | 10% | 5.6%（最大跌幅×90%） | 约10% |

**波动率动态的优势**：
- 档位贴合当前市场波动特性
- 高波动期自动拉宽，低波动期自动收窄
- 分位数方法比分箱更简单直接，无需人为设定区间

## 第二阶段：入场条件实验

**前置条件**：基于第一阶段最优结果

| 编号 | 触发条件 | 说明 |
|------|----------|------|
| 2-A | 无条件每日买入 | 沿用第一阶段最优（市价+挂单） |
| 2-B | 均线过滤 | 股价 < 均线 → 市价买入+挂单<br>股价 ≥ 均线 → 仅挂限价单（不市价买入） |
| 2-C | 连续N天确认 | 连续N天收盘价 < 均线才开始买入<br>**参数扫描：N = 2, 3, 4** |

### 均线过滤逻辑说明（2-B）

```
每日判断：收盘价 vs 20日均线

如果 收盘价 < 均线：
    → 第二天：市价买入 + 三档限价挂单（正常定投）
    
如果 收盘价 ≥ 均线：
    → 第二天：仅挂三档限价单（不市价买入）
    → 好处：高位不追涨，但如果回调仍可通过限价单接住
```

### 连续N天确认逻辑说明（2-C）

```
参数扫描：N = 2, 3, 4

如果 连续N天收盘价 < 20日均线：
    → 第N+1天：开始买入（市价 + 三档限价挂单）
    
否则：
    → 不买入

对比维度：
- N=2：信号较多，反应快，可能有假突破
- N=3：平衡点，信号相对可靠
- N=4：信号最少，确认度高，可能错过机会
```

## 第三阶段：仓位分布实验

**前置条件**：基于第二阶段最优结果

| 编号 | 分布策略 | 说明 |
|------|----------|------|
| 3-A | 固定金字塔 | 沿用 baseline 分布 |
| 3-B | 自适应分布 | 上涨趋势 → 倒金字塔<br>下跌趋势 → 正金字塔 |
| 3-C | 仅下跌买入 | 上涨趋势 → 不买入<br>下跌趋势 → 正金字塔 |

### 仓位分布定义

| 分布类型 | 市价单 | 一档 | 二档 | 三档 | 逻辑 |
|----------|--------|------|------|------|------|
| **倒金字塔** | 0.70 | 0.40 | 0.25 | 0.15 | 近处多、远处少（baseline） |
| **正金字塔** | 0.15 | 0.25 | 0.40 | 0.70 | 近处少、远处多 |

**说明**：
- 倒金字塔：适合上涨趋势，尽早买入
- 正金字塔：适合下跌趋势，等更低价格再重仓

## 第四阶段：止盈策略实验

**前置条件**：基于第三阶段最优结果

### 止盈策略总览（2组）

| 编号 | 止盈策略 | 触发条件 | 止盈仓位 |
|------|----------|----------|----------|
| 4-A | 偏离度峰值止盈 | 偏离度连续下降2天（峰值确认） | 50% |
| 4-B | 趋势确认止盈 | 连续3天收盘价 > 均线 | 25% |

### 统一的止盈尺子

```
7日最大涨跌幅绝对值 = max(近7日每日|涨跌幅|)

止盈位 = 触发K线收盘价 × (1 + 7日最大涨跌幅绝对值)
```

### 4-A 偏离度峰值止盈逻辑

```
每日计算：偏离度 = (收盘价 - 20日均线) / 20日均线 × 100%

峰值确认条件：
- 偏离度连续下降2天
- 即：今日偏离度 < 昨日偏离度 < 前日偏离度
→ 前日为偏离度峰值

触发后：
- 止盈位 = 峰值K线收盘价 × (1 + 7日最大涨跌幅绝对值)
- 挂限价止盈单，平仓 50%

逻辑说明：
- 偏离度达到峰值 = 动量/动能最大
- 偏离度开始下降 = 动量衰竭信号
- 此时规划止盈位，抓住趋势衰竭前的高点
```

### 4-B 趋势确认止盈逻辑

```
触发条件：连续3天收盘价 > 20日均线

触发后：
- 止盈位 = 第3天收盘价 × (1 + 7日最大涨跌幅绝对值)
- 挂限价止盈单，平仓 25%

逻辑说明：
- 连续3天在均线上方 = 上涨趋势确认
- 用7日最大涨跌幅作为尺子，预估未来涨幅空间
- 前置限价单，实现真正的"高卖"
```

### 设计说明

| 策略 | 触发频率 | 信号可靠性 | 止盈仓位 |
|------|----------|------------|----------|
| 4-A（偏离度峰值） | 低 | 高（动量衰竭） | 大（50%） |
| 4-B（趋势确认） | 高 | 中等 | 小（25%） |

**分层止盈逻辑**：
- 4-A 很难触发，但一旦触发说明趋势真的要转弱 → 平大仓位
- 4-B 容易触发，是日常的止盈机会 → 平小仓位

**止盈利润处理**：50% 分流到 SMH

## 回归验证

完成所有阶段后，用最终最优组合 vs baseline 做整体对比，确认收益是叠加而非抵消。

## 评估指标

### 收益与风险指标

| 指标 | 说明 |
|------|------|
| 总收益率 | 最终收益 / 总投入 |
| 年化收益率 | 折算为年化的收益率 |
| 最大回撤 | 期间最大跌幅 |
| 夏普比率 | 风险调整后收益 |
| Calmar比率 | 年化收益率 / 最大回撤 |

### 交易效率指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 平均买入成本 | 总投入金额 / 总持仓股数 | 核心效率指标，越低越好 |
| 成本优势比 | (期间均价 - 平均成本) / 期间均价 | 相对市场的买入优势，越高越好 |
| 总交易次数 | 所有买入次数 | 交易频率参考 |
| 限价单成交率 | 成交的限价单 / 挂出的限价单 | 挂单策略有效性 |
| 限价单节省成本 | Σ(挂单时市价 - 实际成交价) × 股数 | 限价单带来的实际收益 |
| 各档成交分布 | 一档/二档/三档各自成交占比 | 分析哪档最有效 |

**说明**：
- 期间均价 = 回测期间所有交易日收盘价的简单平均
- 成本优势比为正，说明你的平均成本低于市场均价（买得好）
