# SOXL 多层次 DCA 策略回测脚本

## 1. 项目概述

开发一个 Python 回测脚本，用于测试 SOXL（3倍做多半导体ETF）的多层次定投策略。该策略结合了固定定投和下跌加仓的思路。

## 2. 策略规则

### 2.1 每日交易逻辑

每个交易日执行以下操作：

| 订单类型 | 触发条件 | 买入股数 | 成交价格 |
|---------|---------|---------|---------|
| 市价单 | 每日开盘后立即执行 | 0.7 股 | 开盘价 |
| 限价单 A | 开盘价 × 0.98（跌 2%） | 0.4 股 | 开盘价 × 0.98 |
| 限价单 B | 开盘价 × 0.95（跌 5%） | 0.25 股 | 开盘价 × 0.95 |
| 限价单 C | 开盘价 × 0.90（跌 10%） | 0.15 股 | 开盘价 × 0.90 |

### 2.2 挂单规则

- **基准价格**：所有限价挂单基于当日**开盘价**计算
- **有效期**：当日有效（Day Order），收盘前未成交则自动取消
- **成交判定**：由于使用日线数据，若挂单价格 P 满足 `当日最低价 ≤ P`，则视为成交

### 2.3 手续费规则

- **费率**：所有交易收取 **1%** 手续费（因碎股交易）
- **计算方式**：手续费在成交金额基础上额外收取
  - 示例：成交金额 $100 → 手续费 $1 → 实际支出 $101

## 3. 数据源

- **文件路径**：`data/SOXL.csv`
- **数据格式**：CSV，包含字段：`时间, 开盘价, 最高价, 最低价, 收盘价, 成交量`
- **时间范围**：支持指定起止日期，若不指定则使用全部历史数据

## 4. 输出指标

回测完成后需计算并输出以下指标：

| 指标 | 说明 |
|-----|------|
| 总投入成本 | 累计实际支出金额（含手续费） |
| 总持股数量 | 累计买入的股数 |
| 期末市值 | 总持股数量 × 最后一天收盘价 |
| 总收益 | 期末市值 - 总投入成本 |
| 总收益率 | (期末市值 - 总投入成本) / 总投入成本 × 100% |
| 年化收益率 | 根据实际投资天数折算的年化收益 |
| 最大回撤 | 期间内从峰值到谷值的最大跌幅 |
| 平均持仓成本 | 总投入成本 / 总持股数量 |

## 5. 功能需求

### 5.1 核心功能

1. **数据加载**：读取 CSV 文件并解析为可处理的数据结构
2. **策略模拟**：按日期遍历，模拟每日的市价单和限价单成交
3. **收益计算**：跟踪持仓、成本，计算各项评估指标
4. **结果输出**：将回测结果以清晰格式输出到控制台

### 5.2 可选参数

- `--start-date`：回测起始日期（格式：YYYY-MM-DD）
- `--end-date`：回测结束日期（格式：YYYY-MM-DD）
