# ML 标注方案设计 — Ground Truth 定义

> 核心问题：如何定义"好的入场时机"？

## 1. 为什么标注方式是最重要的设计决策

ML 模型只能学到你教它的东西。如果你告诉它"5天后涨就是好"，它就去学"什么时候5天后会涨"。
但你真正想要的是"什么时候是相对低位"，这是两个完全不同的问题。

**标注方式决定了模型在优化什么目标。**

---

## 2. 方案对比

### 方案 A: Fixed Horizon（已淘汰）

```
label = 1 if close[t+5] > close[t] else 0
```

**问题：**
- 窗口选择无理论依据（为什么5天？3天/20天给出完全不同的标签）
- 路径不敏感（第2天涨3%但第5天跌回来 → 被标记LOSS，荒谬）
- 与择时目标错位（不回答"买得便宜吗"）

### 方案 B: Triple Barrier（de Prado 三重屏障法）

```
三道围栏：
  止盈线 TP = +2.0%
  止损线 SL = -3.0%
  时间墙 N  = 20 交易日

哪个先碰到就以那个定标签。
```

**参数来源（基于 SPY 30年数据统计）：**
- SPY 买入后20天内 MFE(最大浮盈) P50 = +2.6%
- SPY 买入后20天内 MAE(最大浮亏) P50 = -1.6%
- 选 TP=2% / SL=-3% 是非对称的，因为 DCA 不怕小浮亏，怕买贵

**优势：**
- 捕捉价格路径，不是终点快照
- 非对称设计贴合 DCA 场景
- 业界标准（Man Group, Two Sigma 等机构使用）

**AUC-PR: 0.741（三种中最高）**

### 方案 C: Relative Low（相对低点评估）

```
avg_price = mean(close[t+1 : t+21])
label = 1 if entry_price < avg_price else 0
```

**逻辑：**
- 直接回答"我是不是买在了接下来这段时间的相对低位"
- 正数 forward_return 意味着你买的价格低于未来20天均价 → 你买便宜了

**优势：**
- 语义最贴合 DCA 择时的核心诉求
- 不需要设阈值参数
- 评估标准清晰：买完之后回头看，你确实买在低位了吗？

**AUC-PR: 0.668（模型暂时学不太好，但标签语义最正确）**

### 方案 D: Swing Low 邻近度（最终选定方案）

```
sl7 = detect_swing_lows(close, dates, N=7)
label = 1 if |signal_date - nearest_sl7| <= 3 天
```

**逻辑：**
- Swing Low 就是局部最低点（前后 N 天都比它高）
- 如果 NDay5 信号在 SL7 的前后 3 天内触发 → 在底部区域
- 如果信号远离任何 SL7 → 不在底部

**优势：**
- 最直觉，直接回答"我是不是在底部附近"
- 标注的区分力最强（正WR=79% vs 负WR=55%，差距24pp）
- 无需收益率假设，纯粹基于价格结构

**关键认知：GT 标注使用未来信息是完全合法的** — 这就是"标准答案"。
只有特征不能偷看未来。

**详细分析见: `sl7-proximity-labeling.md`**

## 4. 参数选择依据

### Triple Barrier 参数

基于 SPY 1993-2025 全量数据统计：

| 指标 | P25 | P50 | P75 |
|------|-----|-----|-----|
| 20D MFE (最大浮盈) | +1.2% | +2.6% | +4.3% |
| 20D MAE (最大浮亏) | -3.8% | -1.6% | -0.3% |
| 年化波动率 | 9.6% | 13.5% | 19.4% |

选择标准方案 TP=+2% / SL=-3%：
- TP=2% 略低于 MFE P50，意味着50%+的概率至少能涨到这
- SL=-3% 接近 MAE P25，只有最严重的25%下跌会触发
- 非对称设计：允许-1~2%的正常波动，只有真正买贵了（-3%）才判负

### Relative Low 参数

- window=20 天（约1个月）
- 无其他参数，标签来自纯粹的价格比较

## 5. 推荐策略（已更新）

**最终选定：SL7 Proximity (K=3)** — 区分度最强，语义最直接

**辅助对照：** Triple Barrier 作为对比参考

**核心逻辑：**
- 你的 DCA 择时需求 = "我是不是在底部附近买的？"
- SL7 Proximity 直接回答这个问题
- 正负标签的实际收益差距最大（+3.46% vs +0.07%）

## 6. 关键认知

1. **标注定义了优化目标** — 换标注 > 换模型 > 换特征
2. **DCA 择时 ≠ 短线交易** — 固定窗口收益不适合，路径/位置才重要
3. **非对称设计** — DCA 天然长持，不怕小幅浮亏，怕大幅买贵
4. **标注质量 > 模型复杂度** — 好的 GT 让简单模型也能学好
