## 问题 1：SpreadConvergence 要不要加？

先看事实：`sig_spread_conv` 作为**布尔特征**被测过，p=0.136，不显著，所以 v3 移除了。

但这里有个关键区别：**布尔版本丢失了大量信息**。SpreadConvergence 状态机把一个复杂的连续过程压缩成了 0/1，效果自然差。

我的建议是：**不要加回布尔版的 `sig_spread_conv`，而是加连续值的 `breadth_spread`（即 `c5 - c1`）。** 原因：

- 布尔版只告诉你"今天有没有收敛"，连续值告诉你"收敛到什么程度了"
- `breadth_spread` 大 → 说明深套股票很多，c5 远高于 c1，恐慌还在扩散
- `breadth_spread` 小且在缩 → 正是你之前假设的那个信号：股票在摆脱均线压制
- XGBoost 本身就擅长在连续值上找最优分裂点，比我们手动设阈值做布尔更灵活

所以结论：**加 `breadth_spread = c5 - c1` 作为连续特征，不加布尔版 `sig_spread_conv`。**

## 问题 2：RSI v2 系统还有什么可以加？

先回顾已被验证无效的：
- `sig_rsi`（当天有无 RSI 买入信号）：p=0.45，完全不显著
- `rsi_signal_strength`（0/1/2/3 离散）：p=0.22，不显著

这两个无效的**共同问题**是：RSI v2 信号本身太稀疏了。从横向对比表看，RSI_v2 在测试期只产生了 53 个信号，而 NDay5 有 188 个。在 NDay5 信号日去看"当天有没有 RSI 信号"，大部分时候答案都是"没有"，所以区分度自然差。

**但 `rsi_14` 本身是最强的单特征（r=-0.12, p=0.0002）**，说明 RSI 的连续值非常有价值。

基于这个逻辑，RSI v2 系统能扩展的连续特征只有一个值得考虑：

| 候选 | 理由 | 推荐？ |
|------|------|--------|
| **`rsi_fast_ma`**（RSI 的 EMA5） | 与 `rsi_14` 高度共线，两者相差仅平滑程度，XGBoost 已经能从 rsi_14 学到同等信息 | **不加** |
| **`rsi_minus_ma`**（RSI - fast_MA） | 代表 RSI 的短期动量方向。正值=RSI 在回升，负值=RSI 在下行。这是 rsi_14 本身无法表达的信息维度——rsi_14 告诉你"现在超卖到什么程度"，rsi_minus_ma 告诉你"RSI 正在好转还是恶化" | **值得试** |
| **`rsi_bull_div`**（看涨背离布尔） | 价格新低但 RSI 没新低，是事件3的核心。但问题和 sig_rsi 一样——太稀疏了，在 NDay5 信号日上很少触发 | **不加** |
| **`rsi_below_extreme`**（RSI < 30 布尔） | `rsi_14` 已经是连续值，XGBoost 自己就能在 30 这个点分裂，手动做布尔多此一举 | **不加** |
| **`bars_since_bull_div`** | 距上次看涨背离天数——太稀疏，大部分时候值都是 99999 | **不加** |

**结论：RSI v2 系统只推荐加一个 `rsi_minus_ma`。**

理由很 solid：
1. `rsi_14` 是"位置"信息（超卖到什么程度），`rsi_minus_ma` 是"方向"信息（在好转还是恶化），两者不共线
2. 在 RSI 同样是 28 的两天，一天 `rsi_minus_ma > 0`（RSI 在回升）另一天 `rsi_minus_ma < 0`（RSI 还在跌），前者买入质量大概率更好
3. 计算成本几乎为零——`rsi_signals.py` 已经算出了 `fast_ma`，做个减法即可

## 问题 3：Breadth 系列特征梳理

先纠正一个认知：**`breadth_c2` 其实是显著的**（r=-0.071, p=0.03），在统计检验中通过了。但你问的问题很好——它和 `breadth`（c1）之间的关系值得推敲。

### breadth_c2 的问题

`breadth` 和 `breadth_c2` 的关系是 `breadth ≤ breadth_c2`（恒成立），且两者高度正相关。c2 只是 c1 的一个"平滑版"——不要求当天在均线下，只要求最近 2 天有 1 天在均线下就算。**它确实可能和 c1 提供的信息高度冗余。**

但从统计上看 c2 是显著的，我不建议直接删。更好的做法是：**把 c2 替换成 c3 的连续值**。理由：

1. c3 和 c1 之间的差距更大，信息冗余更低
2. `sig_breadth_consec` 已经在用 `c3 < 20` 做布尔判断，且模型重要度排名第 3（`vix_regime > vix_above_200ma > sig_breadth_consec`），说明 c3 这个维度的确有价值
3. 给模型连续值的 c3，让它自己找最优分裂点，比我们硬编码 20 这个阈值更灵活

### 最终 Breadth 系列建议

| 特征 | 当前状态 | 建议 | 理由 |
|------|----------|------|------|
| `breadth` (c1) | 连续，已用 | **保留** | p=0.009，显著 |
| `breadth_c2` | 连续，已用 | **替换为 `breadth_c3`** | c2 和 c1 太近，c3 信息量更大 |
| `breadth_c3` | 未用连续值 | **加入连续值** | 替换 c2 的位置 |
| `breadth_c5` | 未用 | **不加** | 与 c3 冗余，且可通过 spread 间接体现 |
| `sig_breadth` | 布尔，已用 | **保留** | p=0.045 |
| `sig_breadth_consec` | 布尔 c3<20，已用 | **保留** | 重要度 Top 3 |
| `sig_breadth_div` | 布尔，已用 | **保留** | p=0.015 |
| **`breadth_spread`** | 未用 | **新增** `c5 - c1` | 见问题 1 分析，收敛/发散的核心指标 |
| **`breadth_delta`** | 未用 | **新增** `breadth - breadth_prev` | breadth 日变化，正=好转，负=恶化。类似 rsi_minus_ma 的逻辑——位置+方向两个维度 |

### 总结变更

```
移除: breadth_c2
新增: breadth_c3 (连续), breadth_spread (c5-c1), breadth_delta (日变化)

净变化: -1 + 3 = +2 个特征
```

加上 RSI 的 `rsi_minus_ma`，总共是 **+3 个新特征，替换 1 个**，从 11 → 14 个。特征数量仍然在合理范围内（样本数 1383，特征 14，比例约 100:1，远离过拟合区域）。
