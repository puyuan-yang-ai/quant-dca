# ML Meta-Labeling — 升级路径 Roadmap

## 当前状态 (2026-06-12 MVP)

| 指标 | 值 |
|------|-----|
| AUC-ROC | 0.570 |
| 模型 | XGBoost, 默认参数 |
| 特征 | 18 个（9 布尔 + 8 连续 + 1 离散） |
| 标签 | Fixed Horizon 5天 |
| 切分 | 一次性 80/20 时间切分 |
| 信号排名 | 第 5（在 VIX+NDay5, VIX>30, Breadth<20, SafeHaven 之后） |

**结论：ML 过滤比不过滤好，但还没超越最好的规则组合 VIX+NDay5。**

---

## 升级方向（按优先级排列）

### P0: 评估体系升级 — 让结论更可信

| 任务 | 说明 | 预计工作量 |
|------|------|------|
| Walk-Forward CV | 滚动窗口训练测试，验证不同市场环境稳定性 | 中 |
| AUC-PR 作为主指标 | 已加入 evaluate.py ✓ | 已完成 |
| 统计显著性检验 | t-test 或 bootstrap 检验收益差异是否显著 | 小 |

### P1: 标签升级 — 更贴近实盘

| 任务 | 说明 | 预计工作量 |
|------|------|------|
| Triple Barrier 标签 | 带止盈止损的标签方式，收益/风险更真实 | 中 |
| 多 Horizon 对比 | 对比 3/5/10/20 天标签效果差异 | 小 |

### P2: 特征升级 — 让模型学到更多

| 任务 | 说明 | 预计工作量 |
|------|------|------|
| 时序滞后特征 | 各指标的 lag-1/3/5，捕捉变化趋势 | 小 |
| 变化率特征 | VIX 5日变化、Breadth 5日变化等 | 小 |
| 交互特征 | Breadth × VIX、EMA距离 × 连续天数 等 | 小 |
| 成交量特征 | Volume 相对均值、放量缩量 | 小 |

### P3: 模型升级 — 提升学习能力

| 任务 | 说明 | 预计工作量 |
|------|------|------|
| 超参调优 | Optuna/GridSearch 在验证集上调参 | 中 |
| LightGBM 对比 | 通常比 XGBoost 更快，效果相当 | 小 |
| 模型 Ensemble | 多个模型投票 | 中 |

### P4: 系统集成 — 接入回测引擎

| 任务 | 说明 | 预计工作量 |
|------|------|------|
| MetaLabelingEntry 模块 | 包装成标准 Entry，接入 BacktestEngine | 中 |
| 完整回测对比 | 含仓位、手续费、止盈的完整 Sharpe/Calmar 对比 | 中 |
| 信号输出 CSV | 每日输出 ML 信号供其他系统使用 | 小 |

### P5: 高级方向（远期）

| 任务 | 说明 |
|------|------|
| 凯利公式仓位管理 | 根据 predict_proba 动态调仓 |
| 分箱验证 | 验证概率分箱与实际胜率的单调性（模型校准） |
| 多标的扩展 | SMH/QQQ 同框架复用 |
| 在线学习 | 增量更新模型，适应市场变化 |

---

## 建议的执行顺序

```
第一轮（短期）: P0 Walk-Forward + P2 变化率特征
  → 目标: 验证结论稳定性 + 尝试超越 VIX+NDay5

第二轮（中期）: P1 Triple Barrier + P3 调参
  → 目标: AUC-PR 显著提升

第三轮（中长期）: P4 集成 BacktestEngine
  → 目标: 完整策略回测，Sharpe ≥ Buy & Hold + 0.2

第四轮（远期）: P5 仓位/校准/扩展
  → 目标: 实盘可用
```
