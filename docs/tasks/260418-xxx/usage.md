# 交互式图表 — 使用说明

## 运行方式

在项目根目录（`quant-dca/`）下：

```bash
# 运行回测并启动图表服务（默认 bear-bull 环境，端口 9870）
bash show_chart.sh

# 指定市场环境
bash show_chart.sh --env bear          # 纯熊市（2022-01 ~ 2022-12）
bash show_chart.sh --env bull          # 纯牛市（2022-10 ~ 2024-07）
bash show_chart.sh --env bear-bull     # 熊转牛（2022-01 ~ 2024-07）← 默认
bash show_chart.sh --env bull-bear     # 牛转熊（2022-10 ~ 2025-04）

# 指定端口
bash show_chart.sh --port 8080
```

## 使用流程

```
第一次运行：
  bash show_chart.sh
    → 回测完成
    → 终端输出 URL（如 http://10.7.78.227:9870/interactive.html）
    → 复制 URL 到本地浏览器打开
    → 看到交互式 K 线图
    → 服务保持运行（Ctrl+C 停止）

切换环境查看（开另一个终端）：
  bash show_chart.sh --env bear
    → 回测完成
    → 检测到服务已在运行，提示"刷新浏览器"
    → 回到浏览器按 F5 刷新
    → 看到新环境的图表
```

**核心体验：第一次复制 URL 到浏览器，之后每次只需重新跑脚本 + 浏览器刷新。**

## 图表内容

- **顶部信息栏** — 标题、收益率、夏普比率、最大回撤、交易笔数
- **SOXL K 线图**（蜡烛图，含 OHLC）
- **EMA20 线**（橙色叠加线）
- **买入信号标注**：
  - 蓝色上箭头 = 市价买入
  - 绿色上箭头 = 限价买入（标注跌幅档位）
- **止盈信号标注**（红色下箭头，需使用带止盈策略时才会出现）

## 交互操作

| 操作 | 方式 |
|------|------|
| 缩放 | 鼠标滚轮 |
| 平移 | 鼠标左键拖拽时间轴 |
| 十字光标 | 鼠标移动时自动显示 |
| 重置视图 | 双击图表区域 |
| Y 轴自动跟随 | 缩放/平移时自动调整 |
