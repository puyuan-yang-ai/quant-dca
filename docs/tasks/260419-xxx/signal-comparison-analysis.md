## 3. 分析

### 3.1 RSI v2 的核心优势：精选择时

RSI v2 最显著的特征是**买入次数极少**——全量数据 15 年只买了 196 次，是 Baseline 的 1/4。但年化收益率在所有环境下都更高。

这说明 RSI v2 的信号**质量远高于数量**。每次出手都更加精准，单次买入的平均收益更高。

```
买入效率对比（全量数据）：

NDayConfirm-5: 834 次买入 → 年化 +9.10%  → 每次买入贡献 ≈ 0.011%
RSI v2:        196 次买入 → 年化 +10.53% → 每次买入贡献 ≈ 0.054%

RSI 每次出手的效率是 Baseline 的 5 倍。
```

### 3.2 RSI v2 在熊市中的表现最突出

在纯熊市环境中，RSI v2 的优势最明显：

- 年化亏损少 2.88%（-49.04% vs -51.92%）
- 最大回撤低 4.7%（50.5% vs 55.2%）
- 买入次数只有 24 次（Baseline 114 次）

**原因**：熊市中，Baseline 的 EMA 过滤条件几乎常年满足（价格持续低于 EMA），导致频繁买入。而 RSI v2 只在真正超卖时才出手，避免了"中途接飞刀"。

### 3.3 RSI v2 在牛市中的隐忧

在纯牛市中，RSI v2 的 Sharpe (0.79) 与 Baseline (0.80) 几乎持平，且最大回撤略高 (44.3% vs 42.7%)。

**原因**：牛市中 RSI 很少进入超卖区（< 40），信号极少（只有 13 次买入 vs Baseline 78 次）。RSI v2 错过了很多上涨过程中的"正常回调"买入机会。虽然年化收益更高（+114% vs +105%），但那是因为少数几次精准抄底的贡献，收益集中度高，运气成分不可忽略。

### 3.4 最大回撤：RSI v2 的弱点

在 5 个环境中，RSI v2 的最大回撤有 2 次比 Baseline 更高（牛市 +1.6%、牛转熊 +2.3%），2 次更低（熊市 -4.7%、熊转牛 -4.7%），1 次持平。

**原因**：RSI v2 买入次数少，持仓集中在少数几个时间点。如果某次买入恰好在下跌中继（而非真正的底部），单次亏损对整体影响更大。相比之下，Baseline 分散在 100+ 次买入中，天然分散了风险。

**这是"精选"策略的固有特性**：高收益 + 高集中度 = 好的时候很好，差的时候可能更差。

### 3.5 全量数据的表现

全量 15 年数据覆盖了多轮牛熊。RSI v2 年化 +10.53% vs Baseline +9.10%，Sharpe 0.11 vs 0.09。优势不大但稳定。

最大回撤几乎相同（89.0% vs 88.5%）——这主要受 2020 年 COVID 崩盘影响（SOXL 跌超 80%），所有策略都无法避免。

## 4. 结论

### 4.1 RSI v2 是否应该升级为新 Baseline？

**是的，但需要注意。**

RSI v2 在加权 Sharpe 上胜出（0.1610 vs 0.1464），在 5 个环境的年化收益率上全胜，在熊市中抗跌能力明显更强。它的核心优势是"少而精"——用 1/4 的买入次数获得了更好的收益率。

但它有两个需要注意的点：
1. **信号稀少**：在牛市中可能错过机会（13 次 vs 78 次）
2. **集中度风险**：持仓集中在少数时间点，单次判断失误的影响更大

### 4.2 后续建议

| 方向 | 具体做法 | 预期效果 |
|------|---------|---------|
| **融合策略** | EMA 过滤 + RSI 信号双重条件 | 可能兼顾覆盖率和精准度 |
| **执行层调优** | 锁定 RSI 信号，重新跑 4 阶段实验 | 找到适合 RSI 节奏的最优仓位/档位 |
| **信号分级执行** | B → 轻仓，B+ → 标准，B++ → 重仓 | 利用信号强度信息提升效率 |
| **止盈加入** | 加入 DeviationPeakTP 或 TrendConfirmTP | RSI 精选买入 + 止盈可能效果更好 |

### 4.3 风险提示

当前比较使用的是标准化执行层（买 1 股、不止盈），**只比较了信号择时质量**。实际交易中：
- 执行层的影响可能与信号层一样大
- RSI v2 目前未接入执行层优化，Baseline 已经经过 4 阶段调优
- 公平的最终比较应该是：RSI + 最优执行 vs Baseline + 最优执行（见 strategy-comparison-guide.md 的两步走流程）
