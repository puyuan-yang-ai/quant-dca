# ML Features V3 — 窗口化 + 信号共振 + 多尺度标注

## 需求

解决 V2 的"温和底部误杀"问题。V2 在 drawdown -5%~-10% 的普通回调底部（如 2022-12-28、2023-03-13）给出低概率（0.3~0.4），导致好买点被 SKIP。

## 根因

1. 特征是"单天快照"，信号之间有 1-2 天错位（NDay5 和 RSI B 不同天触发）
2. 训练集中"温和回调"区域的正负标签特征分布几乎相同，模型无区分力
3. 人看图时看"区域内多信号共振"，模型只看"单天单特征值"

## 目标

- Recall 从 39% 提升到 50%+（减少好买点被误杀）
- AUC-ROC >= 0.618（不低于 V2）
- 具体验证：2022-12-28、2023-03-13 的概率从 0.3~0.4 提升到 0.5+

## V2 基准

```
AUC-ROC: 0.618
Recall: 39%
ML 信号数: 85/275
平均 20D 收益: +3.16%
```
