# V3 实验结果与经验沉淀

## V1 → V2 → V3 全版本对比

| 指标 | V1 (11特征) | V2 (15特征) | V3 (21特征) |
|------|-------------|-------------|-------------|
| AUC-ROC | 0.599 | 0.618 | **0.634** |
| AUC-PR | 0.480 | 0.472 | **0.636** |
| Recall | ~39% | ~39% | **50.7%** |
| ML 放行信号数 | 82 | 85 | 116 |
| 正标签比例 | 38% | 38% | 49% |
| 标注方式 | SL7 only | SL7 only | SL5+SL7 |
| 特征数 | 11 | 15 | 21 |

## 关键发现

### 1. AUC-PR 从 0.47 暴涨到 0.64

这是最显著的提升（+34%），原因是**多尺度标注让正负标签更平衡（49% vs 之前的 38%）**。AUC-PR 对不平衡数据很敏感，标签平衡后 PR 曲线自然改善。

### 2. Recall 从 39% 提升到 50.7%

V2 只放行 85/277 信号（31%），V3 放行 116/277（42%）。模型变得更"积极"——这正是我们想要的，因为 V2 太保守导致好买点被误杀。

### 3. 被误杀信号的修复情况

| 日期 | V2 概率 | V3 概率 | V3 决策 | 实际 20D 收益 |
|------|---------|---------|---------|--------------|
| 2022-12-28 | 0.322 | 0.268 | SKIP | +7.7% |
| 2023-03-13 | 0.436 | 0.464 | SKIP | +6.7% |
| **2023-03-14** | 0.335 | **0.637** | **BUY** | +4.6% |
| **2023-03-15** | 0.200 | **0.639** | **BUY** | +6.6% |

**2023 年 3 月的黄金坑被部分救回**：03-14 和 03-15 概率从 0.2~0.3 跳到 0.64，成功通过。

**2022 年 12 月底仍然未被救回**：这是模型的能力边界——那段时间的特征组合太温和，即使加了窗口化和共振，模型仍然没有足够的区分信号。

### 4. Confluence Score 的验证

| 日期 | confluence_5d | V3 决策 |
|------|--------------|---------|
| 2022-12-28 | 4 | SKIP (高共振但概率仍低) |

## 核心经验

### 1. 三件事各自解决了什么问题

| 改进 | 解决的问题 | 效果 |
|------|-----------|------|
| 特征窗口化 | 信号错位1-2天 | rsi_min_3d 让模型看到"最近到过超卖" |
| Confluence Score | 人眼能看到"多信号共振"但模型看不到 | 把直觉编码为数字 |
| 多尺度 SL 标注 | 正标签太少，温和底部覆盖不足 | 正标签 38%→49%，模型有更多正样本学习 |

### 2. AUC-PR 的跳跃说明什么

AUC-PR 对正标签比例很敏感。V2 的 0.47 低是因为正标签只有 38%（少数类），模型想从少数类中精确识别正样本很难。V3 把正标签提到 49%（接近平衡），AUC-PR 自然大幅改善。

**教训：如果 AUC-PR 一直偏低，先检查标签是否太不平衡，而不是急着加特征。**

### 3. 为什么 2022-12-28 始终无法救回

Confluence = 4（已经很高了），所有窗口化特征都就位了，但概率仍然只有 0.27。

这说明模型学到了一个更深层的模式：**即使"看起来"各信号都到位了，但在那个特定的市场结构下（ema20_dist 只有 -2.7%，drawdown 只有 -7%），历史上类似情况大部分不是真底。**

模型做了一个正确的统计判断：虽然人眼觉得是好机会，但从历史概率看，这种"温和超卖+信号共振"组合的成功率确实不够高。只是这次碰巧它真的是底——这属于"模型正确地不自信"的情况。

### 4. 模型的能力边界

```
深V底部 (drawdown > -10%): 模型准确度高，信心强
温和底部 (drawdown -5~-10%): 模型有一定区分力，V3比V2好
极温和回调 (drawdown < -5%): 模型无区分力，这是当前能力边界
```
