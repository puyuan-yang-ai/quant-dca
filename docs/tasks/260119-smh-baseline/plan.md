# SMH 基准线实施方案

## 修改思路

在现有流程基础上，增加 SMH 数据的加载和收益率计算，传递给绑图模块绑制第三条线。

## 改动范围

| 文件 | 操作 | 说明 |
|-----|------|------|
| `main.py` | 修改 | 加载 SMH 数据，计算收益率，传递给绑图函数 |
| `src/chart.py` | 修改 | 增加绘制 SMH 曲线和标注 |

## 实施步骤

### Step 1: 修改 main.py

1. 加载 SMH 数据文件（使用现有 `load_data` 函数）
2. 按回测日期范围截取 SMH 数据
3. 计算 SMH 每日收益率：`(close - first_close) / first_close`
4. 将 SMH 收益率序列添加到 result 字典，传递给 `save_chart`

### Step 2: 修改 src/chart.py

1. 从 result 中读取 SMH 收益率（若存在）
2. 绘制第三条曲线（棕色/咖啡色 `#8B4513`）
3. 添加最终收益率标注
4. 更新图例

## 设计要点

- **复用现有函数**：使用 `load_data` 加载 SMH，无需新增模块
- **最小改动**：仅修改 2 个文件，不引入新抽象
