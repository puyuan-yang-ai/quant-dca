# Session 复盘：czsc 可视化 → 作为 ML 特征 → 框架杠杆（2026-06-28 夜）

> 一句话主线：从"把 czsc 买卖点画进交互图"出发，想拿它当 ML 特征，**一路被数据推着发现真正的杠杆不在特征、而在框架（候选 universe / 标签）**。

---

## 〇、最重要的三条结论（先看这个）

1. **czsc 特征对模型没用**：无论旧 universe 还是新 universe、无论离散/单布尔/5列，AUC 增量都 ≈ +0.004（噪声级）。最初的设想被证伪。
2. **真正的杠杆是"第一层候选 universe"**：把候选从「NDay2(跌破均线)」换成「近底(近30日低≤5%)」，AUC **0.638 → 0.752**（置信区间不重叠，真提升）。
3. **杠杆优先级**：**候选 universe ≈ 标签 ＞＞ 特征**。下一步破局点是**换收益类标签**（"是不是底" → "买了赚不赚"）。

## 四、知识点（重点复习）

**① 前视偏差 / 幸存者偏差**：图上"事后复盘"漂亮，是因为只画了幸存者、且钉在极值上 → 不能当真。喂模型只能用**因果信号**（实时口径，触发当天只用过去）。**被重绘的×必须全进训练**（触发时无法区分，事后剔除=偷看未来）。

**② 重绘机制**：缠论最后一笔是"铅笔的"，价格创新极值就被丢弃重画 → 约 49% 实时买卖点后续消失。

**③ 因果 vs 标签**：第一层候选**必须因果**（实盘要用，不能偷看未来）；**标签可以用未来**（它是答案）。所以候选不可能精确对称（SL7 需未来确认），只有标签能精确 ±2。

**④ AUC vs 精确率/召回率（关键！）**：
- AUC：全局**排序**力，随机基准 0.5，且**会被易分负样本灌水**（universe 放宽→AUC 涨但不一定帮边界）。
- **精确率随机基准 = 正样本占比（这里 30%），不是 0.5**！精确率 0.52 = 1.7× 提升，**不随机**。
- 高 AUC ≠ 高精确率：精确率被"正样本稀少 + 排序不完美 + 阈值"共同限制；要 P 高就卡高阈值（但召回率掉）= 精确率↔召回率取舍。

**⑤ 杠杆优先级**：候选 universe ≈ 标签 ＞＞ 特征。"去哪找人(universe)"比"用什么尺子(特征)"重要得多。

**⑥ 标签天花板**：sl_proximity 标的是"底部邻近度"≠"收益"。**即使底探得准，也不等于赚钱**——这是最终经济价值的天花板，要靠**换收益类标签**(triple-barrier 等)突破。

**⑦ 统计口径 & "看着准但只有 52%"**：
- **精确率的分母 = "模型出手的那批天"**，换 universe 口径**不改变精确率**（出手的天没变）。
- **全 K 线的"准确率(accuracy)"会虚高 = 准确率悖论**：大量"轻松不买日"灌水，对稀有事件毫无意义（所以稀有事件从不用 accuracy）。
- **眼睛"看着准" = 用了比标签松的"命中尺"**：标签"±2 根 bar 内"很严；肉眼"差不多在坑里/后面涨了"就算好 → 放松命中尺，数字自然升到贴合体感。

**⑧ 横向可比性 & IC**：
- 分类指标(精确率/AUC)都依赖 **universe + label + 阈值**，**不可跨团队比**（各家卷子不同）。
- 公平比较靠**统一最终目的(收益) + 统一评估协议(样本外/防泄漏/统一成本)**，**不是**靠统一 universe。
- **IC(信息系数)** = 预测值与未来收益的**秩相关**，是评"信号预测力"的业界标尺——**只需"信号 + 未来收益"，不需要交易系统**。
- 终极尺 = **扣成本样本外夏普**（但需接订单/仓位/止盈的交易系统）。

**明天主线：用 IC 评"买点信号"本身**（业界标尺、不需交易系统）。诉求 = 只衡量买点信号好不好，不碰订单/挂单/仓位/止盈。
1. **算 IC**：模型 OOS `proba` 与 **未来 20 日收益** 的 **rank IC（Spearman）**；并报 **IC 均值 / IC-IR(均值/标准差，按时间分段)**。
2. **分位/事件研究**：把 OOS 预测按分位分桶，看**高分位 vs 低分位的远期收益**是否单调拉开（"信号越强→未来收益越高"=有预测力）。
3. **直接可算**：现成 `output/oos_proba_*.csv` 已含 `proba + forward_return`，无需重训、无需交易系统。
4. **横向对比**：v3_n2 vs v5_pa 的 IC，看"换 universe"是否也提升了"信号→收益"的预测力。

**为什么不是夏普**：夏普需接整套交易系统（订单/限价挂单/仓位/止盈），内容多；当前只评**信号**，故用 **IC（信号级、业界公认、与交易系统解耦）**。夏普留到信号确认有价值后再接系统。

**中期**：换收益类标签(triple-barrier/收益分位)让目标与收益对齐；czsc 特征已证伪，可搁置。
