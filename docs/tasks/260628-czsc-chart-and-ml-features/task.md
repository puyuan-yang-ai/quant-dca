# 任务：czsc 缠论可视化 + 作为机器学习特征

## 背景

- **quant-dca**：SPY/SOXL 定投（DCA）量化项目，含回测引擎 + ML meta-labeling（XGBoost 给抄底候选日打分）。
- 已 vendored czsc 缠论核心（`src/chan/czsc_vendor/`）：`K线 → 分型 → 笔 → 中枢` + 一二三类买卖点信号；纯价格几何，无线段/递归，"级别"= 输入 K 线周期。
- 交互式图表（`src/interactive_chart.py` + `scripts/show_chart.py`）：基于 lightweight-charts 的自包含 HTML + 本地 HTTP 服务。

## 需求

1. **可视化**：在交互图（SPY 日线全周期）主图上叠加 czsc 结构——分型、笔、中枢、一二三类买卖点。
2. **揭示重绘 / 前视偏差**：区分买卖点的"被看到的时点"，提供三视图：
   - 实时回放 / 确认实战 / 事后复盘。
3. **沉淀为 ML 特征**：把 czsc 买点做成可复用指标模块，并作为机器学习特征，验证能否提升现有模型。

## 目标

- **图表（已交付）**：三视图可切换、按方向/类型过滤、悬停明细；czsc 模式纯缠论画面（隐藏交易/Swing/ML 标记与副图、不画 EMA）；全周期秒级生成、绘图库本地化加载。
- **ML（待实施）**：新增 czsc 特征 → 用项目**现有全套评估量具**（统计 WF + 经济 A/B + 三条判据），对 **v3 / v3_n2 / v4 三版并排对比**，客观回答"czsc 特征是否带来提升"。

## 关键认知（决定方案的前提）

- **缠论买卖点是"事后确认"**：标记虽可画在拐点极值，但实时只能在其后才知道；且最近一笔是"铅笔的"——价格创出新极值会触发**重绘**（该笔被丢弃、重画到新极值），导致**约一半实时信号后续被抹掉**。
- **前视偏差红线**：
  - **事后复盘视图（含幸存者筛选）禁止进入模型**——它用了未来信息。
  - **实时回放（触发当日记录）与确认实战（确认日记录）都是因果的、可用作特征**。
- **ML 特征用实时口径**：实时及时、能抓到更低点；由模型负责过滤重绘噪声（这正是 meta-labeling 的本职）。
- **被重绘的信号（灰色 ×）必须全部进入训练**：信号触发当时无法区分其将来会否被抹掉，事后剔除即 look-ahead；它们恰是模型要学的"难负样本"。
- **评估要对齐项目既有方法论**（不只看 AUC）：统计层（WF + Purge/Embargo + 唯一性权重 → AUC-ROC/CI/PR）+ 经济层（接回测引擎 A/B → Sharpe/收益/条件收益/t 检验/阈值扫描）+ 三条验收判据。
- **AUC 只看排序、不看幅度**：v3 历史结论是"统计可信但经济无价值"，根因在 `sl_proximity` 标签（标的是"底部邻近度"而非"收益幅度"）。故对 v4 **不预期直接变现**——经济判据才是真正门槛，本轮目的在于**隔离 czsc 特征单独的贡献**。

## 范围与非目标

- **本次范围（A 方案，只动一个变量）**：候选样本不变（现有 NDay 门槛 `n=2`），**仅新增 czsc 特征列、标签（`sl_proximity`）不变**；评估沿用现有全套量具，v3 / v3_n2 / v4 三版并排。
- **非目标（留作下一步，B 方案）**：以 czsc 实时买点为候选事件、做成"czsc 信号过滤器"——改动更大，且无法与 v3_n2 直接对比。
- **不修改现有活模型 `v3_n2`**。
