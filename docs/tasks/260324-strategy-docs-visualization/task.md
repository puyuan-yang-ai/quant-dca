# 策略文档化 + 买点可视化

## 任务目标

1. 用伪代码描述两套 SOTA 策略，写入 `docs/tasks/todos/sota_strategys.md`
2. 画 K 线图可视化两套策略的买入信号，便于直观理解策略行为差异

## 两套 SOTA 策略

| 参数 | 旧 SOTA | 新 SOTA |
|------|---------|---------|
| EMA 周期 | 20 | 30 |
| 确认天数 N | 5 | 7 |
| 档口间距 | 2%/5%/10% | 1%/3%/7% |
| 仓位 | 正金字塔 (0.15/0.25/0.40/0.70) | 同左 |
| 止盈 | 不止盈 | 同左 |

## 可视化需求

- 4 个市场环境各一组图
- 长区间（>300 交易日）按半年分段为子图
- 每张图包含：SOXL 日 K 蜡烛图、EMA20 线、EMA30 线
- 两套策略的买入信号用不同颜色 + 数字（1~4）标在 K 线下方
