问题：当前两套SOTA策略（不同EMA周期、确认天数及档口间距）缺乏清晰的文档记录，且仅有收益数据而无法直观对比它们在真实行情中的买入行为差异。
影响：缺乏文档沉淀和直观的买点可视化，导致难以深入理解参数变化对实际交易触发时机和频率的具体影响，不利于策略逻辑的复盘和优化。
修复方案：计划编写伪代码文档详细对比新旧SOTA策略，并使用K线图对四种不同市场环境下的买入信号进行可视化标注，以便直观分析策略的微观行为。
