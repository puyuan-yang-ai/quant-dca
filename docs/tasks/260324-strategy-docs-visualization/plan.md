## 第二步：K 线买点可视化

### 图表规格

| 要素 | 说明 |
|------|------|
| K 线 | SOXL 日 K 蜡烛图（红涨绿跌或自定义配色） |
| EMA 20 | 蓝色线 |
| EMA 30 | 橙色线 |
| 旧 SOTA 买入信号 | 绿色数字（1~4）标在 K 线下方，表示当天成交笔数 |
| 新 SOTA 买入信号 | 紫色数字（1~4）标在 K 线下方，与旧 SOTA 错开 |

### 4 组图表

| 环境 | 时间区间 | 交易日数 | 分段方式 |
|------|---------|---------|---------|
| bear | 2022-01-01 ~ 2022-12-31 | ~251 天 | 单张图 |
| bull | 2022-10-10 ~ 2024-07-08 | ~437 天 | 2 张子图（每半年） |
| bear-bull | 2022-01-01 ~ 2024-07-08 | ~630 天 | 3 张子图（每半年） |
| bull-bear | 2022-10-14 ~ 2025-04-08 | ~622 天 | 3 张子图（每半年） |

### 买入信号计算

对每个交易日，运行策略逻辑，统计成交笔数：
- 市价单成交 = 1 笔
- 限价单 A 成交 = 1 笔（当日最低价 <= 开盘价 × (1 - 一档%)）
- 限价单 B 成交 = 1 笔（当日最低价 <= 开盘价 × (1 - 二档%)）
- 限价单 C 成交 = 1 笔（当日最低价 <= 开盘价 × (1 - 三档%)）
- 当天总成交 = 0~4 笔

### 输出

图片保存到 `output/` 目录，命名格式：`strategy_signals_{环境名}.png`

## 依赖

需要安装 `mplfinance` 库用于绘制专业 K 线图，或使用 matplotlib 手动绘制蜡烛图。
