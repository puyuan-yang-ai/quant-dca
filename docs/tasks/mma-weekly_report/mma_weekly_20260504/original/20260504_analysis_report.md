### 当周（5/4 - 5/8）核心占星

- **5/4 Mars square Jupiter**：扩张与冲动碰撞，常对应高位剧烈波动或加速突破。
- **5/6 Pluto retrograde**：长期能量转向，对应市场短期反转节点。
- **当周 CRD 仅 1 星**，单独权重较弱，但配合后续 Mars-Aries 窗口形成连续反转区。

### 5/8 - 5/16 Mars 22-27° Aries 强反转窗口

> Mars 合相 NYSE Saturn、对冲 NYSE Jupiter/Neptune（位于天秤座）

- 性质：**反转优先**（不预设方向）。
- 既可能形成 **major cycle trough**（回调结束、再做多），也可能形成 **major cycle crest**（趋势暂顶、深度回调）。
- 配合 Jupiter/Neptune → 行情波动可能放大、消息驱动剧烈。
- **从市场实际走势看，5/14 的 ATH 7,540 高度怀疑就是这个窗口内形成的 crest**。

### 5/22 - 5/26 三星 CRD（本月主角）

- 强度最高（3 星），传统对应主周期或半主周期级别拐点。
- 节假日缩短交易日（May 25 Memorial Day），周边波动可能加剧。
- **重点关注**：如果 5/14-5/16 已经形成 crest 并启动回调，那么 5/22-5/26 窗口就是 **major cycle trough 候选**。
