## 仓位计算（半凯利）

- 本周有效做多概率 p = **80%**（A=55% + B=25%，两者本周方向一致）
- 盈亏比 b = max_profit / max_loss = $279 / $221 = **1.262**
- 原始凯利：f* = (p × b − (1−p)) / b = (0.80 × 1.262 − 0.20) / 1.262 = 0.8096 / 1.262 = **64.2%**
- 半凯利：f* / 2 = **32.1%**
- ⚠️ 半凯利 > 30%，已压至硬性上限 **30%**
- 建议下注：期权预算 $4,890 × 30% = **$1,467**
- 单组 debit = $2.21 × 100 = $221
- 建议张数 = floor($1,467 / $221) = **6 组**
- 占总资金约 **27.1%**（$1,326 / $4,890）
