# MMA CRD Event Study：统计验证占星反转日的有效性

## 背景

quant-dca 项目目前的 MMA 周报校验流程（`mma-3-verify` 命令 + 每周 `scenario_evolution.md`）建立在一个**未被独立验证的假设**之上：MMA 的 Geocosmic Critical Reversal Dates (CRDs) 真的能在统计意义上预测市场反转。

这个假设的来源是 Raymond Merriman 本人 50 年的口碑与 MMA 在周报中给出的描述性数字（"82% 频率出现反转"、"±3 天 orb"），但**从未在 quant-dca 项目内用独立数据复现**。在继续投入更多精力于 MMA 框架（更复杂的剧本推演、规则化回测、状态空间建模等）之前，必须先把这个**地基**验证清楚。

讨论的完整逻辑链记录在 [对齐讨论](https://example.invalid/placeholder)（聊天 transcript），核心结论：**Event study 是后续任何 MMA 相关建模的必经前置步骤**。

## 目标

### 主要目标

回答一个核心问题：**MMA 体系所依赖的占星几何关系，在 SPY (1993-2026) 与 DJIA (1928-2026) 上是否具有可统计验证的市场反转 edge？**

可拆解为三个子问题：

1. **复现 MMA 自己的 claim**：CRD 窗口（±3 天 orb）内出现"两周新高/低后反转"的频率，是否显著高于无 CRD 窗口？MMA 声称的 82% 能否被复现？
2. **量化前瞻交易价值**：进入 CRD 窗口后 N 天（N=1, 3, 5, 10）的收益分布、波动率、Sharpe，是否显著优于无 CRD 窗口的同期对照？
3. **识别"真正有 edge"的占星组合**：在所有行星几何关系（合/冲/方/三）中，哪些组合的统计显著性最强？是否与 MMA 文献中强调的关键组合（如 Venus-Saturn hard aspect、Sun-Uranus 等）一致？

### 决策价值

| 验证结果 | 后续行动 |
|---------|---------|
| 反转频率 + 前瞻收益**均显著**（p < 0.05 且年化超额 ≥ 3%）| 进入 Step 2：规则化回测 MMA 决策逻辑 |
| 反转频率显著但前瞻收益不显著 | MMA 适合做"reversal alert"工具，不适合做方向性交易；调整 scenario_evolution 用法 |
| **两者均不显著**（p > 0.05 且年化超额 < 3%）| 终止 MMA 相关建模投入，daily verify 流程降级为参考性观察 |

## 关键决策（已对齐）

| 维度 | 决策 | 备注 |
|------|------|------|
| **CRD 方法论** | 混合（先全扫描建基线，再对照 MMA 规则验证） | 避免 cherry-picking；同时保留与 MMA 直接对比的能力 |
| **Edge 度量** | 反转频率 + 前瞻收益 双指标 | 反转频率验证 MMA 的 claim；前瞻收益对接交易决策 |
| **Kill 阈值** | p > 0.05 **且** 年化超额收益 < 3% | 中等严格；平衡假阳性与实用性 |
| **测试标的** | SPY (1993-) + DJIA (1928-) | DJIA 给长历史样本，SPY 给现代市场样本；分开报告 |
| **交付形态** | quant-dca task 文档 + 可复用代码模块 + 探索 notebook | 沿用现有 task 结构 |

## 范围

### 包含

- 用 Skyfield + JPL DE440 历表精确计算 1928-2026 年所有主要行星几何关系
- 用 Tiingo (SPY) + Stooq/Yahoo 镜像 (DJIA) 拉取历史日线数据
- 对所有主要行星对的硬相位（合、冲、方）+ 软相位（三、六）做全量统计扫描
- 与 MMA 文献中点名提及的关键 CRD 组合做对比验证
- Bonferroni / FDR 多重比较校正
- 输出统计报告（含 p-value、效应量、按强度分层的收益分布、与基线的对比）

### 不包含

- 不做规则化交易回测（属于 Step 2，另开 task）
- 不做 EMD / HHT / MESA / Kalman 等高级建模（依赖本 task 结论）
- 不计算 Solar/Lunar reversal dates（短周期，属另一研究范畴）
- 不构建实时交易信号（属于工程化阶段，另议）
- 不复现 MMA 的 cycle counting 方法（属周期范畴，与 CRD 验证正交）

## 关键风险

1. **DJIA 历史数据质量**：1928-1962 区间的成分股变更、除数调整可能影响极端事件统计。
2. **多重比较问题**：扫描 ~150 个相位组合时，按 α=0.05 期望有 7-8 个假阳性。必须做 Bonferroni / Benjamini-Hochberg 校正。
3. **结构性时变**：1929 / 1987 / 2000 / 2008 / 2020 几次市场结构断裂可能让"全样本统计"误导。需要分时段稳健性检验。
4. **MMA 规则解读偏差**：MMA 文献对"CRD 触发条件"的描述可能不够精确，复现时存在主观性。需要明确记录每条规则的来源出处。
