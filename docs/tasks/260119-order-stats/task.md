# 回测结果增加订单分类统计

## 1. 功能概述

在回测结果输出中，增加按订单类型分类的详细统计信息，区分市价单和各档限价单的成交情况。

## 2. 输出格式

```
总持股数量：282.3000 股
  - 市价单：175.70 股（$4,200.00）成交 251 次
  - 限价单：106.60 股（$2,495.31）成交 450 次  ← 450 = 200 + 150 + 100
    - 跌2%：xx.xx 股（$xxx.xx）成交 200 次
    - 跌5%：xx.xx 股（$xxx.xx）成交 150 次
    - 跌10%：xx.xx 股（$xxx.xx）成交 100 次
```

## 3. 统计维度

| 订单类型 | 统计项 | 说明 |
|---------|--------|------|
| 市价单 | 股数、金额、成交次数 | |
| 限价单（汇总） | 股数、金额、成交次数 | 成交次数 = 各子项之和 |
| 限价单（分档） | 股数、金额、成交次数 | |

## 4. 档位描述

根据 `price_ratio` 自动计算：
- `0.98` → "跌2%"
- `0.95` → "跌5%"
- `0.90` → "跌10%"

计算公式：`(1 - price_ratio) * 100`%

## 5. 验收标准

- [ ] 市价单单独统计（股数、金额、成交次数）
- [ ] 限价单汇总统计（股数、金额）
- [ ] 限价单按档位细分统计（股数、金额、成交次数）
- [ ] 档位描述自动生成
