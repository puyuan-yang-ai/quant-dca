### 一、哪些因子有科学/统计基础（值得尝试）

**1. 月相周期 (Lunar Cycles) — 可行度：高**

这个其实有学术论文支撑：
- Dichev & Janes (2003, Journal of Private Equity)：发现新月后15天的股票收益率显著高于满月后15天，跨48个国家的数据验证
- Yuan, Zheng & Zhu (2006)：类似结论，效应虽小但统计显著

MMA 的 Solar/Lunar 概率表本质上就是在做这件事——只是他们的数据库覆盖了 1930-2024 的 DJIA，比学术研究更精细（区分了不同行星组合下的月相效应）。

**你可以做的**：用 `ephem` 库计算月相（新月/满月/上弦/下弦），作为一个 categorical 特征加入模型。这个因子的计算完全确定性、零成本。

**2. Mercury 逆行 — 可行度：中高**

从 MMA 报告验证来看：
- 周报明确说 "Mercury retrograde → position traders stand aside"
- 4/7 底部恰好是 Mercury 顺行日

本质上这可能是一个**波动率放大因子**而非方向因子。Mercury 逆行每年约3次、每次约3周，日期完全可计算。

**你可以做的**：加一个 binary 特征 `mercury_retrograde`，测试它是否与 VIX 升高 / 波段底部出现的概率有相关性。

**3. CRD 日期（行星相位聚类） — 可行度：中**

CRD 的本质算法：
1. 列出所有"Level 1/2/3"行星相位事件
2. 找连续6个日历日内有2+事件的聚类
3. 取聚类中点作为 CRD

这个方法论在统计学上其实是合理的——如果单个行星事件有微弱信号，聚类叠加确实会放大信号。问题是**你需要知道哪些相位算"有效"**，这是 MMA 40年研究的核心 IP（Volume 3 书中）。

**你可以做的**：
- 先用 `skyfield` 计算主要行星相位（合相、对冲、四分相、三分相）
- 计算"行星事件密度"（滑动窗口内的事件数）作为连续特征
- 不需要完全复制 MMA 的方法，只需验证"行星事件密集区"是否与市场反转有统计相关性

### 二、哪些因子风险很高（谨慎对待）

**1. 具体行星相位（Venus trine Mars 等） — 过拟合风险：极高**

问题：
- 行星两两组合 × 相位类型 = 几百种可能的特征
- 每种相位每年可能只出现 1-3 次
- 几百个特征、每个只有几十个样本 → **过拟合几乎是必然的**

MMA 的方法是用了 40 年数据 + 人工经验来筛选"有效"相位，不是暴力搜索。如果你用 ML 暴力搜索所有行星组合，100% 会找到"统计显著"的虚假相关。

**2. 周期阶段标注 — 主观性太强**

MMA 的周期分析核心问题：**周期标注是事后判断**。同一段走势，他们自己都给出"preferred"和"alternate"两种标注。模型训练需要确定性的标签，而他们的标注在实时中是模糊的。

从验证报告可以看到：50-week cycle 的起点是 8/5 还是 1/13，他们自己在报告中也在犹豫。这种不确定性没法直接输入模型。

### 三、核心风险定量分析

| 风险 | 严重程度 | 说明 |
|------|---------|------|
| **过拟合** | **极高** | 行星因子维度高（几百种相位）、样本低（每种每年1-3次）。即使你只选少数因子，也需要极其严格的交叉验证 |
| **样本量不足** | **高** | CRD 每年约 10-15 个，Mercury 逆行每年3次。用30年数据也只有几百个 CRD 样本 |
| **验证偏差** | **高** | 我们只验证了**一期**报告。MMA 网站展示的是精选成功案例。需要验证连续 12-24 期才有统计意义 |
| **因果不明** | **中** | 即使统计上有相关性，也可能是：(a) 偶然、(b) 通过其他已知因子（如期权到期日与行星周期恰好同步）间接产生 |
| **信号稀疏** | **中** | CRD 每月 1-3 个，Mercury 逆行每年3次。信号太稀疏可能导致模型在大部分时间没有占星特征可用 |

### 四、如果要做，推荐的稳健路线

**Phase 1：最小可行验证（1-2周）**

只测 **2 个最简单、最确定性的因子**：
```python
# 1. 月相因子（连续值 0-1，新月=0，满月=0.5）

# 2. Mercury 逆行（二元）

```

加入你现有的 NDay5 / RSI / VIX / Breadth 特征集，跑 walk-forward 回测，看 Sharpe 是否有统计显著提升（不是 in-sample，而是 out-of-sample）。

**Phase 2：CRD 密度因子（如果 Phase 1 有信号）**

```python
# 计算"行星事件密度"——N天窗口内主要行星相位的数量
aspect_density = count_major_aspects(date, window=7)
```

只用 5 种主要相位（合相 0°、对冲 180°、四分 90°、三分 120°、六分 60°），只用外行星（Jupiter、Saturn、Uranus、Neptune、Pluto）。这样特征空间可控。

**Phase 3：Solar/Lunar 概率值（需要数据）**

这是 MMA 最核心的 IP——1930 年至今每天的反转概率。你要么：
- 订阅周报每周手动记录（很慢）
- 买他们的 Galactic Trader 软件（$1,895，含 FAR 工具可自己算）
- 自己从零回测（工作量巨大，但可行——你已经有 SPY 1993-2025 的数据）

### 五、最诚实的判断

**能成吗？**

- 月相和 Mercury 逆行作为**辅助特征**加入现有模型 → **大概率不会显著提升**，但值得花1-2天验证，成本极低
- CRD 密度作为**时间窗口确认因子** → **有可能有增量价值**，特别是和你现有的 VIX > 30 + Breadth < 20 信号叠加使用
- 完整的行星相位特征工程 → **过拟合风险极高**，不推荐暴力搜索

**我更看好的角度**：不是把占星因子直接扔进 ML 模型，而是把 CRD 当作一个**独立的时间窗口过滤器**——当你的量化系统已经给出买入信号（VIX 高 + RSI 超卖 + Breadth 低）时，如果恰好处于 CRD 窗口内（+/- 3 天），把信号置信度提升。这种用法不需要 ML，是 rule-based 的叠加，更稳健、更不容易过拟合。

**坦率地说**：MMA 验证报告评分 7.7 和 6.2，其中 CRD 拿了 9 分。但这是**一个样本**。在你投入大量时间建模之前，更高 ROI 的事情是：**再验证 6-12 期历史报告的 CRD 命中率**。如果连续验证 CRD 命中率依然在 70%+，那这个因子就值得认真对待。如果发现只有极端行情才准（如 2025.4 的关税冲击），那它可能只是恰好与"黑天鹅事件倾向于在特定日历效应附近发生"重合。
