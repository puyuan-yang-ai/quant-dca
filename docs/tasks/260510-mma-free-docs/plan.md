# 月相周期与 SPY 收益率关系验证 — 实施方案

## 实施步骤

### 第一步：月相日期计算

用 `ephem` 库计算 1993-2025 年间所有月相转折点：

- **4 个关键点**：新月 (New Moon)、上弦月 (First Quarter)、满月 (Full Moon)、下弦月 (Last Quarter)
- 每个点输出精确日期（UTC → 美东时间映射到交易日）
- 预计约 32 年 × 12.4 次/年 ≈ 400 个完整月相周期

### 第二步：月相阶段划分

两种粒度并行分析：

**4 段划分**：
| 阶段 | 区间 | 天文含义 |
|------|------|---------|
| Phase 1 | 新月 → 上弦月 | 月亮渐盈（新月后约 0-7 天） |
| Phase 2 | 上弦月 → 满月 | 月亮将满（新月后约 7-15 天） |
| Phase 3 | 满月 → 下弦月 | 月亮渐亏（满月后约 0-7 天） |
| Phase 4 | 下弦月 → 新月 | 月亮将暗（满月后约 7-15 天） |

**8 段划分**：每段再对半分，用日期中点切割。

**对应 Dichev & Janes 的简化分组**：
- "新月半周期" = Phase 1 + Phase 2（新月 → 满月，约 15 天）
- "满月半周期" = Phase 3 + Phase 4（满月 → 新月，约 15 天）

### 第三步：收益率计算

对每个月相转折点，计算两种持仓周期的 SPY 收益率：

- **7 天收益率**：`(close[t+7] - close[t]) / close[t]`
- **15 天收益率**：`(close[t+15] - close[t]) / close[t]`

其中 `t` 为月相事件对应的最近交易日。

### 第四步：统计分析

| 分析项 | 方法 |
|--------|------|
| 描述性统计 | 各阶段的均值、中位数、标准差、胜率（正收益占比） |
| 组间差异检验 | 独立样本 t 检验（新月半周期 vs 满月半周期） |
| 非参数检验 | Mann-Whitney U 检验（不假设正态分布） |
| 效应量 | Cohen's d |
| 年化差异 | 将日均收益率差异年化，与学术论文的 3-5% 对照 |

### 第五步：稳定性验证

将 32 年数据分为 3-4 个子区间，分别统计：

| 区间 | 说明 |
|------|------|
| 1993-2000 | 互联网泡沫期 |
| 2001-2009 | 911 + 次贷危机 |
| 2010-2019 | QE 长牛 |
| 2020-2025 | 疫情 + 加息 |

检查信号是否在各区间一致存在，还是仅在特定市场环境下有效。

### 第六步：输出

终端打印结构化表格：


## 依赖

- `ephem`：天文历法计算（需 `pip install ephem`）
- `scipy.stats`：t 检验、Mann-Whitney U 检验
- 项目已有：`src/data_loader.py`（加载 SPY CSV）

## 关键文件

| 文件 | 作用 |
|------|------|
| `scripts/lunar_analysis.py` | 新建，主脚本 |
| `data/SPY_adjusted.csv` | 已有，SPY 日线数据 |
| `src/data_loader.py` | 已有，CSV 加载器 |

## 验证方式

```bash
python scripts/lunar_analysis.py
```

检查：
1. 输出表格中新月 vs 满月半周期收益率差异的 p-value
2. 与 Dichev & Janes 论文结论对比（预期新月半周期收益率更高）
3. 各子区间结果一致性
