# 月相周期与 SPY 收益率关系验证 — 调查笔记

## 初版脚本的 2 个 Bug

### Bug #1：阶段分组定义错误（90° 相位偏移）

初版代码将月相周期按"新月→满月"和"满月→新月"二分：

```
初版定义（错误）：
  新月半周期 = 新月→上弦→满月（Phase 0+1）
  满月半周期 = 满月→下弦→新月（Phase 2+3）
```

但 Dichev & Janes (2001) 的定义是**以月相事件为中心**：

```
论文定义（正确）：
  新月半周期 = 以新月为中心 ±7 天 = 下弦→新月→上弦（Phase 3+0）
  满月半周期 = 以满月为中心 ±7 天 = 上弦→满月→下弦（Phase 1+2）
```

两个定义**相差 90°**——初版把"满月前一周"(Phase 1) 归入了新月半周期，把"新月前一周"(Phase 3) 归入了满月半周期。导致分组完全错误，结论无意义。

### Bug #2：样本非独立性导致 p-value 虚假

初版对全部 8100 个交易日都计算 15 天前向收益，每个阶段约 2000 个"样本"。但相邻交易日的 15 天前向收益有 14/15 = 93% 的重叠，严重违反 t 检验的独立同分布 (iid) 假设。

后果：标准误被严重低估 → p-value 虚假偏小（初版 p=0.0012 毫无意义）。

## 修正方案

修正版实现了两种独立的分析方案：

| 方案 | 方法 | 样本特性 |
|------|------|---------|
| 方案 A（事件驱动） | 在每个新月/满月事件日计算 N 天前向收益 | ~400 个独立样本 |
| 方案 B（日收益率） | 每个交易日按距最近月相分组，比较日均收益率 | 最接近论文方法 |

## 修正后的结果

### 方案 A：事件驱动法

| 持仓 | 新月后均值 | 满月后均值 | 差异 | p-value | 年化差异 |
|------|-----------|-----------|------|---------|---------|
| 7 天 | +0.156% | +0.311% | -0.156% | 0.42 | -5.60% |
| 15 天 | +0.399% | +0.737% | -0.338% | 0.21 | -5.67% |

方向与论文**不一致**（满月后反而更高），但统计不显著。

稳定性：4 个子区间中 3 个满月后更高，仅 2020-2025 新月后略高。

### 方案 B：日收益率分组法（论文方法）

**二分法结果**：

| 指标 | 新月附近 | 满月附近 | 差异 |
|------|---------|---------|------|
| 日均收益 | +0.054% | +0.035% | +0.019% |
| 年化 | | | **+4.79%** |
| p-value | | | 0.47 |
| Cohen's d | | | +0.016（微小） |

方向与论文**一致**，年化差异 +4.79% 落在论文报告的 3-5% 区间内。

**四分法结果**：

| 阶段 | 日均收益 | 年化 | 胜率 |
|------|---------|------|------|
| 新月附近 | +0.066% | +16.73% | 54.0% |
| 上弦附近 | -0.001% | -0.20% | 52.6% |
| 满月附近 | +0.047% | +11.85% | 53.9% |
| 下弦附近 | +0.069% | +17.27% | 55.5% |

下弦附近日均收益最高（+17.27% 年化），上弦附近最低（-0.20%）。

**稳定性验证**：

| 时期 | 差异 | 年化 | 方向一致 |
|------|------|------|---------|
| 1993-2000 | +0.061% | +15.47% | 是 |
| 2001-2009 | -0.006% | -1.51% | 否 |
| 2010-2019 | +0.012% | +2.98% | 是 |
| 2020-2025 | +0.011% | +2.83% | 是 |

4 个子区间中 3 个方向一致，但全部统计不显著。2001-2009（911+次贷）方向相反。

## 方案 A 与方案 B 结论相反的原因

方案 A 衡量的是"在新月当天买入，持仓 N 天的收益"——这是一个**交易策略**视角。

方案 B 衡量的是"新月附近的每日市场收益是否高于满月附近"——这是一个**统计规律**视角。

两者不同因为：方案 A 的收益横跨整个持仓期，一笔 15 天的交易可能从新月半周期延伸到满月半周期。方案 B 的每日收益只反映当天的市场状态。

## 结论

1. **方向一致**：用论文方法（方案 B），新月附近日均收益确实高于满月附近，年化差异 +4.79%，与 Dichev & Janes 报告的 3-5% 吻合
2. **统计不显著**：p=0.47，SPY 单标的 32 年数据不足以拒绝零假设。论文用 DJIA 72 年 + 多国多指数，样本量大得多
3. **效应极小**：Cohen's d = 0.016，即使效应真实存在，也属于微小效应
4. **不稳定**：2001-2009 区间方向相反，信号在危机期失效
5. **无独立交易价值**：年化 +4.79% 扣除交易成本后 alpha 极小
6. **可作辅助因子**：与 RSI/Breadth/VIX 等信号组合时，可提供微弱的方向性偏好

## 月相特征作为 XGBoost 输入的评估

### 与现有信号横向对比

| 信号 | 成本优势 | 效应量 | 信号频率 | 维度 |
|------|---------|--------|---------|------|
| VIX > 30 | +9.71% | 强 | 61 次/3年 | 隐含波动率 |
| BreadthC3 < 20 | +9.77% | 强 | 37 次/3年 | 市场宽度 |
| NDay5 | +5.52% | 中 | 162 次/3年 | 价格动量 |
| RSI v2 | +4.00% | 中 | 48 次/3年 | 超买超卖 |
| EMA 过滤 | +3.36% | 中 | 335 次/3年 | 趋势 |
| Breadth 背离 | +2.56% | 弱 | 4 次/3年 | 背离 |
| SafeHaven | +1.03% | 极弱 | 188 次/3年 | 避险情绪 |
| **月相（日收益率）** | — | **Cohen's d=0.016** | 每天 | **天文周期** |

月相信号强度在所有现有信号中**排名末尾**，弱于 SafeHaven（+1.03%）。

### 评估结论：值得加入，但预期要低

**加入理由**：

1. **与所有现有特征正交**——RSI/Breadth/VIX/EMA 全部派生自价格/波动率/市场宽度，彼此有相关性。月相是唯一来自非价格维度的信号，信息零重叠
2. **XGBoost 擅长弱特征**——boosting 机制能从弱特征中提取边际信息，尤其与强特征交叉时（如"VIX > 30 且恰好在新月附近"）
3. **特征工程成本极低**——月相是确定性天文计算，不需要外部数据、不滞后、不存在前视偏差

**推荐的特征编码**：

```python
# 连续特征
'lunar_phase':        0-1 归一化月相角度（0=新月，0.5=满月）
'days_to_new_moon':   距最近新月天数（-7 到 +7）
'days_to_full_moon':  距最近满月天数（-7 到 +7）

# 离散特征
'lunar_quarter':      0/1/2/3（新月/上弦/满月/下弦附近）
'is_near_new_moon':   布尔（距新月 ≤3 天）
```

**注意事项**：

- 不要期望它显著提升模型——它的贡献量级可能在第五、第六位
- 必须做样本外验证——Merriman 的 144 种 Sun-Moon 组合有严重的过拟合风险
- 我们只用最基础的月相特征（新月/满月距离），不用星座组合，避免数据挖掘

**优先级**：在特征收集阶段加入是合理的（成本低、正交性高），但重要性远低于 VIX/Breadth/NDay5 核心特征。

## Merriman 对 Solar/Lunar 信号的实际使用方式

### 信号的时间尺度定位

Merriman 将信号体系按时间尺度严格分层：

| 层级 | 信号来源 | 周期 | 用途 |
|------|---------|------|------|
| **微周期** | Solar/Lunar 日月组合评分 | **1-7 天**（平均 4 天） | 日内/Swing 交易 |
| 短周期 | CRD（行星集群中点） | 数天到数周 | 波段交易 |
| 中周期 | 木星相位 | 数周到数月 | 中期波段 |
| 长周期 | 土星/天王星/海王星/冥王星相位 | 数年 | 投资决策 |

**月相/Solar-Lunar 信号属于最底层的微周期——找的是小周期的短线反转点，不是大周期买点。**

### Merriman 的具体操作流程

```
1. 查看 WV 表：今天的太阳-月亮组合，WV 是否 ≥ 138？
   ├── 否 → 今天不是高概率反转日，不操作
   └── 是 → 进入步骤 2

2. 观察当天价格行为：
   ├── 价格突破前一天高点 → 可能形成"孤立低点"→ 看多
   └── 价格跌破前一天低点 → 可能形成"孤立高点"→ 看空

3. 次日确认：
   ├── 确认反转方向 → 入场
   └── 未确认 → 放弃

4. 持仓 1-7 天，目标 3-4% 利润
```

**关键点**：Merriman 不会仅靠月相做交易。Solar/Lunar 只是一个"今天是否值得关注"的过滤器。真正的买卖决策需要周期阶段判断 + 技术确认。

### 对我们 DCA 系统的适用性

我们的 DCA 是中长期定投策略（持仓数月到数年），月相信号是 1-7 天微周期。时间尺度不匹配。

但在 XGBoost 场景下，月相特征可以回答一个微观问题：**"在已经决定本周买入的前提下，周内哪天入场略微更优？"** ——这是执行层优化，不是信号层决策。

### 星级评定标准

| 星级 | 条件 | 历史准确率 |
|------|------|-----------|
| 3 星 | 4 天内至少 2 个 Level 1 相位 | 80%+（3 交易日容差内） |
| 2 星 | 附近至少 1 个 Level 1 相位 | 与半周期或完整主周期相关 |
| 1 星 | 仅 Level 2/3 相位 | 与次级周期相关 |

**重要补充**：星级指示概率而非确定性。如果主周期尚未到期，即使 3 星 CRD 也不会产生主周期反转。

### 集群计算方法（完全可复现）

```
1. 列出所有 geocosmic 事件（相位、逆行/顺行、入座）
2. 如果相邻两个事件间隔 ≤ 6 个日历日 → 归入同一集群
3. CRD = 集群首尾事件的时间中点
4. 容差窗口 = CRD 前后 ±3 个交易日
```

### 独立计算 CRD 的可行性评估

**能做到的（~80% 复现度）**：

1. 用 `pyswisseph` 计算所有行星相位、逆行/顺行、入座——精度达弧秒级
2. 用上面 12 个已确认 Level 1 相位作为核心信号集
3. 用 6 天规则做集群，取中点
4. 用集群内 Level 1 相位数量作为简易权重（2 个以上 = 高优先级）
5. 对 SPY 回测，自己跑出相关性数据

**做不到的（需要 Vol.3）**：

- 完整的 Level 1/2/3 排名（数百种相位组合）
- 渐盈 vs 渐亏的区分（Merriman 说差异可能"截然不同"）
- 市场特异性（哪些相位对 SPY vs 黄金 vs 大豆更敏感）

**实际影响**：核心 Level 1 相位已知 12 个且是最强的，缺失的 Level 2/3 相位对信号质量的影响是边际递减的。Vol.3 售价 $75，如果想做完整复现，是值得的投资。

## 教训

- 复现学术论文时，必须严格对齐定义（"新月半周期"的含义差 90° 就会得出相反结论）
- 前向 N 天收益产生的样本重叠会严重扭曲 p-value，应使用事件驱动（独立样本）或日收益率（最小粒度）
- 结论与方法论强相关：事件驱动法和日收益率法可以给出相反的方向
- 弱信号（Cohen's d < 0.02）作为独立策略毫无价值，但在 ML 框架中可作为正交特征贡献边际信息
- Merriman 方法论中约 80% 的内容是公开可复现的，私有部分（Level 2/3 排名、渐盈/渐亏区分）是锦上添花而非必需
