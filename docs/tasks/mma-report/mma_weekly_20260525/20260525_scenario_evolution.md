### 6.6 周报信任度分层（实盘是裁判，周报是框架）

**核心原则**：实盘 > 周报。周报算得再精也不可能 100% 命中走势；它的价值是给出**结构骨架**（位置、规则、止损），而不是**预测走势**。当周报与实盘冲突，**永远以实盘为准**。

| 周报内容 | 信任度 | 用法 |
|---|---|---|
| **关键价位**（TIP / 周支撑 / 周阻力 / 硬止损）| ⭐⭐⭐⭐⭐ | 当成铁律，市场常围绕其反应 |
| **bullish/bearish trigger 规则**（trade above + close back below 等）| ⭐⭐⭐⭐ | 当成规则，触发就承认信号 |
| **方向 bias**（bearish bias / rally elevated）| ⭐⭐⭐ | 当成倾向，实盘可推翻 |
| **CRD / Venus-Saturn 解读**（"已对应 5/19/20"等）| ⭐⭐ | 仅作参考；实盘当天有动作就以实盘为准 |
| **价格目标 + 时间窗**（7650-7700 in time）| ⭐⭐ | 长期目标，时间不绑定 |
