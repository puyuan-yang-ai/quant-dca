## 3. 策略 2：期权增强（推荐叠加，配合期货使用）

### 3.1 主战法：Bull Call Debit Spread on SPX / SPY（7/17 到期）

**为什么是 Debit Spread**：
- VIX 16.70 = 低 IV → 期权"便宜"，**买入策略性价比高**
- Debit Spread 限定最大亏损 = 净付权利金，与期货多单不冲突
- 到期日 7/17 完美对齐 PT 主候选窗

**推荐配置**（基于 SPX 现货约 7491×0.997 ≈ 7470）：

| 参数 | 数值 |
|---|---|
| 标的 | SPX（或 SPY，1/10 比例）|
| 策略 | Long Call Debit Spread |
| 到期日 | **2026-07-17（周五）** |
| 买入 Call 行权价 | **7500**（ATM）|
| 卖出 Call 行权价 | **7700**（PT base 目标）|
| 价差宽度 | 200 点 |
| 预估净 Debit | ~70-90 点（视 IV）|
| 最大盈利 | 200 - 90 = **110 点** |
| 最大亏损 | 90 点 |
| **盈亏比** | **~1:1.2**（保守）/ 1:2 （IV 进一步压缩）|
| 触发盈利目标 | ES 收 ≥ 7700 |
| 触发最大亏损 | ES 7/17 收 ≤ 7500 |

**仓位建议**：占总风险预算 **3-5%**（与期货多单叠加使用）

### 3.2 备选战法：Call Ratio Spread（动能型，B 剧本对冲）

如果 5/26 美股开盘确认 A2/B 路径（突破真实）：

| 参数 | 数值 |
|---|---|
| 到期日 | **2026-06-26（B 剧本 PT 候选窗）** |
| 买入 1 张 Call | 7550 |
| 卖出 2 张 Call | 7750 |
| 净 Debit / Credit | 接近零成本 |
| 最大盈利 | 在 7750 收盘（净赚 200 点）|
| 最大亏损 | ES > 7950（裸 short call 风险）|
| 风险点 | bull case 失控时被双倍 short call 套住 |

**仅在你有期货多单做"对冲"时使用**（裸 ratio spread 不建议）

### 3.3 不推荐的期权策略

- ❌ **裸 Put**（趋势完好，时间价值损耗大）
