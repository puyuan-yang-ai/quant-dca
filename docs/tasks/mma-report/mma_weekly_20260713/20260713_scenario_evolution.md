## 5. 所有可能的走势剧本

### 剧本 A：CRD 冲顶后反转（主剧本）

**核心逻辑**：ES 在 7/10 创新高 7,628.8，三角形突破动能释放。Jupiter △ Neptune & ⚹ Uranus（7/20-21）的"非理性繁荣"推动最后一波加速上涨，在 July 17-20 CRD 窗口形成 Primary cycle crest，随后展开 2-5 周回调。

**时间线**：
1. **7/13（周一）**：Venus □ Uranus 开启 CRD 集群，波动加大但仍偏多
2. **7/14-16**：Uranus ⚹ Neptune（7/15），ES 继续上攻，目标 7,676–7,700（周阻力）
3. **7/17-18**：Uranus △ Pluto，CRD 集群高潮，ES 可能触及 7,750–7,800 形成 Primary crest
4. **7/21 起**：Mercury 仍逆行，反转开始，第一波下跌
5. **7/23**：Mercury 顺行，确认下跌趋势
6. **7/24-27 CRD**：回调加速或形成反弹高点后继续下跌
7. **7/29-30**：Solar-Lunar 146.1* 极强低位信号 → 回调中继低点
8. **8/7-10 CRD**：Primary cycle trough 候选（第 19 周）

**关键点位**：
- Primary crest：ES 7,750–7,800（DJIA 55,000）
- 回调目标：ES 7,200–7,400（DJIA 51,000–52,000）
- 止损确认：ES 收盘跌破 7,395

### 剧本 B：提前见顶 + 深度回调

**核心逻辑**：7/7 DJIA 的 53,289 就是 Primary cycle crest（Neptune Rx 当天）。ES 虽然 7/10 创了新高，但这是 Mercury 逆行期间的假突破。三指数熊市背离 + NQ Lorusso 5-pointer 指向更深回调。

**时间线**：
1. **7/13-14**：Solar-Lunar Low 122.5* → 本周即见低位反转触发
2. **7/15-16**：Solar-Lunar High 125.9* → 弱反弹高点
3. **7/17-20 CRD**：不是冲顶而是确认下跌，加速回调
4. **7/23**：Mercury 顺行确认跌势
5. **7/24-27 CRD**：回调继续
6. **7/29-30**：Solar-Lunar 146.1* → 可能形成 Primary trough

**关键点位**：
- Primary crest：已在 7/7 形成（DJIA 53,289 / ES ~7,601）
- 回调目标：ES 7,200–7,350（DJIA 51,000–51,500）
- 极端回调：ES 跌破 7,200 → NQ Lorusso 5-pointer 确认

**触发条件**：ES 本周无法突破 7,630 或快速跌回 7,540 以下

### 剧本 C：延迟见顶至 Mercury 顺行

**核心逻辑**：Mercury 逆行压制真正的突破。市场在 7/13-20 横盘震荡，Mercury 7/23 顺行后才迎来最终冲高，在 July 24-27 CRD 形成 Primary crest。

5. **7/28 起**：反转下跌
6. **7/29-30**：Solar-Lunar 146.1* → 快速回调

**关键点位**：
- Primary crest：ES 7,800–7,950（DJIA 55,000–56,000）
- 回调目标：ES 7,350–7,500
- 优势：更充分的上涨空间，更接近 DJIA 55,000 目标

**触发条件**：本周 ES 未能突破 7,700 但也未跌破 7,516

**关键点位**：
- Primary crest：ES 7,950–8,050

**触发条件**：ES 连续两天收在 7,700 以上，且 NQ 同步创新高
