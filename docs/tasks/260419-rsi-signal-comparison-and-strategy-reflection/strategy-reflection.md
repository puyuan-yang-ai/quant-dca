**结论：RSI v2 对 Baseline 的提升极其微小，两者本质上没有显著区别。**

花了大量时间设计、调试、优化 RSI v2 指标（三事件信号系统、背离检测、信号分级），最终只获得了 Sharpe 从 0.09 到 0.11 的提升。这不是 RSI 指标的问题——是优化方向的问题。

### 1.2 为什么信号优化的天花板这么低

```
策略收益 = 信号质量 × 执行效率 × 风控能力

目前状态：
  信号质量：已优化（RSI v2，效果 +22%）      ← 做了这个
  执行效率：未优化（固定 1 股）              ← 没做
  风控能力：不存在（不止盈、不止损、不减仓）   ← 没做

类比：
  你花了很多时间选最好的弓箭（信号），
  但射出的力度是固定的（执行），
  而且射完不回收箭（没有风控）。
  弓箭再好，这两个短板不补，整体效果提升有限。
```

## 2. 真正拖垮 Sharpe 的是什么

### 2.1 SOXL 3 倍杠杆的"诅咒"

SOXL 是 3 倍杠杆 ETF，这意味着：

| 特性 | 影响 |
|------|------|
| 日波动 = 基础标的 × 3 | Sharpe 的分母（波动率）被放大 3 倍 |
| 杠杆衰减 | 横盘震荡时持续损耗价值 |
| 极端回撤 | 2020 COVID：-80%，2022 熊市：-80%+ |

```
Sharpe = (收益 - 无风险利率) / 波动率

SOXL 波动率 ≈ SMH 波动率 × 3
→ 即使收益也是 3 倍，Sharpe 也不会提升
→ 实际上由于杠杆衰减，收益不到 3 倍，Sharpe 反而更低
```

**所有策略在 SOXL 上的 Sharpe 都很低，不是策略的问题，是标的的特性。**

### 2.2 没有止盈 = 坐电梯

当前所有策略用的是 `NoTakeProfit`——买了就永远持有，不卖。这意味着：

```
2022 年 1 月：持仓浮盈 +200%
2022 年 12 月：持仓浮亏 -80%

一整年的利润全部回吐，Sharpe 被这个巨幅回撤拖入深渊。
```

**如果在 +200% 时卖掉一部分锁住利润，即使后来跌 80%，总损失也会小很多。这就是止盈的价值。**

### 2.3 熊市中继续买入 = 越亏越买

DCA 的理念是"不管涨跌都定期买入"。但在持续下跌的熊市中：

```
每天买 1 股 × 250 个交易日 × 价格一路下跌
= 持续往正在下沉的船里注水
```

**缺少"熊市暂停"或"减仓"的机制，是回撤巨大的直接原因。**

## 3. 量化行业的基准参考

### 3.1 标准基准标的

| 标的 | 代码 | 特点 | 长期 Sharpe |
|------|------|------|-----------|
| **标普 500** | SPY | 行业标准基准，最广泛使用 | 0.4 - 0.6 |
| 纳斯达克 100 | QQQ | 科技股集中，波动稍大 | 0.4 - 0.5 |
| 半导体 ETF | SMH | 你项目的基准标的 | 0.3 - 0.5 |
| 3 倍杠杆半导体 | SOXL | 你目前的交易标的 | 0.05 - 0.15 |

**SPY 是量化行业最通用的基准。** 如果你的策略在 SPY 上跑出 Sharpe > 0.5，就说明"策略本身有价值"。如果策略在 SOXL 上 Sharpe 只有 0.1，可能是标的的问题而不是策略的问题。

### 3.2 Sharpe 的实战分级

| Sharpe 范围 | 评价 | 说明 |
|------------|------|------|
| < 0.5 | 不具备实战价值 | 风险调整后不如无脑持有 SPY |
| 0.5 - 1.0 | 及格 | 可以考虑小仓位实盘 |
| 1.0 - 1.5 | 良好 | 多数量化基金的目标线 |
| 1.5 - 2.0 | 优秀 | 头部量化基金水平 |
| > 2.0 | 顶尖 | 极少数策略能长期维持 |

**你目前 SOXL 上的 Sharpe 0.11 处于"不具备实战价值"区间。但这不代表策略思路有问题——可能只是标的和风控的问题。**

### 3.3 怎么判断"是策略差还是标的差"

```
同一个策略，分别在 SPY 和 SOXL 上跑：
  SPY 上 Sharpe = 0.8  → 说明策略本身不错，SOXL 的波动拖累了结果
  SPY 上 Sharpe = 0.2  → 说明策略本身有问题，换标的也救不了

目前还没在 SPY 上测试过，这是一个值得做的实验。
```

## 7. 标准化执行下的 Sharpe：相对排名工具，不是实战水平指标

### 7.1 一个容易犯的错误

看到标准化执行下 Sharpe = 0.11，第一反应是"这策略太差了，业界标准是 1.0 以上"。

**这个比较是错误的。** 因为两个数字的含义完全不同：

```
业界 Sharpe > 1.0 = 完整策略（信号 + 执行 + 风控 + 资金管理）的最终成绩
你的 Sharpe 0.11 = 裸信号（信号 + 最简执行 + 零风控）的测试成绩

就像拿引擎台架测试的马力数据，去跟正式赛车的圈速比 —— 不是一个维度的东西。
```

### 7.2 标准化执行的设计目的

标准化执行（买 1 股、不限价、不止盈）是**故意剥掉所有执行/风控能力**的：

| 被剥掉的能力 | 对 Sharpe 的影响 | 为什么要剥掉 |
|-------------|----------------|------------|
| 仓位管理 | 大幅影响 | 不同信号配不同仓位，会混入执行层的影响 |
| 止盈/止损 | 极大影响 | 止盈能锁住利润、降低回撤，直接拉高 Sharpe |
| 限价单/分批买入 | 中等影响 | 成交价格差异会干扰信号质量的比较 |
| 趋势过滤/风控 | 极大影响 | 风控能减少熊市亏损，但那是风控的功劳不是信号的 |

**剥掉这些后，剩下的就是纯粹的信号择时能力。** Sharpe 低是必然的——因为所有能提升 Sharpe 的"武器"都被拿走了。

### 7.3 正确的用法：看相对排名

标准化执行下的 Sharpe 唯一有意义的用法是**横向比较**：

```
✓ 正确：RSI (0.1610) > NDayConfirm (0.1464) > EMA (0.1064)
         → RSI 信号择时能力最好

✗ 错误：RSI (0.1610) < 业界标准 (1.0)
         → "RSI 策略不行"（这个结论是无效的）
```

**类比：赛车选引擎**

```
选引擎阶段（现在在做的）：
  把所有引擎装在同一辆测试车上（标准化车架 = 标准化执行层）
  跑圈速：引擎 A = 2:15, 引擎 B = 2:20, 引擎 C = 2:30
  测试车跑 2 分 15 秒 —— 很慢？对，但这不是正式比赛。
  你要看的是 A 比 B 快 5 秒，A 是最好的引擎。

装正式赛车阶段（后面要做的）：
  选定引擎 A，装上空气动力学套件（止盈）、底盘（仓位管理）、轮胎（风控）
  正式跑圈速：1:30
  现在的圈速才是跟 F1 标准比较的 —— 这时候看绝对成绩才有意义。
```

### 7.4 什么时候该看绝对 Sharpe

```
阶段 1（信号筛选）：
  执行层 = 标准化（固定）
  看 Sharpe 的相对排名 → 选出最好的信号
  不关心绝对值

阶段 2（执行层优化）：
  信号层 = 锁定最好的（固定）
  执行层 = 网格搜索最优参数
  看 Sharpe 的绝对值是否开始接近 0.5

阶段 3（完整策略）：
  信号 + 执行 + 风控 全部到位
  看 Sharpe 的绝对值 → 这时候跟业界标准比才有意义
  目标：Sharpe > 0.5（及格线），> 1.0（良好）
```

**你现在处于阶段 1。** 在这个阶段纠结"Sharpe 0.11 太低"是没有意义的，就像在引擎测试阶段纠结"测试车跑不过 F1"一样。

### 7.5 如果换成标普数据会怎样

即使把 SOXL 换成 SPY（标普 500），用标准化执行跑：

- Sharpe 会稍高（因为 SPY 波动小，分母变小）
- 但依然不会达到"实战水平"（因为没有止盈和风控）
- **排名顺序可能跟 SOXL 上的一致**（如果信号逻辑是通用的）

所以换标的的主要价值不是"让数字好看"，而是**验证信号逻辑是否通用**——如果一个信号在 SOXL 和 SPY 上排名都是第一，说明它的择时能力是稳定的、不依赖特定标的的。

## 8. 核心教训

| 教训 | 说明 |
|------|------|
| 信号优化的天花板很低 | 在 3 倍杠杆 ETF 上，信号再好，没有风控也是白搭 |
| 标准化 Sharpe ≠ 实战 Sharpe | 标准化执行下的 Sharpe 是排名工具，不是水平指标 |
| 现阶段看相对排名 | 不跟业界 Sharpe 1.0 比，只看"谁的信号更好" |
| 绝对 Sharpe 在阶段 3 才有意义 | 信号 + 执行 + 风控全到位后，才跟业界标准比 |
| 标的选择影响巨大 | SOXL 的高波动从根本上限制了 Sharpe |
| 止盈比信号重要 | 赚到了锁不住 = 没赚到 |
| 先做影响最大的事 | 止盈 > 风控 > 仓位 > 信号，按这个顺序优化 |
| 没有圣杯 | 每个策略都有适用场景和局限性 |
