## 他的核心错误在哪里

他的表格：

| | Vertical (2W/2W) | Diagonal (2W/1W) |

平仓价值差 = $9.50 − $8.30 = **$1.20**

这意味着他认为 Vertical 的短腿（610C，还剩 1W DTE，**此时 ATM**）回购成本 = **$1.20**。

**这是严重低估。** 一个 ATM 周度期权（7 DTE）不可能只值 $1.20。

## 正确的 ATM 周度 Call 定价

用 Black-Scholes 近似（SPY 级别标的，IV≈13%）：

ATM Call ≈ 0.4 × S × σ × √T = 0.4 × 610 × 0.13 × √(7/365) ≈ **$4.40**

即使保守用 $3.50-4.00，也远不是 $1.20。

他犯的错：**把入场时的 610C 1W 价格（SPY=600 时 $10 OTM = $1.20）直接当成了出场时的 610C 价格（SPY=610 时 ATM）。** 但 SPY 涨了 $10 之后，这条 610C 从 $10 OTM 变成了 ATM——delta 从 ~0.15 飙升到 ~0.50，时间价值从 $1.20 膨胀到 $4+。
