# ML 特征 V2 升级

## 需求

在 v1（SL7 Proximity + 11 个特征）基础上，通过改进特征集提升模型表现，重点解决 v1 已知弱点。

## 目标

1. 新增 4 个特征，替换 1 个，从 11 → 14 个
2. 重点解决 v1 的"下跌初期假阳性"问题
3. 引入"方向/动量"维度（v1 只有"位置/水平"维度）
4. 不改变标注方法（仍用 SL7 Proximity, K=3）

## v1 基准指标

```
AUC-ROC: 0.599
ML 放行信号数: 82/276
平均 20D 收益: +3.61%（baseline +2.16%）
```

## v1 已知弱点

**下跌初期假阳性**：市场刚开始跌时（如 2022年9月初），"连续跌N天 + RSI 超卖"的特征组合和真正底部很像，模型无法区分"刚开始跌"和"已经跌够了"。

## 成功标准

- AUC-ROC > 0.599（超过 v1）
- 或 ML 过滤后平均 20D 收益 > +3.61%
- 如果都不如 v1，则不切换，保留 v1 为激活版本
