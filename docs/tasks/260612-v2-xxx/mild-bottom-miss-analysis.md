# 温和底部误杀问题 — 根因分析与改进方案

## 问题现象

2022-12-28 和 2023-03-13 两个明显的黄金坑被 ML 模型 SKIP 了。
肉眼从图表可以看到：RSI 有 B 信号、breadth 在低位区间，但模型只给出 0.32 和 0.44 的概率。

## 根因调查

### 发现 1：时间错位（信号差 1 天）

```
NDay5 触发: 2022-12-28    RSI B 触发: 2022-12-29 (差1天)
NDay5 触发: 2023-03-13    RSI B 触发: 2023-03-14 (差1天)
```

当前 `sig_rsi` 只看"当天有没有 B 信号"→ 差一天就完全看不到。

### 发现 2：sig_rsi 在 SL7 标注下实际是显著的

```
sig_rsi 在正标签触发率: 28.5%
sig_rsi 在负标签触发率: 19.9%
差异: +8.6pp (p=0.0002 显著)
```

V1 移除 sig_rsi 时依据的是 Fixed Horizon 标注下的 p=0.45。换成 SL7 标注后它变显著了。

### 发现 3：加回 sig_rsi 可以提升 AUC

```
V2:           AUC = 0.618
V2 + sig_rsi: AUC = 0.640 (+0.022)
```

但对具体被误杀的信号帮助有限（因为那几天 sig_rsi=0，差了一天）。

### 发现 4：根本原因是特征空间中温和底部无区分度

```
训练集中"类似温和回调"的样本: 78 个
  正标签率: 37% (与全局 40% 几乎一样)
```

正标签和负标签的 drawdown 分布：
- 正标签 P50 = -7.2%
- 负标签 P50 = -7.0%
- 几乎无差异

**模型在"温和回调"区域没有统计信号可以利用。**

---

## 关键指标说明

### "避免误杀"对应什么指标？

- **AUC-ROC**: 整体区分能力（正负分得开）
- **Recall（召回率）**: 正标签中有多少被模型放行 → **这才是"避免误杀"的指标**
- 当前 Recall = 39%，意味着 61% 的好入场被误杀了

目标：**提高 Recall 的同时不让 Precision 大幅下降。**

---

## 改进方案

### 方案 1：特征时间窗口化（"近N天"代替"当天"）

**核心思想**：人看图时看的是"最近几天的状态"，不是精确到某一天。

具体做法：
- `rsi_b_recent_3d`：最近 3 天内是否有 RSI B 信号（替代 sig_rsi 的"当天"逻辑）
- `breadth_min_3d`：最近 3 天 breadth 的最低值（捕获"最近几天到过低位"）
- `rsi_min_3d`：最近 3 天 RSI 的最低值（即使今天 RSI=39，前天可能到过 28）

**理由**：
- 信号系统之间天然有 1-2 天的错位
- 人脑看"区域"不看"点"
- 3 天窗口能容忍错位，不至于丢失时效性

### 方案 2：增加温和底部样本（调整 SL 参数）

**当前 SL7 (N=7)**: 前后各 7 天的局部最低 → 平均每年 10.8 个底部

**问题**：SL7 能覆盖"温和回调底部"吗？
- 验证结果：2022-12-28 和 2023-03-13 都恰好是 SL7 → GT 没问题
- 真正的问题不是样本不够，而是这些温和底部的特征和非底太像

**可能的改进**：
- 加入 SL5 (N=5) 作为补充：更灵敏，能捕获更多小底部
- 多尺度标注：`label = 1 if near SL5 OR near SL7`
- 这能增加正标签数量（从 40% 提升到 ~55%），让模型在温和底部有更多正样本学习

### 方案 3：特征相对化

**当前问题**：drawdown = -7% 在不同波动率环境下含义不同
- 2020 年 VIX=80 时，-7% 是小波动
- 2023 年 VIX=20 时，-7% 已经是显著回调

**改进**：
- `drawdown_relative = drawdown_from_high / ATR(20)`
- 或 `drawdown_zscore = drawdown / rolling_std(60)`
- 这让模型理解"-7% 在当前环境下算不算大回撤"

## 顶级量化机构的做法

从 Two Sigma / Jane Street 的角度看这个问题：

### 1. 永远不用单点特征，用统计量窗口

机构做法是对每个原始信号计算滚动窗口的多个统计量：
```
对 RSI 这一个指标：
  - rsi_current (当前值)
  - rsi_min_5d (5天最低)
  - rsi_percentile_20d (20天百分位)
  - rsi_slope_5d (5天斜率)
  - rsi_cross_below_30_in_5d (5天内是否跌破30)
```

这比我们的"一个 rsi_14 值"信息量大 5 倍。

### 2. 信号共振计数（Confluence Score）

不问"某个信号是否触发"，而是数"有多少个信号同时处于活跃状态"：
```
confluence = sum([
    rsi_below_30_in_3d,
    breadth_below_20_in_3d,
    vix_elevated,
    nday5_active,
    price_at_support,
])
```

当 confluence >= 3 时买入。这正是人眼看图时做的事——"多个信号共振 = 底部确认"。

### 3. 时间衰减特征

信号触发后不是 0/1，而是随时间衰减：
```
signal_strength = exp(-distance_days / decay_half_life)
```

RSI B 触发在 3 天前 → 强度 0.7
RSI B 触发在 10 天前 → 强度 0.2

这完美解决"差 1 天"的问题——不再是非此即彼。

### 4. 接受模型的能力边界

机构的共识：**没有模型能抓住所有底部。** 追求 100% recall 会导致大量假阳性。

正确的框架是：
- 高确信度区域 → 全仓位
- 中等确信度 → 半仓位
- 低确信度 → 跳过

对 DCA 场景可以这样实现：
```
p >= 0.5: 正常加仓
0.3 <= p < 0.5: 减半加仓（不完全跳过）
p < 0.3: 跳过
```

这样 2022-12-28 (p=0.32) 不会完全被错过——只是仓位减半。

## 推荐实施优先级

| 优先级 | 方案 | 预期效果 | 复杂度 |
|--------|------|----------|--------|
| **高** | 特征窗口化 (3天) | 解决信号错位 + 更贴合人脑观察 | 低 |
| **高** | 信号共振计数 | 直接编码"多信号共振=底" | 低 |
| 中 | 分级仓位 (p=0.3/0.5 双阈值) | 减少完全误杀 | 极低 |
| 中 | 多尺度 SL 标注 (SL5+SL7) | 增加温和底部样本量 | 中 |
| 低 | 特征相对化 (drawdown/ATR) | 跨波动率环境一致性 | 低 |
| 低 | 时间衰减特征 | 精细化信号强度 | 中 |
