# V2 消融实验 — 发现与踩坑记录

## 踩坑：V2 性能为什么下降了？

### 现象

```
V1 (11特征): AUC=0.599  ret=+3.61%  n=82
V2 (14特征): AUC=0.588  ret=+3.00%  n=91
```

V2 加了 4 个新特征，效果反而更差了。

### 根因

**不是新特征的问题，而是"替换"和"移除"造成的伤害。**

V2 同时做了两件有害的事：
1. 移除了 `sig_vix`（VIX>30 布尔哨兵）
2. 将 `breadth_c2` 替换为 `breadth_c3`

这两个变更导致 AUC 从 0.599 暴跌到 0.547。新增的 4 个特征虽然有正面贡献（从 0.547 拉回到 0.588），但无法完全弥补损失。

### 消融实验数据

| 配置 | AUC-ROC | 20D收益 | 信号数 |
|------|---------|---------|--------|
| V1 完整 (c2+sig_vix, 11特征) | **0.599** | **+3.61%** | 82 |
| V1结构用c3 (无sig_vix, 10特征) | 0.547 | +2.80% | 83 |
| V2 完整 (14特征) | 0.588 | +3.00% | 91 |

**结论：移除 + 替换 造成了 -0.052 AUC 的伤害，新增特征只拉回了 +0.041。**

### 逐个新增特征的贡献

在"共同9特征"基础上逐个添加：

| 新增特征 | AUC | 收益 | 评价 |
|----------|-----|------|------|
| +breadth_spread (c5-c1) | 0.580 | +3.30% | 最强，有明确正面贡献 |
| +breadth_delta_3d | 0.562 | +3.21% | 不错 |
| +drawdown_from_high | 0.553 | +2.80% | 一般 |
| +rsi_minus_ma | 0.547 | +1.99% | 效果不佳，可能引入噪声 |
| +breadth_c3 | 0.547 | +2.80% | 不如保留 c2 |

## 核心教训

### 1. "只加不减"原则

> 在现有模型表现良好时，新版本应该只添加新特征，不移除已有特征。
> 每次只改一个变量，才能确定效果归因。

V2 同时做了"加4个"+"减1个"+"换1个"= 6 个变量变更，无法归因。

### 2. 统计显著性 ≠ 可以安全移除

`sig_vix` 在 V1 中单独移除时 AUC 不变（因为 `vix_regime` 兜底）。
但和 c2→c3 替换组合时，两者的联合效应导致大幅下降。
**特征之间有交互作用，不能根据单变量检验决定移除。**

### 3. 新特征确实有价值

消融测试证明 `breadth_spread` 和 `breadth_delta_3d` 有正面贡献。
问题不在于新特征不好，而在于不该同时做"移除+替换"。

---

## 正确的 V2b 方案

**保留 V1 全部 11 个特征 + 只新增表现最好的特征：**

```
V1 的 11 个特征（全保留）
  + breadth_spread (c5-c1)      ← 消融中表现最强
  + breadth_delta_3d            ← 消融中表现第二
  = 13 个特征
```

不加的：
- `rsi_minus_ma`：消融中收益反而下降（+1.99% < baseline 3.61%）
- `drawdown_from_high`：消融中表现一般
- `breadth_c3`：不替换 c2，而是和 c2 并存（如果想加可以后续再测）
