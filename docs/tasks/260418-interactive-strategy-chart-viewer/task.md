# 交互式策略图表查看器

## 背景

quant-dca 项目当前使用 Matplotlib 生成静态 PNG 图表（`src/chart.py`），仅展示收益率曲线对比，存在以下局限：

- 无 K 线图，无法直观看到价格走势与策略动作的关系
- 不支持缩放/平移，无法聚焦到特定时间段细看
- 无十字光标，无法精确读取价格和日期
- 无法在图上标注策略的买入点位、档位成交、止盈触发等信号
- 不支持切换时间周期

这导致策略开发者难以直观判断：策略的入场点位是否精准、止盈时机是否合理、各档位的成交分布是否符合预期。

## 需求目标

从"静态画图"升级到"交互式策略研究界面"，具备类似看盘软件的基本能力：

1. **K 线图展示** — 显示 SOXL 的 OHLC K 线
2. **缩放与平移** — 可自由聚焦到任意时间段，Y 轴自动跟随
3. **十字光标** — 鼠标悬停时精确显示价格/日期
4. **策略信号标注** — 在 K 线上叠加显示 DCA 买入点、档位成交、止盈触发等标记
5. **技术指标叠加** — 可叠加 EMA、偏离度等回测引擎已有的指标
6. **多面板布局** — 价格主图 + 指标副图（如成交量、偏离度）

## 不在本次范围

- 不需要实时数据推送或实盘看盘功能
- 不需要多页面仪表盘或参数调优 UI
- 不需要前后端分离的 Web 应用架构
- 保留现有 Matplotlib 静态图表功能不变，交互式图表为增量添加
