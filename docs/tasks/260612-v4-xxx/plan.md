# V4 实施方案

## 优先级1：连续趋势评分 + 趋势自适应入场

### 1.1 连续趋势评分 (trend_score)

双维度合成，判断当前是牛市/熊市及强度：

```python
# 维度1: 价格位置 — 当前价格相对 MA200 的偏离
price_vs_ma200 = (price / MA200 - 1)

# 维度2: 趋势结构 — MA50 vs MA200 的金叉/死叉几何
ma50_vs_ma200 = (MA50 / MA200 - 1)

# 合成原始值 (等权)
trend_raw = 0.5 * price_vs_ma200 + 0.5 * ma50_vs_ma200

# 归一化: 滚动252天 percentile rank，输出 0~1
trend_score = rolling_percentile_rank(trend_raw, window=252)
```

**为什么两个维度：**
- price vs MA200 单独看会在均线附近抖动（如 2022-12-28 附近）
- MA50 vs MA200 变化慢、很稳，代表"趋势骨架"
- 两者结合：价格刚跌破 MA200 但 MA50 还在上方 → 大概率牛市回调（应该买）

**为什么用 percentile rank 而非 z-score：**
- z-score 假设正态分布，但极端行情（2008 跌 -40%、2020-03 跌 -30%）会拉偏均值和标准差，导致之后很长一段时间评分不稳定
- percentile rank 天然归一到 0~1，不怕离群值，分布永远均匀
- 可解释性强："trend_score = 0.85"意味着"当前趋势强度排在过去一年前15%"
- 对 XGBoost 友好 — 树模型本身就是做分位切割的

**窗口 252 天（一年交易日）：** 与 MA200 (~1年) 同尺度，逻辑自洽。

**牛熊分界：** trend_score > 0.5 = 上升趋势，<= 0.5 = 下降趋势（过去一年中位数，无需额外调参）。

### 1.2 趋势自适应入场规则

```python
if trend_score > 0.5 (上升趋势):
    收盘价 < EMA20 (1天即可) → 候选信号
    # 牛市浅快回调也能进候选池，解决 2020-12 那批被漏的 GT

if trend_score <= 0.5 (下降趋势):
    连续 4 天 < EMA20 → 候选信号
    # 熊市要求更深回调确认，避免半山腰乱抓
```

### 1.3 trend_score 同时作为第二层 ML 特征

同一个信号两处复用：
- 第一层：控制候选门槛（宽/严）
- 第二层：作为 XGBoost 的一个特征（让模型知道当前趋势环境）

## 趋势识别方法选型依据

对话中调研了业界 regime 识别方法（从弱到强）：

| 方法 | 评价 | 问题 |
|------|------|------|
| VIX 阈值 (>20) | 最弱 | 滞后，等看到时损失已发生 |
| 滚动波动率过滤 | 一般 | 纯回看，不含趋势方向 |
| 裸二元 price vs MA200 | 有用但粗糙 | 无置信度、均线附近抖动 |
| 持续性纪律 / 缓冲带 | 改进版 | 减少抖动，但仍是二元硬标签 |
| 连续趋势评分 | **本项目选用** | 可解释、不过拟合、连续值有强弱 |
| HMM / Markov-switching | 机构标准 | 概率化软标签 + 状态粘性 |
| 多模型集成 + 宏观特征 | 最强 | 加信用利差/收益率曲线等正交维度 |

**选连续趋势评分的理由：**
- 机构标准是 HMM，但 HMM 是黑盒（说不清为什么今天判成牛市），与本项目"可解释"理念冲突
- 本项目只有 ~1387 个信号，HMM 多状态拟合容易过拟合
- 连续评分不训练、纯规则计算，不增加过拟合风险
- 是"可解释 + 不过拟合"的最优折中
