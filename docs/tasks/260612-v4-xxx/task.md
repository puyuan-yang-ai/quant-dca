# ML V4 — 趋势自适应入场 + 连续趋势评分 + 正交特征扩展

## 背景

V1/V2/V3 一直在治"模型看到了但 SKIP 了"（第二层 ML 问题），但忽略了另一种完全不同的根因：**第一层规则（NDay5）在牛市中把浅坑直接过滤掉了，模型根本没机会评估。** 这两种问题需要分开治。

```
根因A: 第一层规则(NDay5)就过滤掉了 → 模型根本没看到 (如2020-12牛市浅坑)
根因B: 模型看到了但SKIP了          → 第二层ML判断保守  (如2022-12熊市温和回调)
```

## 根因证据

2020年12月~2021年4月的 4 个 GT(SL7) 底部：

| SL7 底部 | 是否触发 NDay5 | 连续低于 EMA20 天数 |
|----------|---------------|-------------------|
| 2020-12-14 | 否 | 0 天 |
| 2021-01-29 | 否 | 1 天 |
| 2021-03-04 | 否 | 2 天 |
| 2021-03-24 | 否 | 1 天 |

全部在第一层就被漏掉。加再多特征也救不了第一层没放进来的信号。

## 需求（三层递进）

### 优先级1：修第一层规则漏洞 — 趋势自适应入场

- 实现连续趋势评分 (trend_score)，用 price/MA200 + MA50/MA200 两个维度判断牛熊及强度
- 第一层入场规则根据 trend_score 自适应调整：
  - 牛市：收盘价 < EMA20（1天即候选）— 解决浅坑被漏
  - 熊市：连续4天 < EMA20 才候选 — 避免半山腰乱抓
- trend_score 同时作为第二层 ML 特征（一份信息两层复用）

### 优先级2：Regime 分层决策

- 上升趋势：温和底部历史胜率高，ML 用低阈值积极买
- 下降趋势：只在极端恐慌买，ML 用高阈值保守
- 依赖优先级1验证完成后，根据新候选池的分布数据设计具体阈值方案

### 优先级3：加正交特征

在技术指标失效的温和区提供增量区分力：

| 数据 | 来源 | 难度 | 价值 |
|------|------|------|------|
| Put/Call Ratio | CBOE 免费日频 | 低 | 直接的期权情绪 |
| VIX 期限结构 (VIX/VIX3M) | Yahoo 免费 | 低 | 恐慌持续性 vs 短期 |
| 高收益信用利差 | FRED (BAMLH0A0HYM2) | 低 | 风险偏好/信用紧张 |
| 国债收益率曲线 | FRED | 低 | 宏观流动性 |
| TradingView 自定义指标 | 用户提供 Python 翻译版 | 中 | 私有经验信号 |

这些数据与价格/技术指标正交 — 当 RSI/breadth 在温和回调区失效时，信用利差或 put/call 可能还有区分力。

## 目标

- 牛市浅坑的 GT 覆盖率从 0% 提升到 >80%（第一层能捕获到）
- 整体 F1 和 AUC 不低于 V3
- 新增 trend_score + 正交特征，扩展模型信息维度
