# 任务：Breadth 连续弱势曲线可视化与特征探索

## 背景

现有 Breadth 指标只描述某一天有多少比例的 S&P 500 成分股收盘价高于 SMA(20)，本质上是一个静态快照。这个指标能反映市场宽度的当前状态，但不能直接表达“有多少股票已经连续多天处于 MA20 下方”。

为了观察市场弱势的持续性和严重程度，需要在现有 Breadth 基础上扩展一组连续弱势曲线，用于描述成分股连续低于 MA20 的时间层级。

## 需求

新增 5 条归一化到 0-100 的 Breadth 连续弱势曲线：

| 曲线 | 含义 |
|------|------|
| `B_c1` | 低于 MA20 至少 1 天的成分股比例，约等于 `100 - Breadth` |
| `B_c2` | 连续低于 MA20 至少 2 天的成分股比例 |
| `B_c3` | 连续低于 MA20 至少 3 天的成分股比例 |
| `B_c4` | 连续低于 MA20 至少 4 天的成分股比例 |
| `B_c5` | 连续低于 MA20 至少 5 天的成分股比例 |

这组曲线应满足：

```text
B_c1 >= B_c2 >= B_c3 >= B_c4 >= B_c5
```

## 可视化目标

在交互式图表中增加一个 Breadth 连续弱势副图，将 `B_c1` 到 `B_c5` 画在同一个副图里，并用不同颜色区分。

本阶段重点是可视化探索，不直接新增交易策略。需要通过图表观察以下形态：

- 2022 熊市中各曲线的层级结构和持续弱势变化。
- 2020 年 3 月 COVID 崩盘期间 `B_c1` 到 `B_c5` 的扩散与收敛。
- `B_c1 - B_c5` 等 spread 是否在关键市场拐点出现规律性变化。

## 后续方向

如果可视化结果显示这组曲线有稳定信息量，再将其作为 ML 特征工程的一部分。可考虑的衍生特征包括 spread、变化率、曲线面积等，标签可以使用未来 N 天收益率或 Oracle 最优买点二分类。

同时，现有 `validate_signal_returns.py` 的前瞻收益分析尚未覆盖 VIX、Breadth 以及第一梯队 AND 组合。后续可以先补齐这些信号的 5/10/20 日前瞻收益和期权可行性评估，再决定是否进入牛市价差等期权策略回测。
