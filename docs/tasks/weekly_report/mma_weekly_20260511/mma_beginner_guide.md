## 一、MMA 是什么？

**MMA = Merriman Market Analyst**，由 Raymond Merriman 创立的市场分析机构。

| 维度 | 说明 |
|------|------|
| 创立 | 1980 年代由 Raymond Merriman 创立 |
| 特色 | **金融占星 + 周期分析 + 传统技术分析** 三合一 |
| 核心信仰 | 市场转折点的时间不是随机的，而是与天体运行周期高度相关 |
| 主要产品 | 周报（Weekly Stock Indices Report）/ 月报（Monthly Cycles Report）/ 加密报告 |
| 历史命中率 | CRD 反转窗口约 **82-90%**（仍有 10-18% 失效概率）|

> ⚠️ **重要心态**：MMA 是**概率工具**，不是水晶球。把它当作"高概率提示"而不是"确定预测"。

## 三、最重要的工具：太阳-月亮反转日历

这是 MMA 周报里**最常用、最核心**的表格。学会读这张表，你就掌握了 MMA 80% 的实用价值。

### 表格长什么样

```
| 日期         | 反转值   | High    | Low     |
|--------------|----------|---------|---------|
| 5/19-5/20    | 142.0*** | 114.7*  | 169.8*  |
```

每一行 = 一个时间窗口的反转分析，**包含 3 个关键数字**。

### 这些数字是什么？

> ❌ **不是**点位（不是 SPX 142 点）
> ❌ **不是**百分比概率（不是 142% 概率）
> ✅ **是**：**相对历史频率指数** —— 用 **1930 年至今** 的太阳-月亮周期数据回测得到的

公式简化版：
```
某日的"X 值" = (历史上该日组合形成 X 的次数 ÷ 全样本平均) × 100
```

**基准线 = 100**（与历史平均相同），**越大越强**。

### 关键阈值

| 数值范围 | 含义 | 标记 |
|---------|------|------|
| < 100 | 低于基准（弱信号） | 可能带 `#` |
| 100-113 | 接近基准（平淡） | 无标记 |
| **> 113** | **显著高于预期** | 通常带 `*` |
| > 130 | 强 | 通常 `**` |
| > 140 | **非常强** | 通常 `***` |

> `*` 数量 = 统计显著性强度（不是数值本身）

---

### 三层逻辑深度详解

读懂一行数据需要分 **3 个层次**：

#### 第一层：反转值 → "这天会不会有反转？"

```
反转值 142.0***
   ↓
看必然性（强度）
   ↓
142.0 = 反转频率是历史平均的 1.42 倍
*** = 三颗星，统计极显著
   ↓
结论：必出反转，未来 2 周第一强
```

#### 第二层：High vs Low → "如果反转，是顶还是底？"

```
High 114.7*    Low 169.8*
   ↓              ↓
顶部反转概率    底部反转概率
   ↓              ↓
横向对比：Low (169.8) >> High (114.7)
   ↓
历史偏向 = 大概率成底（70%）
                = 小概率成顶（30%）
```

#### 第三层：实战修正 → "实际方向看价格怎么冲入"

> ⚠️ 这是 MMA 原文 §69 明确写的关键规则：
> "if the value has an asterisk next to it, it should be looked upon **more as a reversal**, whether historically it has been more often a high or a low."
>
> 翻译：**带星号 → 优先视为"必有反转"，方向是次要的**。

```
带 * 的反转值
       ↓
反转必发生，但方向跟着价格走：
       ↓
┌──────────────────────────────────────────┐
│ 进入窗口前价格已下跌 → 顺历史偏向        │
│   Low 占优 → 🟢 大概率成底（默认）       │
├──────────────────────────────────────────┤
│ 进入窗口前价格强势冲高 → 逆历史偏向       │
│   Low 占优 → 🔴 反向变成顶（反转必发生） │
├──────────────────────────────────────────┤
│ 进入窗口前价格横盘 → 反转弱              │
│   方向不明，看后续价格行为                │
└──────────────────────────────────────────┘
```

### 完整解读流程图

```
┌─────────────────────────────────────────────┐
│ 第一层：反转值 → 看必然性                   │
│ ────────────────────────                    │
│ < 100   → 没事，可忽略                      │
│ 100-113 → 关注，可能有反转                  │
│ > 113*  → 显著（带 1 颗星）                 │
│ > 130** → 强（带 2 颗星）                   │
│ > 140***→ 极强（带 3 颗星），必出反转       │
└─────────────────────────────────────────────┘
                    ↓
              确认有反转
                    ↓
┌─────────────────────────────────────────────┐
│ 第二层：High vs Low → 看方向偏向            │
│ ────────────────────────                    │
│ High >> Low → 历史上多为顶                  │
│ Low >> High → 历史上多为底                  │
│ 两者接近   → 双向都强                       │
└─────────────────────────────────────────────┘
                    ↓
        ⚠️ 带 * 时，方向会被实际价格走势覆盖
                    ↓
┌─────────────────────────────────────────────┐
│ 第三层：实战修正 → 看价格如何冲入           │
│ ────────────────────────                    │
│ 强势上涨进入 → 反转向下 = 顶                │
│ 已下跌进入  → 反转向上 = 底                 │
│ 横盘进入    → 反转弱，待价格行为表态        │
└─────────────────────────────────────────────┘
                    ↓
            最终方向 = 历史偏向 ⊕ 当前价格趋势
```

### 实战阅读示范

#### 示范案例：解读 5/19-20 这一行

原始数据：
```
| 日期      | 反转值    | High   | Low    |
| 5/19-5/20 | 142.0*** | 114.7* | 169.8* |
```

**第一层 → 反转必然性**
- 142.0 = 反转频率是平均的 1.42 倍
- 三颗星 = 统计极显著
- ✅ 结论：**必出反转**，未来 2 周第一强

**第二层 → 方向偏向**
- High 114.7（历史成顶频率 = 平均 1.15 倍）
- Low 169.8（历史成底频率 = 平均 1.7 倍）
- Low ÷ High ≈ 1.48
- ✅ 历史偏向：**70% 概率成底，30% 概率成顶**

**第三层 → 实战修正**

| 进入 5/19-20 时的市场状态 | 5/19-20 最可能成什么 |
|----------------------|------------------|
| 之前已经回调 / 横盘走弱 | 🟢 **底**（顺偏向，符合 70% 默认）|
| 之前持续强势上涨创新高 | 🔴 **顶**（逆偏向，反转必发生）|
| 不温不火横盘 | ⚪ 反转弱，方向待定 |

✅ **最终判断需要等到 5/19 临近时看实际价格走势**。

## 四、周期体系（5 类周期）

MMA 把市场周期分成 5 个层级，**层级越大、时间越长、影响越深**。

```
┌────────────────────────────────────────────────────┐
│ 50-Week Cycle    34-67 周（约 1 年）  年度大势    │
│ ────────────                                       │
│ Primary Cycle    13-23 周（约 4-6 月）大势         │
│ ────────────                                       │
│ Half-Primary     8-12 周                中期        │
│ ────────────                                       │
│ Major Cycle      5-8 周                 中期        │
│ ────────────                                       │
│ Trading Cycle    几天                   短线        │
└────────────────────────────────────────────────────┘
```

### 关键关系

- **1 个 50-Week Cycle = 多个 Primary Cycle**
- **1 个 Primary Cycle = 2 个 Half-Primary 阶段** 或 **3 个 Major Cycle 阶段**
- 当前 Primary Cycle 是"两相位"还是"三相位"，要看实际行情验证（前 5-8 周见顶 = 三相位 / 8-12 周见顶 = 两相位）

### 周期阶段对操作的影响

| 你处于 Primary Cycle 第几阶段 | 偏向 |
|--------------------------|------|
| 第 1 阶段（前 1/3） | 偏多，回调买入 |
| 第 2 阶段（中 1/3） | 中性，注意见顶 |
| 第 3 阶段（后 1/3） | 偏空，警惕 Primary Cycle 大底 |

## 五、CRD 临界反转日

**CRD = Geocosmic Critical Reversal Date**，MMA 自己计算的"占星临界反转日"。

### 关键属性

| 维度 | 说明 |
|------|------|
| 计算依据 | 多个占星相位的"密集出现期"（geocosmic cluster）|
| 时间容差 | 通常 **±3 天**，最大可扩展到 **±6 天** |
| 历史命中率 | ±3 天约 **82%**，±6 天约 **90%+** |
| 强度等级 | `*`（弱）→ `**`（中）→ `***`（强）|
| 与太阳月亮反转日的区别 | CRD 时间窗口更宽（±3 天 vs ±1 天），通常对应更大级别的反转 |

### CRD 标记示例（来自实际报告）

```
May 5* (low in Gold, high in Soybeans)
May 25*** (holiday, so May 22-26, T-Notes highlighted)
June 26-29*
```

读法：
- `May 5*` = 5 月 5 日中心 ± 3 天 = 5/2-5/8 反转窗口
- `May 25***` = 5 月 25 日中心，**三星 = 强信号**，因有节假日所以窗口为 5/22-26
- `June 26-29*` = 6 月 26-29 日反转窗口

## 六、TIP 趋势指标点

**TIP = Trend Indicator Point**，MMA 自定义的**周线趋势判定指标**（不是通用技术指标）。

### 用法

| 周收盘价 vs TIP | 趋势判定 |
|--------------|---------|
| 周收盘 **> TIP** | 多头趋势成立（trend run-up） |
| 周收盘 **< TIP** | 趋势降级到中性（neutral） |
| 连续 N 周 > TIP | "TIP run-up"，趋势延续力越强 |

### 实例

```
报告原文："This week's TIP is 49,421. It will be downgraded back to neutral
         if it closes below there this week."
```

含义：本周 DJIA 的 TIP 是 49,421。只要本周收盘 ≥ 49,421，多头趋势继续；否则降级中性。

> ⚠️ **每周更新**：每份新周报会发布新的 TIP 数值用于本周判定。

## 七、3-8 天回调机制

MMA 的核心剧本：**Major Cycle 顶 → 3-8 天下跌 → Major Cycle 底 → 重启上涨**

### 完整逻辑链

```
Major Cycle 顶 (Top)
       ↓
3-8 个交易日下跌 (Corrective Decline)
       ↓
Major Cycle 底 (Trough)
       ↓
重启上涨 (Resumption of Uptrend)
```

### 关键性质

| 维度 | 说明 |
|------|------|
| 必要性 | Major Cycle 顶必须配合"3-8 天下跌"才能确认 |
| 时间长度 | 3-8 个**交易日**（不是日历日），约 1-1.5 周 |
| 回调幅度 | 通常 **3-5%** |
| 验证信号 | RSI 进入 40-60 区；价格测试 15 日均线 |

### 用途

- 判断"Major Cycle 顶是否真的形成"
- 推算"Major Cycle 底大约何时到达"
- 如果顶后没有 3-8 天下跌 → 顶剧本作废（参见 2026-05-08 实例）

## 八、常见误区（小白最容易犯的 6 个错）

### ❌ 误区 1：把数字当百分比

```
错误理解：Low 169.8 = 169.8% 概率成底
正确理解：Low 169.8 = 历史成底频率是平均的 1.7 倍
```

### ❌ 误区 2：不看价格行为，盲目按时间操作

```
错误：5/19 到了，赶紧买！
正确：5/19 到了，看 K 线 → 出现长下影线 / 反包阳线才买
```

### ❌ 误区 3：忽略带 * 的"方向覆盖"规则

```
错误：Low 占优 → 一定是底
正确：Low 占优 + 带 * → 反转必发生，方向看价格冲入趋势
```

### ❌ 误区 4：把 MMA 当圣经

```
错误：MMA 说见顶我就梭哈做空
正确：MMA 提示见顶概率高 → 减仓 1/3 + 设止损
```

### ❌ 误区 5：不设止损

```
错误：MMA 说底要到了，跌穿支撑也死扛
正确：失效条件触发立即清仓，认错离场
```

### ❌ 误区 6：忽略周期定性切换

```
错误：以为永远是 Major Cycle（5-8 周）
正确：第 5-8 周不见顶 → 自动升级 Half-Primary（8-12 周）
```
