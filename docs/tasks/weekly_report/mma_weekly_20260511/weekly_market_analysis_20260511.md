> **读法**：反转值 > 113 表示比预期高的反转概率；带 `*` 强度更高，带 `#` 反之。"高/低" 列分别是历史上更常出现的方向。

> **方向判定规则**（**新增列**）：
> - **High > Low** → 🔴 倾向**顶部**（反转向下）
> - **Low > High** → 🟢 倾向**底部**（反转向上）
> - **High ≈ Low** → ⚪ **双向**（反转方向不明，看实际价格行为）

### 6.1 数值原理速查（这些数字到底什么意思？）

#### 三个核心问题

| 问题 | 答案 |
|------|------|
| 是点位吗？ | ❌ **不是**，与 SPX/DJIA 价位无关 |
| 是百分比概率吗？ | ❌ **不是**，不是 0-100% 那种概率 |
| 那是什么？ | ✅ **相对历史频率指数**（normalized historical frequency index） |
| 越大越好还是越小越好？ | ✅ **越大越强**（在该方向上的反转倾向越强） |

#### 计算原理（简化版）

```
某日"High 值" = (历史上该太阳-月亮组合日出现"高点"的次数 ÷ 全样本平均出现"高点"的次数) × 100
某日"Low 值" 同理
```

数据样本：MMTA 研究员 Yating Hu 自 **1930 年至今** 的回测。

#### 关键阈值表

| 数值范围 | 含义 | 标记 |
|---------|------|------|
| < 100 | 低于基准（反转概率低于历史平均） | 可能带 `#`（越多 # 越弱）|
| 100-113 | 接近基准（平淡，无明显信号） | 无标记 |
| **> 113** | **高于预期的反转概率**（MMA 原文阈值线） | 通常带 `*` |
| > 130 | 显著偏高 | 通常 `**` |
| > 140 | 非常显著 | 通常 `***` |

> `*` 的数量代表**统计显著性强度**，不是数值本身大小。带星 = 不是噪声，是真信号。

#### 数值含义实例

| 数值 | 解读 |
|------|------|
| `100` | 基准线 — 与历史平均一样，没有偏向 |
| `113` | 比平均高 13% — 开始值得留意 |
| `144.3*` | 比平均高 **44.3%**，统计显著 — 强信号 |
| `169.8*` | 比平均高 **69.8%**，统计显著 — **本期表中最强** |
| `84.0` | 比平均**低 16%** — 反向不利信号 |

#### 横纵对比规则

| 看什么 | 怎么用 |
|-------|-------|
| **同一行 High vs Low** | 哪个数值大 → 倾向哪个方向（**判方向**） |
| **同一列纵向比较** | 数值最大的那行 → 该方向最强信号（**判强度**） |
| **是否带 `*`** | 带星 → 统计显著、可信度高；无星 → 仅供参考 |

#### 形象类比："反转可能性的天气预报"

| 数值 | 类比 |
|------|------|
| 100 | ☀️ 平常天气 |
| 113 | ☁️ 阴天（要留意） |
| 130\* | 🌦️ 局部阵雨（带伞） |
| 140\*\* | ⛈️ 暴雨预警 |
| 170\* | 🌪️ 极端天气（高度警惕） |
