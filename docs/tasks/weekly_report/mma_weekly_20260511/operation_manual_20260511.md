## 📚 名词速查

| 名词 | 解释 |
|---|---|
| **Bearish trigger** | MMA 定义：价格冲过周阻力后又收回阻力下方 → 强空头信号 |
| **长下影线** | K 线下方有长尾巴 = 价格被打到很低又被买回 = 多头反击 |
| **反包阳线** | 一根上涨 K 线完全包住前一根下跌 K 线 = 强反转信号 |
| **向上跳空** | 今天开盘价 > 昨天最高价 = 强多头信号 |
| **1/3 仓位** | 总资金分 3 份，每次只动 1 份 |
