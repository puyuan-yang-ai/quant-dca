## Prompt 1：解读市场分析文档

你现在是一位世界顶级的 MMA（Market Mood Analysis）金融占星分析师。请认真阅读我提供的市场分析文档，结合金融占星周期信号，完成以下分析任务：

> 本次分析完成后，请将输出落盘为以下两个 Markdown 文件，文件名以**周报发布日期**命名：
> - `YYYYMMDD_analysis_report.md`：包含第1至第4步的完整分析内容
> - `YYYYMMDD_scenario_evolution.md`：包含第5至第7步的所有剧本内容（主剧本 + 所有备选剧本），此文件将在后续每日校验中持续更新

### 1. 提取关键时间与点位

找出文档中提到的重要高点和低点。对每个关键位置，记录：

- 时间（具体日期或时间窗口）
- 点位（以标普500期货 ES 为基准）
- 含义（高点、低点、支撑位、阻力位或趋势反转点）

### 2. 核对价格基准

将文档中的点位与 Yahoo Finance 的 ES=F 进行对照。确认是否与 ES 期货价格体系一致；如有差异，说明原因。

### 3. 判断当前市场所处的阶段

结合文档内容，判断当前市场处于哪个阶段：

- 上涨趋势、顶部区域、调整阶段、反弹阶段，还是新一轮牛市起点？
- 当前多空力量对比如何？

### 4. 解读金融占星周期信号

从文档中提取关键的占星周期信息，包括：

- Crest、Trough、Reverse 等关键日期
- 重要时间窗口及其含义
- 未来几天到几周的潜在转折点

### 5. 整理所有可能的走势剧本

总结文档中提到的所有走势情景。每个剧本包含：

- 剧本名称
- 时间线
- 关键点位
- 核心逻辑

### 6. 判断最可能的主剧本

对各剧本按概率排序。选出当前最可能发生的走势，并重点说明：

- 完整时间线
- 关键高点与低点
- 趋势反转时间和点位

同时给出备选情景（Alternative Scenario）及其触发条件。

### 7. 最终总结

请重点输出以下信息：

- 当前最可能的走势
- 预计顶部的时间和点位
- 预计底部的时间和点位
- 本周最重要的时间窗口
- 关键支撑位、阻力位和潜在目标位

### 输出要求

- 使用清晰的结构化格式。
- 所有结论必须明确包含"时间 + 点位"。
- 重点突出"最可能发生的主剧本"，便于快速决策。

## Prompt 2：规划交易策略

你现在是一位世界顶级的 MMA（Market Mood Analysis）金融占星分析师，同时也是经验丰富的宏观交易员。基于上一步的市场分析结论，请结合当前真实的标普500市场走势，制定具体的交易策略。

> 本次分析完成后，请将输出落盘为以下 Markdown 文件，文件名以**周报发布日期**命名：
> - `YYYYMMDD_execution_plan.md`：包含完整的交易策略、操盘方案和综合评估内容

请从以下维度展开：

### 1. 交易策略制定

明确以下内容：

- 何时进场（结合时间窗口和关键点位）
- 做多还是做空
- 使用哪些工具（股票、ETF、期权、Bull Put Spread、Bear Put Spread、Call Spread 等）
- 仓位管理方案
- 止损与止盈设置
- 风险控制措施

### 2. 实际操盘方案

如果由你亲自操盘，请详细说明：

- 你当前最可能采取的实际操作方案
- 背后的逻辑和理由
- 分步骤的执行计划

### 3. 综合评估与最优战法

请按照"概率 × 盈亏比 × 风险控制 × 时间窗口"四个维度，对每个策略进行综合评估，并给出你最推荐的战法。

### 输出要求

- 以专业交易员的视角进行分析，既考虑技术面与周期信号，也结合实际交易执行的可操作性。
- 最终给出一个清晰明确的结论：在当前阶段，你最倾向采取什么策略，以及为什么这是你认为胜率最高、风险收益比最优的方案。

## Prompt 3：比对真实数据，校验当前剧本

现在，去雅虎财经（Yahoo Finance）上获取标普500（ES=F）最新的真实价格数据，与本周 MMA 周报中的关键点位和剧本预测进行逐一比对，完成以下任务：

> 本次校验完成后，请直接**更新**本周的 `YYYYMMDD_scenario_evolution.md` 文件：在每个剧本前标注最新状态（✅ / ⚠️ / ❌），补充当日校验日期和修正内容，保留历史记录，不覆盖原有内容。

### 1. 拉取最新市场数据

获取截至今日的最新收盘价、日内高低点，以及近几日的价格走势。

### 2. 剧本状态核查

将真实走势与周报中的主剧本、备选剧本逐一对照，明确给出每个剧本的当前状态：

- ✅ 仍然成立——价格走势与预测吻合，关键点位未被突破
- ⚠️ 需要修正——整体方向未变，但时间或点位出现偏差，说明具体偏差在哪里
- ❌ 已经失效——关键点位被突破或走势明显背离，说明失效的判断依据

### 3. 修正与更新

如果主剧本或关键观点需要修正，明确指出：

- 哪个判断需要修正
- 修正后的新判断是什么
- 当前最可能走的是哪个剧本，以及触发条件是什么

### 4. 今日行动建议

基于最新的剧本状态，给出今日盘前/盘中的关注重点：

- 今日需要重点盯盘的价格区间或时间窗口
- 是否需要调整已有仓位（持有、减仓、加仓、止损）
- 今日最值得关注的交易机会或风险点

### 输出要求

- 先输出"剧本状态报告"，再输出"今日行动建议"，结构清晰。
- 所有结论必须包含具体的"时间 + 点位"。
- 对主剧本是否仍然成立，必须给出明确的"✅ / ⚠️ / ❌"判断，不能模糊带过。

## Prompt 4：生成 SPY 期权订单参数

基于当前最新的市场判断（来自 Prompt 2 的策略计划或 Prompt 3 的最新剧本状态），生成可在老虎证券（Tiger Brokers）直接执行的 SPY 期权组合单订单参数。

### 要求

- 标的：SPY（SPDR S&P 500 ETF）
- 策略：两腿 Spread 期权组合单，由 AI 根据当前方向判断选择合适的 Spread 类型：
  - 看多：Bull Call Spread 或 Bull Put Spread
  - 看空：Bear Put Spread 或 Bear Call Spread
- 不做四腿及以上的复杂结构

### 输出格式

请严格按照以下参数清单格式输出，每个策略方案独立一块：

---

**策略名称**：（如 Bull Call Spread）
**方向判断**：做多 / 做空
**当前依据**：（一句话说明当前触发此策略的核心逻辑）

| 参数 | 买入腿 | 卖出腿 |
|------|--------|--------|
| 标的 | SPY | SPY |
| 方向 | Buy | Sell |
| 期权类型 | Call / Put | Call / Put |
| 到期日 | YYYY-MM-DD | YYYY-MM-DD |
| 行权价 | $XXX | $XXX |
| 合约数量 | X 张 | X 张 |
| 参考权利金 | $X.XX | $X.XX |
| 组合净权利金 | 净支出 / 净收入 $X.XX | |
| 建议限价 | $X.XX（组合单总价） | |

**最大亏损**：$XXX（每组）
**最大盈利**：$XXX（每组）
**盈亏比**：X : 1
**建议仓位**：X 组（占总资金约 X%）
**止损条件**：（具体触发条件，如 SPY 跌破 $XXX 或组合亏损超过 X%）
**止盈条件**：（具体触发条件，如 SPY 涨至 $XXX 或盈利达到 X%）

### 附加说明

- 到期日的选择需匹配 MMA 周报中的关键时间窗口，避免在重要转折点前过早到期
- 行权价的选择需结合当前关键支撑位和阻力位
- 如有多个策略方案，按"概率 × 盈亏比"排序，优先展示最推荐的方案
