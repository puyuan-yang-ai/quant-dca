# DCA 策略收益对比图表需求文档

## 1. 功能概述

生成一张收益率对比走势图，将 DCA 策略的累计收益率与 SOXL 买入持有的收益率进行可视化对比，便于直观判断策略是否跑赢大盘。

## 2. 图表规格

### 2.1 数据定义

| 曲线 | 计算公式 | 颜色 |
|-----|---------|------|
| DCA 策略收益率 | (当日市值 - 累计成本) / 累计成本 x 100% | 浅蓝色 |
| SOXL 持有收益率 | (当日收盘价 - 首日收盘价) / 首日收盘价 x 100% | 淡红色 |

### 2.2 坐标轴

- **X 轴**：日期
  - 自动间隔显示，避免标签重叠
- **Y 轴**：收益率百分比 (%)
  - 起点为 0%

### 2.3 图表元素

| 元素 | 要求 |
|-----|------|
| 标题 | 显示图表标题 |
| 图例 | 显示两条曲线的名称和颜色 |
| 回测区间 | 显示起止日期 |
| 关键数据标注 | 最终收益率对比、最大回撤点 |

### 2.4 样式要求

- 不显示差值区域填充
- DCA 策略线：浅蓝色
- SOXL 持有线：淡红色

## 3. 输出规格

### 3.1 文件格式

- 格式：PNG
- 保存路径：`output/` 目录

### 3.2 文件命名

- 格式：`YYYY-MM-DD_HH-MM-SS.png`
- 示例：`2024-01-18_15-30-45.png`
- 不包含策略名或标的名

## 4. 技术要求

- 使用 matplotlib 绑制图表
- 图表需支持中文显示
- 自动创建 output 目录（如不存在）
