## 一、为什么股价到了短腿你只赚 30%？—— 这不是你的问题，是 debit spread 的数学

### 1.1 debit spread 的"价值收敛曲线"

```
最大利润 100% ┤                                    ╱── 到期日
              │                                ╱╱
              │                            ╱╱
              │                        ╱╱
        ~50% ┤                    ╱╱  ← 股价到短腿但还剩 50% DTE
              │                ╱╱
              │            ╱╱
              │        ╱╱
              │    ╱╱
         0%  ┤╱╱
              └─────────────────────────────────────
              入场      中期           短腿位置     到期
```

**核心原因**：当股价 = 短腿、但**距到期还剩 50% 时间**：

- **长腿** delta ≈ 0.80-0.85 → 涨得快，但还有时间价值损耗
- **短腿** delta ≈ 0.50-0.55 + **gamma 巨大** → 短腿涨得也很快，**还吃掉你长腿的涨幅**
- **短腿外在价值还剩 60-70%** → 短腿的"枷锁"还套在你身上

**实测数学**（举例）：
- 入场：SPY 730，买 730C / 卖 745C，28 DTE，**debit = $5**（max profit $10）
- 中期：SPY 涨到 745，剩 14 DTE，spread mark ≈ **$6.5-7**
- 你的盈亏：($6.5 - $5) / $5 = **+30%**（max 只能 +100%）

**正确版（已写入 mma-4 铁律 3）**：

| 场景 | 长腿 | 短腿 |
