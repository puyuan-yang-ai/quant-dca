# 参数验证 + 样本外测试

## 背景

当前最优策略：**固定档口 2%/5%/10% + 连续 5 天确认（EMA20）+ 正金字塔 + 不止盈**

该策略在 2022-2025 的 4 种市场环境中，Composite Sharpe 从 baseline 的 +0.04 提升到 +0.18（+331%）。

但有三个核心参数从未被充分验证过：

1. **EMA 周期 = 20**：为什么是 20？10 或 30 会不会更好？
2. **确认天数 N = 5**：N=5 是在 EMA=20 下扫出来的，换了 EMA 周期后最优 N 很可能不同（EMA 越短信号越短暂，需要更小的 N；EMA 越长则相反）
3. **档口间距 = 2%/5%/10%**：为什么是这个组合？更窄或更宽会不会更好？

其中 EMA 周期和 N 天是耦合参数，必须联合搜索。

此外，所有实验都在同一段数据（2022-2025）上完成，存在过拟合风险，需要用**样本外数据**验证。

## 任务目标

1. 在样本内数据（2022-2025，4 种环境）上扫描 EMA 周期和档口间距，确认当前参数是否最优
2. 用样本外数据（2010-2021）验证最终策略，确认没有过拟合

## 成功标准

- EMA 周期和档口间距经过验证（最优或接近最优）
- 样本外测试中，策略的 Composite Sharpe 和 Calmar 仍然优于 baseline
