## 测试 5：run_daily.sh 完整串联

命令：
```
chmod +x scripts/run_daily.sh
bash scripts/run_daily.sh
```

预期：网络就绪 → 拉数据 → 推理 → 报告 → 推送（无密钥应失败但不致命）→ 脚本 exit 0。

实际：✅ 通过。日志逐行：
```
========== 每日推理开始 ==========
网络就绪 (第 1 次探测)
步骤 1/4: 拉取最新数据...
步骤 2/4: 模型推理...
步骤 3/4: 生成报告...
步骤 4/4: Telegram 推送...
警告: 推送失败 (报告已生成, 可手动查看 reports/)
========== 每日推理完成 ==========
脚本退出码=0
```
- 关键验证：**推送失败被正确判定为非致命，脚本仍 exit 0**（符合"推送失败不应让整个任务算失败"的设计）。
- 产物正确生成：`reports/2026-06-12.md`、`logs/daily_20260620.log`。
- 数据 md5 跑前跑后一致（06-12 已是 Yahoo 最新交易日，周六无新数据，符合预期）。
