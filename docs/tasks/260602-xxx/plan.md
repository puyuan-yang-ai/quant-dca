# 江恩九方图 HTML 页面实施方案

## 页面位置

第一版建议实现为独立静态页面：

- `docs/tasks/260602-xxx/gann-square-nine.html`

该项目目前主要是 Python 策略与图表代码，没有现成前端构建入口。因此先采用单文件 HTML，更便于验证交互和计算逻辑。

## 页面结构

- 参数区：输入锚点价格、当前价格、步长、图表尺寸、投射方向、价格精度、容差范围，并提供“生成/更新”按钮。
- 九方图区：展示以锚点为中心的螺旋方格，区分中心、十字线、对角线、当前价附近格子，并把关键价位就近高亮到对应格子。
- 关键价位区：以锚点为原点、按平方根公式向外多圈展开，展示档位（圈数·角度）、方向、价位、与当前价的点数和百分比距离。
- 说明区：提示江恩九方图用于识别观察区，不构成独立交易信号。

## 交互方式

- 页面打开时使用默认参数生成初始视图。
- 用户修改参数后，点击“生成/更新”按钮才重新计算和渲染。
- 第一版不做实时自动刷新，避免用户输入过程中频繁重算导致展示跳动。

## 核心参数

- 锚点价格：关键价位的计算原点，决定整张固定的价位网格，通常取靠近当前价的近期重要高/低点。
- 当前价格：仅作为当前所在位置的标记，用于定位最近的上方阻力和下方支撑，不参与生成价位。
- 步长：决定中间九方图每个格子的价格间隔，应根据品种波动率调整（不影响关键价位计算）。
- 图表尺寸：控制可视网格范围，例如 `9 x 9`、`11 x 11`、`15 x 15`。
- 投射方向：支持向上、向下、上下都显示。
- 价格精度：控制输出价格的小数位。
- 容差范围：当当前价接近关键位时进行提示。

## 计算逻辑

### 中间九方图网格

经典线性螺旋结构：

- 中心格为锚点价格。
- 向外每移动一个螺旋序号，价格增加一个步长，即 `cellPrice = anchor + spiralIndex * step`。
- 网格只表示大于等于锚点的价格，因此低于锚点的支撑位无对应格子。

### 关键价位（方案 B：平方根多圈）

- 以锚点为原点：`root = sqrt(anchor)`。
- 按每 `45°` 一档向外展开：`factor(k) = k * 0.25`，`k = 1, 2, 3 ...`。
- 上方阻力：`level = (root + factor) ^ 2`；下方支撑：`level = (root - factor) ^ 2`（要求 `root - factor > 0`）。
- 每 8 档为一圈：`k = 8 → 360°`（第 1 圈），`k = 16 → 720°`（第 2 圈），以此类推。
- 角度分级：偶数 `k`（`90/180/270/360`）为十字线主力位，奇数 `k`（`45/135/225/315`）为对角线次级位，`k = 8/16/24…` 为整圈共振点。
- 圈数：默认上下各 3 圈（各 24 档）；当当前价超出覆盖范围时自动扩展，至少覆盖 `current ± 15%`，最多 30 圈封顶。
- 当前价定位：在全部价位中取刚好低于当前价的一档为最近支撑、刚好高于的一档为最近阻力。

### 关键价位映射到九方图

- 对每个关键价位，找到价格最接近的网格格子（误差不超过半个步长）就近高亮。
- 由于网格只覆盖大于等于锚点的价格、且步长为线性而价位为平方根，映射为近似高亮；低于锚点的支撑位不会在网格中出现。

### 必须接受的前提

- 档距随价位放大是平方根法的固有特性，不是错误。
- 江恩九方图无经过验证的有效性，仅为观察区工具，需结合其他因素确认。

## 默认参数

- 锚点价格：`100`
- 当前价格：`108`
- 步长：`1`
- 图表尺寸：`11 x 11`
- 投射方向：上下都显示
- 价格精度：`2`
- 容差范围：`0.5%`

## 实施步骤

1. 创建单文件 HTML 页面，完成基础布局和默认参数。
2. 实现参数表单的输入读取，并绑定“生成/更新”按钮。
3. 实现螺旋坐标生成函数，生成 `N x N` 九方图。
4. 实现中心、十字线、对角线、当前价附近格子，以及关键价位就近高亮的逻辑。
5. 实现以锚点为原点的平方根多圈价位计算（含自动扩展、角度分级、整圈共振点）、格式化和距离提示。
6. 在浏览器中验证参数修改并点击按钮后，九方图和关键价位列表能同步更新。
