# 关键价位重构方案（方案 B：平方根多圈）

> 本文档用于评审。确认无误后再修改 `gann-square-nine.html`，目前不改代码。

## 1. 背景与决策

当前页面右侧“关键价位”存在两个问题：

1. 只取了一圈（`45°` 到 `360°`），相当于只展示了江恩螺旋最内一环。
2. 计算基准用的是当前价 `current`，而不是起始锚点 `anchor`。

经过讨论，确定追求“正宗”的江恩九方图逻辑，采用**方案 B：平方根公式 + 多圈展开**。同时明确两个原点角色：

- `anchor`（起始点）：所有关键价位的计算原点，决定整张固定的价位网格。
- `current`（当前价）：仅作为“当前所在位置”的标记，用于定位最近的上方阻力与下方支撑。

这样既忠实于“螺旋以历史枢轴为中心建立”的正宗结构，又能满足“看当前价附近支撑阻力”的实际需求。

## 2. 必须接受的前提

- **档距随价位放大是江恩平方根法的固有特性，不是 bug。** 越往上档距越宽、越往下档距越窄，这是平方关系决定的。追求正宗就要接受档距不均匀。
- **江恩九方图没有经过验证的有效性。** 它只是“可能出现反应的观察区”，是否可用取决于与前高前低、均线、成交量、K 线形态的重合度，以及在具体品种上的回测，不能单独作为买卖信号。

## 3. 计算逻辑

### 3.1 基础公式

以锚点 `anchor` 为原点，按每 `45°` 一档向外展开：

```
factor(k) = k * 0.25          // k = 1, 2, 3, ...
上方阻力 level_up(k)   = (sqrt(anchor) + factor(k)) ^ 2
下方支撑 level_down(k) = (sqrt(anchor) - factor(k)) ^ 2   // 要求 sqrt(anchor) - factor(k) > 0
```

角度与档位对应关系（每 8 档为一圈）：

- `k = 1 → 45°`，`k = 2 → 90°`，…，`k = 8 → 360°`（第 1 圈结束）
- `k = 9 → 405°`，…，`k = 16 → 720°`（第 2 圈结束）
- 以此类推

### 3.2 角度分级

- **十字线（主力位）**：`90° / 180° / 270° / 360°`，对应**偶数 k**。
- **对角线（次级位）**：`45° / 135° / 225° / 315°`，对应**奇数 k**。
- **整圈共振点（squaring）**：`k = 8, 16, 24 …`（即 `360°、720°、1080°…`），表示螺旋每转满一整圈，是江恩里最受重视的“平方/开方”关键位，单独高亮。

### 3.3 圈数

- 默认上下各展开 **3 圈**（每圈 8 档，上下各 24 档）。
- 圈数计划做成可配置参数，方便评审后调整。

### 3.4 当前价定位

- 在全部生成的价位中，找到刚好低于 `current` 的那一档作为**最近下方支撑**，刚好高于 `current` 的那一档作为**最近上方阻力**。
- 计算每档相对 `current` 的点数距离与百分比距离。
- 容差范围内的档位标记“接近”。

### 3.5 锚点与当前价距离的注意事项

- 锚点应选取靠近当前价的近期重要高/低点，固定圈数才能覆盖当前价区间。
- 若锚点离当前价很远（例如 `anchor = 100`、`current = 757`），固定 3 圈可能覆盖不到当前价。
- 评审决策项：是否在固定圈数之外，**自动扩展圈数直到价位网格覆盖当前价上下一定范围**（建议至少覆盖到 current ±15%）。

## 4. 展示与交互调整

- 右侧关键价位面板说明改为：“以锚点为原点、按平方根公式向外多圈展开；当前价用于定位最近支撑/阻力。”
- 表格新增列：圈数、圈内角度、因子；保留价位与距离。
- 用不同样式区分：十字线主力位、对角线次级位、整圈共振点、最近支撑/阻力、接近当前价。

- 表格按价位排序，便于阅读上下梯度。

## 5. 中间九方图

- 本次重构聚焦右侧关键价位，中间螺旋九方图保持以锚点为中心的现状。
- 后续可选增强：把关键价位映射/高亮到中间九方图对应格子，让图与表完全对应（不在本次范围）。

3. 更新最近支撑/阻力与摘要逻辑，使其基于当前价在固定网格中的位置。
4. 更新右侧表格与说明文案，增加圈数/角度/因子展示与分级样式。

## 7. 已确认决策（评审通过，已实现）

1. 上下各展开圈数：**3 圈**。
2. 锚点离当前价较远时：**自动扩展圈数覆盖当前价**（至少覆盖 `current ± 15%`，最多 30 圈封顶）。
3. 表格展示：第一列用紧凑标签 `第N圈·角度`，并标注整圈/接近，不单独显示 factor 原始值。
4. 同步更新 `task.md` 与 `plan.md`，三份文档保持一致。
5. 关键价位就近高亮到中间九方图；受网格特性限制，低于锚点的支撑位无对应格子、且线性步长与平方根价位为近似映射。
