# 江恩九方图 HTML 页面需求

## 背景

需要制作一个 HTML 页面版本的江恩九方图工具，用于辅助观察价格与江恩角度之间的关系。第一版定位为手动输入参数的静态工具，不接入实时行情，也不自动识别高低点。

江恩九方图（Gann Square of Nine）通常以一个关键价格作为锚点，通过螺旋数字结构和角度关系，推导潜在的支撑位、阻力位或目标观察区。它适合作为交易参考工具，但不应单独作为买卖信号。

## 目标

- 用户进入页面后，可以手动输入锚点价格、当前价格、步长、图表尺寸、方向、价格精度和容差范围等参数。
- 用户修改参数后，通过点击“生成/更新”按钮触发重新计算和渲染。
- 页面根据参数生成经典螺旋九方图，以锚点价格为中心向外展开。
- 关键价位以锚点价格为计算原点，按平方根公式向外多圈展开；当前价格仅用于定位最近的上方阻力和下方支撑。
- 页面高亮九方图中的中心、十字线、对角线、当前价格附近区域，并把关键价位就近高亮到对应格子。
- 页面列出关键角度对应的上方阻力和下方支撑（含圈数与角度），帮助用户快速观察价格所处位置。
- 页面说明江恩价位只是观察区、档距随价位放大属正常特性，需要结合趋势、K 线、成交量、均线等其他因素确认。

## 第一版范围

- 实现为独立静态 HTML 页面，文件名为 `gann-square-nine.html`。
- 生成的 HTML 文件放在 `docs/tasks/260602-xxx/` 目录下。
- 只使用 HTML、CSS 和 JavaScript，不引入 npm 构建流程。
- 价格数据全部由用户手动输入。
- 页面形态采用平衡布局：参数面板、九方图、关键价位列表并重。

## 非目标

- 不接入实时行情 API。
- 不上传或解析行情 CSV。
- 不自动识别近期高点、低点或趋势结构。
- 不提供明确买入、卖出、止盈、止损信号。
