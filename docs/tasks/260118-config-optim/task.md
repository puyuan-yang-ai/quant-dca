# 多场景配置文件支持需求文档

## 1. 功能概述

支持多个预设配置文件，对应不同的回测场景（牛市、熊市、牛熊交替等），通过主配置文件快速切换，无需手动编辑参数。

## 2. 目录结构

```
config/
├── settings.yaml          # 主配置（仅指定使用哪个场景配置）
├── 2024-bull.yaml         # 场景配置：2024年牛市
├── 2022-bear.yaml         # 场景配置：2022年熊市
└── 2023-mixed.yaml        # 场景配置：牛熊交替
```

## 3. 配置文件规格

### 3.1 主配置文件 settings.yaml

仅包含一个字段，指定使用的场景配置：

```yaml
# 指定使用的场景配置文件（相对于 config 目录）
use_config: "2024-bull.yaml"
```

### 3.2 场景配置文件

包含完整的回测参数：

```yaml
# config/2024-bull.yaml
start_date: "2024-07-11"
end_date: "2025-04-07"
data_file: "data/SOXL.csv"
fee_rate: 0.01
orders:
  - [1.00, 0.70]   # 市价单
  - [0.98, 0.40]   # 限价单 A
  - [0.95, 0.25]   # 限价单 B
  - [0.90, 0.15]   # 限价单 C
```

### 3.3 场景配置命名规范

格式：`{年份}-{场景类型}.yaml`

示例：
- `2024-bull.yaml` - 2024年牛市
- `2022-bear.yaml` - 2022年熊市
- `2023-mixed.yaml` - 2023年牛熊交替

## 4. 工作流程

1. 用户在 `config/` 下创建多个场景配置文件
2. 修改 `settings.yaml` 中的 `use_config` 指向目标场景
3. 运行 `python main.py`
4. 程序自动加载指定的场景配置

## 5. 技术要求

- 修改 `main.py` 的配置加载逻辑
- 主配置文件 `settings.yaml` 只保留 `use_config` 字段
- 场景配置文件包含所有回测参数

## 6. 验收标准

- [ ] settings.yaml 简化为只有 use_config 字段
- [ ] 场景配置文件格式正确
- [ ] 切换 use_config 后能正确加载对应配置
- [ ] 运行时打印当前使用的配置文件名
- [ ] 创建至少一个示例场景配置文件
