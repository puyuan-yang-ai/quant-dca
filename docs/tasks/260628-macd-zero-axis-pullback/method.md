# 方法说明：MACD 定级别 + 转九序列抄底（通用方法）

> 本文把这套逻辑固化为**级别无关的通用方法**，并给出分钟/日线两种实例化与代码实现指引。
> 口径细节：MACD 见 `docs/indicators/macd/macd.pine`；TD 见 `docs/indicators/TD-sequential/note.md`。
> 实证状态见本文第七节与 `stage3-results.md`。

## 一、目标

下跌趋势中，识别"主跌前的最后一波诱多上拉"，并据此**预判主跌浪的底部**，作为抄底的参考信号。

## 二、核心思想

- 一波下跌往往不是直跌，而是"箱体震荡 → 最后一波上拉（诱多）→ 主跌"。
- 这"最后一波上拉"对应 **MACD 回抽零轴**——但只在**某个特定级别**上才"恰到好处"，这个级别即 **L**。
- 把 L **乘以一个系数**得到"观察级别"，在该级别上用 **TD 九转（神奇九转）** 的"低7-9"来定位主跌浪的**底部**。
- **关键性质（架构 B）**：箱体级别、回抽级别 L、转九观察级别 **三者通常不同**；级别是相对的，必须多级别扫描（见 `czsc-level-essence.md`）。

## 三、口径与名词约定

- **级别**：一根 K 线代表的时间跨度（分钟数或交易日数）。由"基础数据重采样"得到，不是某指标算出来的。
- **中枢（箱体）**：缠论中枢（`分型→笔→中枢`，纯价格几何，**不依赖 MACD**）。上沿 `zg`、下沿 `zd`。
- **MACD**：参数 12/26/9；`DIF=EMA12−EMA26`、`DEA=EMA9(DIF)`、**柱 `hist=DIF−DEA`（单倍，非 ×2）**；EMA 首值初始化（对齐 TradingView ta.ema）。
- **TD 九转**：Jason Perl《DeMark Indicators》(2008) 口径；买入 Setup 连续 9 根 `收盘<前4根收盘`，标 1…9；"低7/8/9"=计数到 7/8/9。

## 四、通用方法（四步，级别无关）

### 第 1 步：定箱体 + 最后上拉窗口
1. 确认一波**明显下跌**（判据：箱体后出现向下笔，最低跌破中枢下沿 `zd`，且该笔跌幅 ≥ 箱体高度 `zg−zd`）。
2. 倒推该下跌前的**箱体（中枢）**。
3. 取"**最后一波上拉**"窗口 = `[箱体低点, 下跌前高点]`
   （箱体低点 = 中枢区间内、下跌前高点之前的最低低点；下跌前高点 = 最后一笔向上笔的顶）。

### 第 2 步：用 MACD 回抽零轴确定级别 L（核心）
在"最后上拉"窗口内，**逐级别**计算 MACD，找出**同时满足以下三条件**的级别，即为 L（可有多个）：
- **(a)** `min(DIF) < 0`（先沉到零轴下）；
- **(b)** `0 < max(DIF) ≤ max(绿柱)`（DIF 回抽到零轴上、但不超过最高绿柱；DIF 峰与绿柱顶可不在同一根）；
- **(c)** DEA 触及/略穿零轴（DEA 峰值进入零轴附近的小容差带）。

> 说明：级别越细，DIF 越易"冲过头"(b 不满足)；级别越粗，DIF 越可能"沉在零轴下"(回抽不到位)。恰好满足三条件的，就是 L。

### 第 3 步：算转九观察级别 = L × 系数
- **观察级别 = round(L × 系数)**。
- **系数经验值：2.5 ~ 3**（两数据集一致指向；见第七节）。

### 第 4 步：在观察级别上用转九定底
- 在"观察级别"上挂 TD 九转，于**主跌浪区间**内寻找信号；
- **信号 = 第 1 次出现的 低7 / 低8 / 低9**；该根附近即**预测底部**（抄底参考）。

**经验上不采用**（实证未加分）：完美结构、13 计数（Countdown A/B）、"第2/3次低9"（"三而竭"未获支持）。

## 五、参数小结

| 项 | 取值 |
|----|------|
| MACD | 12/26/9，柱=DIF−DEA |
| 回抽三条件 | (a) min(DIF)<0；(b) 0<max(DIF)≤max(绿柱)；(c) DEA 触零（容差待校准） |
| 系数 | 2.5 ~ 3 |
| 转九信号 | 第1次 低7/8/9 |
| 不用 | 完美结构、13计数、第2/3次 |

## 六、两种实例化

**A. 分钟版（盘中大盘择时）**
- 数据：`ES=F` 5 分钟（yfinance，约 60 天）为基础，重采样为 `{5,10,15,20,30,45,60,75,90,105,120}` 分钟。
- 跌幅过滤门槛参考 `{0.5,1,1.5,2}%`。

**B. 日线版（中长期大盘择时）**
- 数据：`SPY_adjusted.csv`（1993+），按"每 N 交易日"聚合为 `{1,2,3,4,5,7,10}` 日级别（再大用周线）。
- 跌幅过滤门槛参考 `{3,5,8,10}%`。

> 通用核心相同，只是"基础数据 + 级别集合 + 跌幅门槛"按尺度替换。

## 七、实证状态（诚实记录，勿当已验证）

- **样本内**：盘中 60 天 与 日线 33 年**都**指向同一组参数（系数 2.5~3、第1次低7-9），超额命中 +20~42%。
- **样本外**：两数据集训练/测试切分后**测试集均崩**（触发样本仅 3~6，统计无效）。
- **瓶颈**：单一大盘标的的"箱体→回抽→大跌"事件只有二三十个，样本量不足以统计证实。
- **定位**：**有一致苗头、但未经统计证实的启发式**——可作人工择时的参考信号之一，不宜单独作为量化依据。
- 详见 `stage3-results.md`。

## 八、代码实现指引

**复用模块**
- `src/indicators/macd.py` — `calc_macd(closes)` 返回 (dif,dea,hist)，pine 口径。
- `src/indicators/td_sequential.py` — `compute_td(highs,lows,closes)` 返回 Setup/完美/Countdown。
- `src/chan/czsc_vendor/` — `CZSC` 构笔、`get_zs_seq` 取中枢。

**数据流（端到端）**
1. **数据层**：拉/读基础数据 → 重采样为级别集合（`fetch_intraday_data.py` / 日线按 N 行聚合）。
2. **扫箱体**：每级别 `CZSC`+`get_zs_seq` → 检测"箱体→明显下跌"用例，产出"最后上拉窗口 + 主跌浪 + 底部"（`scan_boxes.py`）。
3. **定级别 L**：把上拉窗口喂"MACD 回抽三条件"扫描 → 每用例的 L 列表（`build_samples.py` / `scan_macd_zero_pullback.py`）。
4. **转九定底**：`观察级别=round(L×系数)` → `compute_td` → 主跌浪内第1次低7-9 → 预测底（`td_bottom_experiment.py`）。
5. **评估**：跌幅过滤 + 三拨(60/20/20) + lift(精度−随机基准) + 消融（`td_bottom_experiment.py --mode grid` / `run_daily_experiment.py`）。
6. **可视化**：盘中用 matplotlib（`show_5m_predictions.py`/`scan_boxes.py --viz`）；日线可用 `src/interactive_chart.py`（原生支持缠论笔/中枢 + 自定义 markers）。

## 九、后续改进方向（若要把"苗头"做成"结论"）
- 扩样本：多个**大盘指数**（SPY/QQQ/DIA/IWM，非个股）汇总；或购买多年**分钟级**数据（FirstRate/Databento）。
- 在更大样本上重跑第五~七步，用样本外测试 + 随机基准做严格验证。
- 校准模糊阈值（DEA 触零容差、跌幅门槛）。
