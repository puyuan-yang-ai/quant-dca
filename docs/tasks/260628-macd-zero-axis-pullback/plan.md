# MACD 回抽零轴 · 多级别识别 — 计划与实施方案

> 需求背景见同目录 `task.md`。TD 序列实现口径见 `docs/indicators/TD-sequential/note.md`。
> 本文记录最终对齐方案（架构 B，分阶段实施）。

## 一、总体目标与链路

**最终目标**：一个**事后、可统计验证**的抄底信号研究。完整链路：

> 箱体 + MACD 回抽 → 定级别 **L** → **× 系数** → TD 观察级别 → 主跌浪里找 TD 低7/8/9（或 13 确认）→ 看信号是否落在底部 **±N 根**内 → 在**大量样本**上算命中率（P/R），与基准比、留测试集防过拟合。

**架构 B（解耦）**：箱体与回抽是不同时间尺度——箱体（较粗级别）定位"最后上拉"时间窗，回抽在**更细级别**判定；该回抽级别即作为后续 ×系数 的输入 **L**。

**实施顺序**：阶段零(✓) → 阶段一(✓) → 阶段二 → 阶段三。

## 二、阶段零：实现并验证 MACD（已完成 ✓）

- `src/indicators/macd.py`：按 `macd.pine` 口径——首值初始化 EMA（alpha=2/(n+1)）、`dif=ema12−ema26`、`dea=ema9(dif)`、**`hist=dif−dea`（单倍，非 ×2）**。
- **不套用** czsc `tas.py`（其 `hist=(dif−dea)×2`，口径不符）。
- 验证：`scripts/validate_macd.py` 与 pandas `ewm(adjust=False)` 逐根**零误差**通过；TradingView 真值比对钩子 `--tv-csv` 就绪（可选兜底，见第八节）。

## 三、数据层（已完成 ✓）

- `scripts/fetch_intraday_data.py`：yfinance 拉 `ES=F` **5 分钟**（约 60 天）→ `data/intraday/ESF_5m.csv` 等。
- 级别：**`{5,10,15,20,30,45,60,75,90,105,120}` 分钟**（30~120 加密，含 90m；均为 5m 整数倍）。扫描脚本从 5m **现场重采样**到任意级别（`--levels` 可配）。
- 时间统一北京时间；预热历史远早于分析窗口，保证各级别 MACD 充分预热。

## 四、阶段一：手动窗口 → 多级别 MACD 回抽扫描（已完成 ✓）

- `scripts/scan_macd_zero_pullback.py`：输入手动"最后上拉窗口" `[起涨低点, 局部高点]`（北京时间），对全部级别算 MACD，窗口内判"回抽零轴"三条件：
  - (a) `min(DIF) < 0`（先沉零轴下）；
  - (b) `0 < max(DIF) ≤ max(绿柱)`（DIF 峰与绿柱顶可不同根）；
  - (c) DEA 触及/略穿零轴（相对容差，待校准）。
- 输出：命中级别（小→大排序）+ 各级别数值 + 每级别一张图（价格+MACD，高亮窗口）。
- **已验证**：用例1 命中 60m、用例2 命中 90m，均与人工判断一致。

## 五、阶段二：自动扫箱体 + 主跌浪（下一步）

用 czsc（笔/中枢）**自动**产出阶段一/三所需的样本，把用例从手挑 3 个扩到几十~上百个。

**流程**：
1. 多级别 `CZSC` 构笔、`get_zs_seq` 得中枢。
2. 定位"下跌前箱体"：其后出现向下笔**跌破中枢下沿 `zd` 且跌幅 ≥ 箱体高度 `zg−zd`**（明显下跌判据）。
3. 产出每个用例：① **最后上拉窗口** `[起涨低点, 局部高点]`（喂阶段一 → 得回抽级别 L）；② **主跌浪区间及其底部**。

**已定细则**：
- 主跌浪**结束于**箱体跌破后向下笔序列的**第一个底分型/低点**（下一波上涨笔起点）。
- TD 信号、底部、N **都在 TD 观察级别（L×系数）上度量**（主跌浪时间区间映射到该级别）。
- 一个用例**回抽级别 L 不唯一**时：每个命中级别各算**一个独立样本**；**零命中则跳过**。
- "真实底部"用 **swing-low（k=3）**（复用 `detect_swing_lows`），取主跌浪内最低的 swing-low。

## 六、阶段三：TD 九转抄底验证（口径见 `docs/indicators/TD-sequential/note.md`）

对阶段二产出的样本集，验证"L×系数 级别上出现 TD 低9（可能第2/3次）≈ 底部"。

**TD 模块**（蓝本 Jason Perl 2008）：
- 标准 Setup 计数（核心，始终算）；
- 完美结构：flag，默认关；
- 13 确认两方案，默认关、开启二选一：**A=正统 Countdown（全细节：close≤low[2]、13-vs-8 递延、取消、recycle/18根/1.618×）**；**B=Setup 溢出（pine 式）**。
- **信号点**：13关→低7/8/9；13开→第13根；完美开→对低9 加过滤。

**待探索变量**（先做减法，先扫核心 3 维：系数 / 第几次 / N；稳了再加回完美、13两方案）：

| # | 变量 | 候选 |
|---|------|------|
| 1 | 回抽级别 L | 阶段一输出 |
| 2 | 系数 coef | {2, 2.5, 3, 3.5, 4} |
| 3 | 触发计数 | 低7 / 低8 / 低9 |
| 4 | 第几次出现 | 1st / 2nd / 3rd（"三而竭"） |
| 5 | 完美结构 | 开 / 关 |
| 6 | 13 确认 | 关 / 方案A / 方案B |
| 7 | 命中距离 N | {1,2,3,5,8} 根（TD 级别上数） |
| 8 | 真实底部 | swing-low(k=3) |

**评估方法论（防过拟合，复用 `ml/research` 思路）**：
- 客观真值（swing-low 近似，类比 `sl_proximity`）；
- 用 **Precision / Recall** 量化（出现信号时是底的比例 / 真底被抓到的比例），**不靠"看着像"**；
- **留测试集 / walk-forward**，参数在训练集选、测试集验；
- 与**傻瓜基准**（如"下跌 N 根后随机猜底"）比较，必须有超额信息量。
