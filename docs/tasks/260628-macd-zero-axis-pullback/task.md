# MACD 回抽零轴 · 多级别识别 — 需求与目标

## 一、背景与核心假设

在下跌趋势中，价格往往不会一路直跌，而是在主跌段开始前先走出一个**箱体震荡**，箱体末端会有**最后一波局部上拉**（即缠论"下跌中枢"里的最后一段反抽），随后才真正展开主跌。

核心假设：**这波"最后上拉"通常对应 MACD 的一次"回抽零轴"动作**——DIF 先沉到零轴下方，再随上拉回抽到零轴附近。本任务要做的，是把这个观察固化成一个可自动判定的工具。

## 二、关键洞见：箱体级别 ≠ 回抽级别

这是整套逻辑的命门，也是必须多级别处理的根本原因：

1. **箱体只在其"自然级别"上可见**。小箱体在细级别（如 5m）看得见、在粗级别（如 1h）会塌缩消失；大箱体在粗级别（如 60m/2h）看得见、在细级别（如 5m）会被打散淹没。因此**扫箱体必须多级别**。
2. **回抽零轴的级别通常比箱体级别更细**。在箱体所在的（较粗）级别上，MACD 被前面的大跌主导，DIF 长期深陷零轴下方，末端那波上拉只是一两根 K 线、抬不动 DIF；只有切到**更细的级别**，这波上拉才被展开成足够多的 K 线，MACD 才有行程把 DIF 回抽到零轴附近，"回抽零轴"形态才显现。

结论：**箱体（定位"最后上拉"的时间窗）与回抽（在更细级别上判定）是两个不同时间尺度的现象，不能强行要求同级别。**

## 三、"回抽零轴"的精确定义

在"最后上拉"的时间窗口内，需**同时满足**以下三条，才算回抽零轴成立：

- **(a) 先沉到零轴下**：窗口内 `min(DIF) < 0`（体现是"回抽"，而非普通上涨）。
- **(b) 回抽到零轴上、但不超最高绿柱**：`0 < max(DIF) ≤ max(绿柱高度)`。其中 DIF 的峰值与最高绿柱可以不在同一根 K 线上（跨根比较）。
- **(c) DEA 触及/略穿零轴**：DEA 峰值抬升到零轴附近的一个小容差带内。

> 口径约定：MACD 参数 12/26/9；柱状图 `hist = DIF − DEA`（单倍，来源见 `docs/indicators/macd/macd.pine`）；绿柱 = 柱状图为正值（`hist > 0`）。

## 四、关键约定

| 项 | 取值 |
|----|------|
| 标的 | `ES=F`（标普期货，近 24 小时连续，最贴近连续合约形态） |
| 基础数据 | 5 分钟 K 线，yfinance，约 60 天 |
| 级别集合 | `{5, 10, 15, 20, 30, 60, 120}` 分钟（均为 5m 整数倍，由 5m 重采样得到） |
| 缠论复用 | `src/chan/czsc_vendor/`：分型 → 笔(BI) → 中枢(ZS)。**无"线段"实现**，"箱体"用中枢(ZS)充当 |
| "明显下跌"判据 | 箱体后出现向下笔，最低点跌破中枢下沿 `zd`，且该笔跌幅 ≥ 箱体高度 `zg − zd` |
| 输入时间 | 用户报"起涨低点 / 局部高点"用**北京时间(UTC+8)**，内部统一转换 |
| 模糊容差 | DEA "触及零轴"带宽、"略穿"容许量等手感阈值，先用保守默认，**留待可视化阶段校准** |

## 五、目标与非目标

**目标**：实现一个**事后复盘**的自动化识别工具——给定一波明显下跌，定位其前的箱体与"最后上拉"，并找出在**哪个（哪些）级别**上 MACD 回抽零轴成立。

**非目标（当前阶段不做）**：
- 不做实时触发（仅事后确认）。
- 暂不做信号胜率回测。
- 暂不接入机器学习系统。

> 后续若识别逻辑站得住，再考虑扩展为胜率回测，胜率可观时再对接 ML（均不在本任务范围内）。
