# TD Sequential（神奇九转）实现逻辑 — 供人工校验

> 蓝本：**Jason Perl《DeMark Indicators》(2008)**。本项目以买入(低)方向为主，卖出(高)为镜像。
> 本文是"实现规格"，请逐条对照 TradingView 上的 TD Sequential 人工校验，确认无误后再落代码。

---

## 0. 基础定义（先统一术语）

- `close[k]`：当前 K 线往前第 k 根的收盘价（`close[0]` = 当前）。
- **真实高 TrueHigh** = `max(high, close[1])`（当前最高价 与 前一根收盘价 取大）。
- **真实低 TrueLow** = `min(low, close[1])`（当前最低价 与 前一根收盘价 取小）。
- **真实波幅 TrueRange(段)** = 该段内 `最高真实高 − 最低真实低`。
- 所有比较用**收盘价/最高价/最低价**，按下文精确指定，**不做任何平滑**。

---

## 1. TD Price Flip（价格反转，Setup 的前提）

- **熊市反转（启动买入 Setup）**：某根收盘 < `close[4]`，且**前一根**收盘 ≥ `close[4]`。
- **牛市反转（启动卖出 Setup）**：某根收盘 > `close[4]`，且**前一根**收盘 ≤ `close[4]`。

> 实现技巧：用"连续计数器归零"即可隐式满足 flip（见下）。

---

## 2. TD Setup（九转计数，核心，始终计算）

### 买入 Setup（低）
- 计数条件：**当前收盘 < `close[4]`**。
- 连续累加：满足则 `+1`，**任意一根不满足则归零、重新计数**。
- 隐式 flip：计数变为 1 的那根，其前一根必然不满足（计数为 0，即前一根收盘 ≥ `close[4]`），恰好是熊市反转。
- 计数 1…9（可继续到 9 以上，见方案B）。**低7 / 低8 / 低9 = 计数到 7 / 8 / 9**。

### 卖出 Setup（高）—— 镜像
- 计数条件：**当前收盘 > `close[4]`**；其余同上。高7/8/9 对应。

### 取值示例（买入）
```
收盘 c[i] 与 c[i-4] 比较，连续 9 根都满足 c[i] < c[i-4]：
c1<c(−4) … c9<c(−4)  → 第9根标 "低9"
中途任一根 c[i] ≥ c[i-4] → 计数清零，从下次熊市反转重数
```

---

## 3. 完美结构 Perfection（可选 flag，默认关）

- **买入完美**：第 **8 或 9 根**的**最低价** ≤ **第 6、7 根的最低价**（两者都要 ≤）。
  - 若第9根时未满足，可由后续 K 线"延迟完美"（第10、11…根最低价满足也算）。
- **卖出完美（镜像）**：第 8 或 9 根的**最高价** ≥ 第 6、7 根的最高价。
- 用途：作为对"低9 信号"的**过滤开关**——开启时，不完美的 9 不算有效信号。

---

## 4. TDST 支撑/阻力（Countdown 取消用）

- **买入 TDST 阻力** = 该买入 Setup（第1~9根）内的**最高真实高 TrueHigh**。
- **卖出 TDST 支撑** = 该卖出 Setup 内的**最低真实低 TrueLow**。

---

## 5. TD Countdown — 方案 A（Perl 2008 正统，可选，默认关）

> 仅在一个**完成的买入 Setup（9）**之后才可能启动。卖出为镜像。

### 5.1 启动
- 若 Setup 第 9 根**收盘 ≤ `low[2]`（前2根最低价）**，则第 9 根即 **Countdown 第 1 根**。
- 否则 Countdown 第 1 根**推迟**，直到出现"收盘 ≤ `low[2]`"的 K 线。

### 5.2 计数
- 计数条件：**当前收盘 ≤ `low[2]`**（前 2 根的最低价）。
- **不要求连续**：不满足的 K 线**跳过、不归零**；满足则 `+1`，从 1 数到 13。

### 5.3 第 13 根资格（13-vs-8 递延规则）
第 13 根要"成立"，必须**同时**满足：
- (a) 第13根**收盘 ≤ `low[2]`**（常规计数条件），且
- (b) 第13根的**最低价 ≤ Countdown 第 8 根的收盘价**。

若 (b) 不满足 → **递延**，图上以 "+" 标记，计数停在 12，等后续同时满足 (a)(b) 的 K 线才真正记为 13。

### 5.4 取消（Cancellation，整段未完成 Countdown 作废）
- ① 出现反向的**卖出 Setup（9）**；或
- ② 价格走高，出现一个**真实低 TrueLow 高于买入 TDST 阻力**（第4节）。

### 5.5 Recycle（重置，与新 Setup 强度有关）
- **Qualifier I（TR 比较）**：设最近完成 Setup 的真实波幅为 TR2、前一个为 TR1，若
  `TR1 ≤ TR2 < 1.618 × TR1` → recycle（新 Setup 取代旧的，Countdown 重置）。
- **Qualifier II（Setup 套 Setup）**：若最近 Setup 的极值区间落在前一个 Setup 的真实波幅之内 → 旧 Setup 保留（不 recycle）。
- **Rule III（18 根）**：若某个 Setup 一路延伸到 **18 根**（18 个连续收盘 < `close[4]`）→ Countdown 取消，标 "R"。

> ⚠️ 蓝本差异已锁定为 **Perl 2008**：recycle 用 **18 根** + **1.618×** TR 比例（官方 DeMARK 的 22 根 / 2.0× 不采用）。

---

## 6. TD Countdown — 方案 B（pine 式 "Setup 溢出"，可选，默认关）

- 不做真正的 Countdown，而是让 **Setup 计数越过 9 继续数**（10、11、12、13…）。
- 即你那份 `td.pine` 的做法（其 13/14/15/16 着色就是这个）。
- 用途：与方案 A 做"哪种 13 更准"的对比实验。

---

## 7. 在本项目中的"抄底信号点"取法

| 配置 | 信号点（候选底） |
|------|----------------|
| 13确认 **关** | **低7 / 低8 / 低9**（Setup）那根 |
| 13确认 **开**（方案A 或 B） | **第 13 根** 那根 |
| 完美结构 **开** | 仅对"低9"加过滤；信号点仍是低9 |

> 主方向用**买入(低)**；卖出(高)对称实现备用。

## 9. 人工校验清单（建议对照 TradingView 逐项打勾）

- [ ] 买入 Setup：连续 9 根 `close < close[4]`，中断归零，低9 位置正确。
- [ ] 完美结构：第8/9根最低 ≤ 第6/7根最低（开启时）。
- [ ] Countdown 启动：第9根 `close ≤ low[2]` 才从9起算，否则推迟。
- [ ] Countdown 计数：`close ≤ low[2]`、不连续、跳过不归零。
- [ ] 第13根：同时满足 `close13 ≤ low[2]` 且 `low13 ≤ Countdown第8根收盘`；否则标 "+"。
- [ ] 取消：反向卖出 Setup 出现 / 真实低高于 TDST 阻力。
- [ ] Recycle：18 根延伸标 "R"；TR2∈[TR1,1.618×TR1) 取代。
- [ ] 配色仅装饰，不影响计数（与图表配色可能不同）。
