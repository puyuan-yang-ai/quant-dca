# MOST on RSI v2 — 使用指南

---

## 1. 指标概述

MOST on RSI v2 是一个基于 RSI 的**底部/顶部捕捉指标**，通过三个独立事件产生不同强度的买卖信号（B/B+/B++ 和 S/S+/S++）。

**核心思路**：RSI 进入超卖/超买区域时，通过极端阈值、均线交叉、价格背离三个维度综合评估信号强度。

**适用场景**：上升趋势或震荡趋势中的回调抄底 / 顶部减仓。下跌趋势中的买入信号需要配合趋势指标过滤（详见第 6 节）。

## 2. 图表元素

### 2.1 线条

| 线条 | 颜色 | 说明 |
|------|------|------|
| RSI 曲线 | 紫色 | 14 日 Wilder RSI |
| 快均线 | 橙黄色（加粗） | RSI 的 EMA(5)（或 VAR(5)，可切换） |
| 70 / 30 水平线 | 灰色 | 超买 / 超卖参考线 |
| 50 中线 | 灰色半透明 | RSI 中性位置 |

### 2.2 渐变区域

| 区域 | 颜色 | 含义 |
|------|------|------|
| RSI 70-100 | 绿色渐变 | 超买区域，越深越超买 |
| RSI 0-30 | 红色渐变 | 超卖区域，越深越超卖 |

### 2.3 信号标签

| 标签 | 颜色 | 大小 | 含义 |
|------|------|------|------|
| `B` | 绿色 | 小 | 基础买入信号（1 分） |
| `B+` | 绿色 | 中 | 中等买入信号（2 分） |
| `B++` | 绿色 | 大 | 强买入信号（3 分） |
| `S` | 红色 | 小 | 基础卖出信号（1 分） |
| `S+` | 红色 | 中 | 中等卖出信号（2 分） |
| `S++` | 红色 | 大 | 强卖出信号（3 分） |

## 3. 三个独立触发事件

指标有三个独立的信号来源，每个事件单独触发标签。

### 3.1 事件 1：RSI 下破/上破极端阈值（左侧预警）

**买入**：RSI 从上方跌破 30 → `B`
**卖出**：RSI 从下方突破 70 → `S`

- 仅在穿越瞬间触发一次，RSI 持续低于 30 不会重复
- 这是最早出现的信号，通常在下跌过程中，表示"已经进入深度超卖"
- 适合轻仓试探

**图表上的识别**：RSI 曲线从渐变区域上方跌入红色渐变区域的那一根 K 线。

### 3.2 事件 2：RSI 上穿快均线（右侧确认）

**触发条件**：
1. RSI 上穿橙黄色快均线（交叉发生）
2. 过去 5 根内 RSI 最低值曾低于 40（门槛检查）

**评分与标签**：

| 条件 | 加分 | 说明 |
|------|------|------|
| 交叉 + 门槛通过 | 1 分（基础） | RSI 上穿快均线，且近期曾超卖 |
| 过去 14 根内 RSI 曾 < 30 | +1 分 | 近期有极端超卖 |
| 过去 14 根内有过背离事件 | +1 分 | 近期有价格背离 |

| 总分 | 标签 |
|------|------|
| 1 分 | `B` |
| 2 分 | `B+` |
| 3 分 | `B++` |

**图表上的识别**：RSI 紫色曲线从下方穿越橙黄色快均线的那一根 K 线。

**卖出方向完全对称**：RSI 下穿快均线 + RSI 曾 > 60 → S/S+/S++。

### 3.3 事件 3：背离（高置信度信号）

**看涨背离触发条件**（全部满足）：
1. 当前价格低于近 14 根内的最低价（价格创新低）
2. 当前 RSI 高于那个最低价时的 RSI（RSI 未创新低）
3. 那个最低价时的 RSI ≤ 30（参考点必须是真正的超卖低点）
4. 首次检测到时触发，连续成立不重复

**评分**：

| 条件 | 分数 | 标签 |
|------|------|------|
| 背离成立 | 2 分（基础） | `B+` |
| 背离 + 近 5 根内有过有效交叉 | 3 分 | `B++` |

**背离的含义**：价格跌到新低，但 RSI 没有跟着创新低，说明下跌动能在减弱。这是一个强信号，所以直接给 2 分。

**看跌背离完全对称**：价格创新高 + RSI 未创新高 + 参考点 RSI ≥ 70 → S+/S++。

## 4. 信号的时间递进

在一轮典型的底部行情中，三个事件通常按以下顺序出现：

```
价格下跌过程:

1. RSI 跌破 30
   → B 出现（事件1，左侧预警）
   → 此时可轻仓试探

2. 价格创新低，RSI 未创新低（背离）
   → B+ 出现（事件3，背离信号）
   → 此时可标准仓位

3. RSI 开始回升，上穿快均线
   → B+ 或 B++ 出现（事件2，右侧确认）
   → 若近期有背离+极端 → B++，可重仓确认
```

**不是每次都会三个事件齐全**。有时只出现事件 1（浅度超卖后直接反弹），有时事件 2 和事件 3 间隔较远。信号越多、越密集，底部的置信度越高。

## 5. 操作建议

### 5.1 仓位对应

| 信号 | 建议仓位 | 逻辑 |
|------|---------|------|
| `B` | 轻仓（20-30%） | 单因子预警，可能是底部也可能还在跌 |
| `B+` | 标准仓位（40-60%） | 背离或双因子，较可靠 |
| `B++` | 重仓（70-100%） | 三因子集齐，高置信度 |

### 5.2 同一位置出现多个标签

由于三个事件独立触发，同一根 K 线可能同时出现多个标签。这是正常的，看**最高级别**的标签做决策即可。

### 5.3 信号频率与级别分布

正常分布应为：**B 多 > B+ 少 > B++ 罕见**。

- 如果 B++ 频繁出现，通常意味着处于持续下跌趋势中，信号可靠性降低（见第 6 节）
- B++ 真正有价值的场景是：长期上涨后的深度回调中首次出现

---

## 6. 重要局限性

### 6.1 RSI 是均值回归指标，不是趋势指标

RSI 告诉你"当前超卖多严重"，但**不告诉你趋势方向**。

同样 RSI = 25：
- 上升趋势中的回调 → 好买点，趋势会拉回来
- 下跌趋势中的常态 → 陷阱，还会继续跌

### 6.2 买入信号在下跌趋势中会失效

在持续下跌中：
- RSI < 40 是常态 → 门槛永远开着
- RSI 反复跌破 30 → 极端信号频繁
- 价格不断创新低，RSI 碰到数学地板 → 背离反复触发
- 每次小反弹 RSI 穿越快均线 → 交叉频繁

**三因子全满足恰恰是强下跌的特征，而不是底部的特征。**

### 6.3 正确的使用方式

**RSI 信号要顺势使用**：

|  | RSI 买入信号 | RSI 卖出信号 |
|--|------------|------------|
| 上升趋势 | 靠谱（抄底） | 不太靠谱（可能卖早） |
| 震荡趋势 | 靠谱 | 靠谱 |
| 下跌趋势 | **不靠谱**（接飞刀） | 靠谱（卖反弹） |

### 6.4 建议搭配趋势工具

在主图上叠加趋势参考，在采纳 RSI 信号前先判断趋势：

| 方法 | 做法 | 判断 |
|------|------|------|
| EMA 均线 | 主图叠加 EMA(200) | 价格在 EMA(200) 上方 = 上升趋势 |
| 均线交叉 | EMA(50) 与 EMA(200) | 金叉 = 上升趋势确立 |
| 价格结构 | 观察高点和低点 | 更高的高低点 = 上升趋势 |

```
决策流程：
  1. 先看趋势：价格在 EMA(200) 上方吗？
  2. 再看 RSI 信号：有 B/B+/B++ 吗？
  3. 两者结合：趋势向上 + B++ → 高置信度买入
                趋势向下 + B++ → 忽略或极轻仓
```

## 7. 参数说明

### RSI 设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| RSI Length | 14 | RSI 计算周期，通常无需修改 |
| Source | close | RSI 数据源 |

### 均线设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| MA Type | EMA | 快均线类型（EMA 或 VAR） |
| Fast MA Length | 5 | 快均线周期 |

### 信号设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Buy Gate | 40 | RSI 低于此值才产生买入交叉信号 |
| Sell Gate | 60 | RSI 高于此值才产生卖出交叉信号 |
| Extreme Buy | 30 | RSI 低于此值触发事件 1 + 极端加分 |
| Extreme Sell | 70 | RSI 高于此值触发事件 1 + 极端加分 |
| Cross Lookback | 5 | 交叉事件的门槛检查窗口 |

### 背离设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Divergence Window | 14 | 背离比较窗口，在此范围内找参考低/高点。也用于极端 RSI 和近期背离的追溯窗口 |

## 8. 快速参考卡

```
看到 B  → 问自己：趋势向上吗？→ 是 → 轻仓试探
看到 B+ → 问自己：趋势向上吗？→ 是 → 标准仓位
看到 B++ → 问自己：趋势向上吗？→ 是 → 重仓确认
                                → 否 → 忽略或极轻仓

看到 S  → 问自己：趋势向下吗？→ 是 → 轻仓减持
看到 S+ → 问自己：趋势向下吗？→ 是 → 标准减持
看到 S++ → 问自己：趋势向下吗？→ 是 → 大幅减持
                                → 否 → 观望，可能只是短期过热

B/B+/B++ 短期内反复密集出现 → 可能处于下跌趋势，信号可靠性降低
S/S+/S++ 短期内反复密集出现 → 可能处于上升趋势，信号可靠性降低
```
