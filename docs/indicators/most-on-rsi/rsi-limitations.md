# RSI 指标的适用边界与局限性分析

本文档记录在 MOST on RSI v2 指标实盘验证过程中发现的根本性问题，以及对 RSI 类指标适用场景的深度反思。

---

## 1. 发现的问题

### 1.1 现象

将 v2 指标放到 TradingView 上观察历史行情，发现：

- **下跌趋势中买入信号过多**：B、B+、B++ 信号频繁出现，但每次只是抓到小反弹，随后继续下杀
- **B++ 反而不如 B**：权重最高的 B++（三因子满分）标记的位置，很多只是"下跌中继的小反弹"；而简单的 B（RSI 下破 30）有时反而更准
- **信号越强，亏损越大**：按照 B++ 重仓操作，在持续下跌中会造成最大亏损

### 1.2 根本原因

**这不是参数调整或逻辑 bug 能解决的问题，而是 RSI 指标的先天盲区。**

---

## 2. RSI 的本质：均值回归指标

RSI（Relative Strength Index）衡量的是"近期涨幅占总波动的比例"。它本质上是一个**均值回归（mean-reversion）指标**——告诉你"当前价格偏离均值多远"。

```
RSI 高（>70）→ 近期涨多了，可能要回调
RSI 低（<30）→ 近期跌多了，可能要反弹
```

**关键假设**：均值回归指标隐含一个前提——**存在一个"均值"可以回归**。

- 在上升趋势中：均值在上移，RSI 低了会被趋势拉回来 → 假设成立
- 在震荡趋势中：均值不变，RSI 低了自然会回归 → 假设成立
- 在下跌趋势中：均值在下移，RSI 低了不代表会回归，可能继续更低 → **假设不成立**

---

## 3. 为什么三因子在下跌中全部失效

### 3.1 门槛（RSI < 40）变成常态

在上升趋势中，RSI 大部分时间在 40-80 之间运行。RSI 跌破 40 是"异常事件"，代表有价值的买入机会。

在下跌趋势中，RSI 大部分时间在 20-50 之间运行。RSI < 40 是**常态**，不是异常。门槛永远敞开，失去了过滤作用。

### 3.2 极端 RSI（< 30）反复出现

在上升趋势中，RSI 跌破 30 很罕见，可能几个月才出现一次。出现时往往是深度回调的底部。

在下跌趋势中，RSI 可以在 20-35 之间反复震荡数周甚至数月。RSI < 30 频繁出现，每次都触发极端加分。

```
上升趋势中的 RSI < 30：
RSI: 65  58  52  45  38  28  35  42  50  58  65
                           ↑
                      罕见事件 → 好买点

下跌趋势中的 RSI < 30：
RSI: 38  32  28  25  30  35  28  22  26  32  28  20  24  30
              ↑   ↑           ↑   ↑           ↑   ↑
           反复出现 → 每次都是"假底"
```

### 3.3 背离成为"永动机"

背离的逻辑是"价格创新低但 RSI 未创新低"。但 RSI 有一个数学特性：**它的下限是 0，实际中很难低于 15**。

在持续下跌中：
- 价格可以从 100 跌到 80、60、40、20...（跌幅不封顶）
- RSI 跌到 20 左右就很难再低了（有数学下限）
- 所以价格不断创新低时，RSI 几乎必然"不创新低"→ 背离反复触发

**这种背离不是"下跌动能减弱"的信号，而是 RSI 数学公式的天花板/地板效应。**

### 3.4 交叉在震荡中频繁发生

RSI 在 20-35 之间反复波动时，会频繁穿越 EMA(5) 均线。每次小反弹都产生交叉信号。

### 3.5 三因子同时满足 = 强下跌的特征

```
三因子全满足的真实含义：

你以为的：                          实际上的：
"超卖 + 背离 + 交叉 = 底部"         "RSI 在低位反复震荡 = 强下跌趋势"

B++ 出现在上升趋势回调 → 好买点      B++ 出现在下跌趋势中 → 陷阱
```

---

## 4. 为什么 B 有时比 B++ 更准

B（RSI 下破 30）只在 RSI **从上方首次跌破** 30 时触发一次（`ta.crossunder`）。

- 如果 RSI 从 55 一路跌到 28 → 这通常是一轮正常回调的末期，B 信号有价值
- 如果 RSI 已经在 25-35 之间反复震荡 → B 不会重复触发（因为 RSI 没有回到 30 以上再跌下来）

而 B++ 需要交叉 + 极端 + 背离，这三个条件在深度下跌中反复成立，每次小反弹都产生 B++。

**B 的"低频"特性反而是优势**——它只在 RSI 从正常区域首次进入极端区域时触发，不会在已经极端的区域内反复触发。

## 5. RSI 信号的适用方向

### 核心原则：RSI 信号顺着大趋势方向用才靠谱

|  | RSI 买入信号（做多） | RSI 卖出信号（做空/减仓） |
|--|-------|-------|
| **上升趋势** | 很好用：回调到 RSI 低位 = 趋势内的买入机会 | 不太好用：RSI 高位可能只是趋势延续 |
| **震荡趋势** | 好用：RSI 低位反弹 = 区间底部 | 好用：RSI 高位回落 = 区间顶部 |
| **下跌趋势** | **不好用：RSI 低位可能是下跌中继** | 很好用：反弹到 RSI 高位 = 卖出/做空机会 |

### 为什么会这样

**均值回归 + 趋势 = 信号方向**

- 趋势向上 + RSI 超卖 → 趋势力量会把价格拉回来 → 买入信号可靠
- 趋势向下 + RSI 超卖 → 趋势力量继续压低价格 → 买入信号不可靠
- 趋势向下 + RSI 超买（反弹后）→ 趋势力量会把价格压下去 → 卖出信号可靠
- 趋势向上 + RSI 超买 → 趋势力量可能继续推高 → 卖出信号不可靠

**一句话总结：RSI 信号要顺势而为。逆势使用 RSI 就是在和趋势对赌。**

### 对 v2 指标的具体含义

v2 指标的三个买入事件（B/B+/B++）本质上都是在寻找"超卖反弹"的机会。这在以下场景有效：

- 牛市/上升趋势中的深度回调 → 指标的最佳使用场景
- 长期横盘震荡中的区间底部 → 指标正常工作
- 熊市反弹 → **指标会频繁误报，信号不可靠**

同理，v2 的卖出信号（S/S+/S++）在以下场景有效：

- 熊市/下跌趋势中的超买反弹 → 卖出信号的最佳场景
- 牛市追高 → **卖出信号可能过早，卖飞**

## 6. 正确的使用方式

### 6.1 不要在指标内部解决趋势问题

在 RSI 指标上叠加更多过滤条件（更严格的门槛、更长的窗口等）只会增加参数复杂度，但**无法解决"不知道趋势方向"的根本问题**。趋势信息不在 RSI 里面，它在价格本身的结构里。

### 6.2 RSI 指标 + 趋势判断 = 完整决策

```
RSI 指标（已有，管"超卖程度"）：
  → B / B+ / B++（当前超卖多严重？）

趋势判断（需要另加，管"方向"）：
  → 价格在 EMA200 上方？
  → 周线 MACD 金叉？
  → 更高的高点和更高的低点？

交易决策 = RSI 信号 × 趋势环境：
  上升趋势 + B   → 轻仓买入
  上升趋势 + B++ → 重仓买入
  下跌趋势 + B++ → 忽略买入信号！或极轻仓
  下跌趋势 + S+  → 卖出/减仓的好时机
```

### 6.3 趋势判断的常用方法

以下方法不需要修改 RSI 指标，在 TradingView 主图上叠加即可：

| 方法 | 做法 | 判断 |
|------|------|------|
| EMA 均线 | 主图叠加 EMA(50) 和 EMA(200) | 价格在 EMA200 上方 = 上升趋势 |
| 均线交叉 | EMA(50) 在 EMA(200) 上方 | 金叉 = 上升趋势确立 |
| 价格结构 | 肉眼观察高点和低点 | 更高的高点 + 更高的低点 = 上升趋势 |
| 周线级别 | 切换到周线看 RSI | 周线 RSI > 50 = 大趋势偏多 |

### 6.4 实操建议

```
每次看到 RSI 指标出现 B/B+/B++ 信号时，先问自己：

1. 价格在 EMA(200) 的什么位置？
   → 上方：可以信任这个信号
   → 下方：要打很大折扣，或忽略

2. 这是第几次出现 B++ 了？
   → 上升趋势中首次出现：高置信度
   → 短期内反复出现：说明处于持续下跌，信号失效

3. 卖出信号同理，反过来判断：
   → 下跌趋势中的 S/S+ → 可以信任（顺势卖出）
   → 上升趋势中的 S++ → 可能卖早了
```

## 7. 与 quant-dca 项目的关联

这个认知与 quant-dca 回测系统的设计思路完全一致：

- `ComposableStrategy` 的 **Entry 模块**（`EMAFilterEntry`）就是用 EMA 趋势来过滤入场的
- 策略不会在价格低于 EMA 时盲目买入，即使"超卖"了
- **模块化设计的精髓**：把"超卖检测"和"趋势判断"拆成独立模块，各自做好各自的事

RSI 指标的角色应该类似 Entry 模块中的一个因子，而不是独立的交易系统。

---

## 8. 总结

| 认知 | 说明 |
|------|------|
| RSI 是均值回归指标 | 它告诉你"偏离多远"，不告诉你"会不会回来" |
| 趋势决定 RSI 信号的可靠性 | 顺势信号靠谱，逆势信号危险 |
| 买入信号适合上升/震荡趋势 | 下跌趋势中的 RSI 买入信号会频繁误报 |
| 卖出信号适合下跌/震荡趋势 | 上升趋势中的 RSI 卖出信号可能过早 |
| B++ 在下跌中反而最危险 | 三因子全满足恰恰是强下跌的特征 |
| 不要用 RSI 解决趋势问题 | RSI 管超卖，趋势判断用其他工具 |
| RSI 指标 + 趋势过滤 = 完整系统 | 两者配合才能做出可靠的交易决策 |
