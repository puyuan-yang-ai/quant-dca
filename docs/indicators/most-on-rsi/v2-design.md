# MOST on RSI v2 改版设计方案

---

## 1. 改版背景

### 1.1 v1 版本的问题

通过对 v1 PineScript 代码的深度分析和实际观察，发现以下问题：

**问题一：MOST BUY/SELL 信号严重滞后，无法标在高低点附近**

MOST（Moving Stop Loss）是一条"只能单方向移动"的止损线，套在 RSI 均线上。信号产生需要经过三层滞后叠加：

```
价格出现拐点
    ↓ 滞后 1：RSI(14) 对价格的平滑
RSI 出现拐点
    ↓ 滞后 2：RSI 均线(5日 VAR) 对 RSI 的平滑
RSI 均线出现拐点
    ↓ 滞后 3：MOST 需要 RSI 均线移动 9% 幅度才翻转方向
MOST 交叉信号出现
    → 此时离真正的底部/顶部已经很远
```

结论：MOST 的 BUY/SELL 信号**对找买卖点没有帮助**，保留它只会误导交易决策。

**问题二：RSI 与 RSI 均线的交叉噪音太多**

一个直觉上合理的替代方案是看 RSI 上穿/下穿 RSI 均线。但实际上假信号太多，因为 RSI 本身是一条"毛躁"的锯齿线，而 RSI 均线相对平滑：

```
RSI（锯齿状）：    ╱╲╱╲╱╲╱╲╱╲╱╲
                        ↕↕↕ 频繁穿越
RSI 均线（平滑）：  ─────────────────

一条毛躁的线穿一条平滑的线 → 震荡时来回穿越，假信号泛滥
```

但配合门槛过滤（仅 RSI < 40 / > 60 区域），RSI 与快均线的交叉信号置信度很高。在底部/顶部区域，交叉是有方向性的回归信号，不是震荡噪音。

**问题三：双均线交叉仍有滞后**

在早期 v2 设计中尝试了快慢双均线交叉（快 EMA5 上穿慢 EMA14），虽然比 MOST 好，但两条平滑线交叉的响应速度仍然不够快。改用 RSI（未平滑的原始信号）与快均线(EMA5)的交叉，响应速度最快。

**问题四：v1 的背离信号不错，但参数全部硬编码**

背离检测（Bull/Bear Divergence）是 v1 中最有价值的部分，能在接近顶底的位置预警。但以下参数无法通过 UI 调整：

```pinescript
lookbackRight = 5    // 硬编码
lookbackLeft = 5     // 硬编码
rangeUpper = 60      // 硬编码
rangeLower = 5       // 硬编码
```

**问题五：背离和其他信号完全独立，没有联动**

v1 中两套信号各跑各的，没有"背离 + 交叉同时出现 = 更强信号"这样的复合逻辑。

### 1.2 v1 中保留的部分

| 模块 | 决策 | 原因 |
|------|------|------|
| RSI 计算 | 保留 | 标准 Wilder RSI，无需改动 |
| 背离检测 | **简化为实时检测** | 去掉 pivot 确认延迟，价格新低+RSI未新低=背离（零延迟） |
| RSI 超买超卖渐变色 | 保留 | 视觉辅助，不影响信号 |
| MOST 线 + BUY/SELL | **完全去掉** | 三层滞后导致信号无实用价值 |
| 慢均线 | **完全去掉** | 双均线交叉仍有滞后，改用 RSI 与快均线交叉 |
| VAR 均线类型 | **改为 EMA/VAR 可选** | 默认 EMA，保留 VAR 供用户对比测试 |

## 2. 核心改动

### 2.1 去掉 MOST 和慢均线，改用 RSI 与快均线交叉

**改动**：去掉 MOST 止损线和慢均线，仅保留一条快均线（默认 EMA5）。交叉信号改为 RSI 原始曲线上穿/下穿快均线。

```
改动前（v1）：
  RSI ──→ VAR均线(5) ──→ MOST止损线 ──→ 均线穿越MOST = 信号
                                         ↑ 三层滞后

最终版本（v2）：
  RSI（原始曲线）─┐
                   ├──→ RSI 穿越快均线 = 信号（最快响应）
  RSI ──→ 快均线(5) ┘
                     ↑ 原始信号 vs 一层平滑，交叉速度最快
```

#### 均线类型：EMA vs VAR（用户可选）

| 均线类型 | 特点 | 适合场景 |
|----------|------|----------|
| **EMA**（默认推荐） | 固定平滑系数，行为可预测 | 通用场景，信号稳定一致 |
| VAR | 自适应：趋势强时加速，震荡时减速 | 高波动标的（如 SOXL） |

### 2.2 三个独立触发事件

v2 有三个独立的信号触发事件，每个事件都可以单独产生信号标签：

#### 事件 1：RSI 下破/上破极端阈值（最早的左侧预警）

| | 买入 | 卖出 |
|--|------|------|
| 触发条件 | `ta.crossunder(rsi, extremeBuy)` — RSI 从上方跌破 30 | `ta.crossover(rsi, extremeSell)` — RSI 从下方突破 70 |
| 信号 | **B**（1 分） | **S**（1 分） |
| 特点 | 最先出现，左侧预警；仅在穿越瞬间触发一次，持续低于 30 不重复 | 同理 |

#### 事件 2：RSI 上穿/下穿快均线（右侧确认信号）

| | 买入 | 卖出 |
|--|------|------|
| 触发条件 | `ta.crossover(rsi, fastMA)` — RSI 上穿快均线 | `ta.crossunder(rsi, fastMA)` — RSI 下穿快均线 |
| 门槛 | 过去 `crossLookback`(5) 根内 RSI 最低值 < 40 | 过去 `crossLookback`(5) 根内 RSI 最高值 > 60 |
| 基础信号 | **B**（1 分） | **S**（1 分） |
| 升级规则（极端） | 过去 `divLookback`(10) 根内 RSI 最低值 < 30 → **B+**（2 分） | 过去 `divLookback`(10) 根内 RSI 最高值 > 70 → **S+**（2 分） |
| 升级规则（背离） | 过去 `divLookback`(10) 根内有**已确认**的背离 → **B++**（3 分） | 同理 → **S++**（3 分） |

**门槛** 用 `crossLookback`（默认 5）：检查 RSI 是否最近进入过低位区域。
**极端加分** 用 `divLookback`（默认 10）：RSI 极端低点往往在交叉前 6-10 根 K 线，用更宽的窗口才能捕获。

**注意**：事件 2 的背离加分只能识别已经被代码确认的历史背离（即之前触发过 `bullDivAlert` 的）。对于正在发生但尚未确认的当前背离，需要通过事件 3 的反向检查来处理（见下文）。

#### 事件 3：背离（实时检测 + 反向检查）

| | 买入 | 卖出 |
|--|------|------|
| 触发条件 | 价格创 `divWindow`(14) 根新低，RSI 未创新低，**且参考点 A 的 RSI ≤ `extremeBuy`(30)** | 价格创 `divWindow`(14) 根新高，RSI 未创新高，**且参考点 A 的 RSI ≥ `extremeSell`(70)** |
| 基础信号 | 直接 **B+**（2 分） | 直接 **S+**（2 分） |
| 门槛 | 参考点 RSI 必须处于超卖区（≤ 30） | 参考点 RSI 必须处于超买区（≥ 70） |
| **反向检查升级** | 过去 `crossLookback` 根内有过有效交叉事件 → **B++**（3 分） | 同理 → **S++**（3 分） |
| 去重 | 仅在首次检测到时触发，连续成立不重复 | 同理 |

**简化背离检测**（相比 v1 的 pivot 方案）：

v1 用 `ta.pivotlow()` 检测背离，需要等 `lookbackRight`(5) 根 K 线确认 pivot，有 5 根延迟。v2 直接比较"当前价格 vs 近 14 根内的最低价"、"当前 RSI vs 那个最低价时的 RSI"。如果价格更低但 RSI 更高，**且参考点的 RSI 处于超卖区（≤ 30）** → 背离。零延迟，当下即可判断。

**为什么需要参考点 RSI 约束**：背离的本质是"超卖后的动能恢复"——参考点 A 必须处于 RSI 极端区域（≤ 30），当前点 B 的价格更低但 RSI 回升，说明卖方力量衰竭。如果不加此约束，两个都不在超卖区的普通点（例如 RSI 45 vs RSI 48）也会被判定为背离，这种比较没有实际意义。实测中会导致 B+ 信号比 B 信号更频繁，出现信号强度分布倒挂的反常现象。

```
v1 (pivot):  价格触底 → 等5根确认 → 5根后才出信号（已错过入场）
v2 (实时):   价格创新低 + RSI未新低 → 当下出信号（可即时行动）
```

### 2.3 双向检查机制

由于背离和交叉是独立事件，发生时间不同，用双向检查实现联动升级：

**正向检查（事件 2 → 查近期背离）**：交叉事件触发时，检查 `divWindow`(14) 根内是否有过背离事件。

**反向检查（事件 3 → 查近期交叉）**：背离触发时，检查 `crossLookback`(5) 根内是否有过有效交叉事件。

两个方向都能产生 B++，不管哪个事件先发生都能正确联动。

**所有交易信号标签都画在当前 bar**，表示"此刻可以行动"。

### 2.4 信号强度与标签

| 分数 | 级别 | 买入标签 | 卖出标签 | 含义 |
|------|------|---------|---------|------|
| 3 分 | 强 | `B++` | `S++` | 三因子集齐（来源于事件 2 或事件 3 的升级） |
| 2 分 | 中 | `B+` | `S+` | 背离单独触发 / 交叉 + 极端位置 |
| 1 分 | 弱 | `B` | `S` | RSI 下破极端阈值 / 单纯交叉 |

**B++ 的两种产生路径**：

1. **事件 2 路径**：交叉触发 + 近期 RSI < 30 + 近期背离 → B++
2. **事件 3 路径**：背离触发 + 近期有效交叉 → B++

### 2.6 视觉设计

#### 信号标签

| 标签 | 颜色 | 位置 | 大小 |
|------|------|------|------|
| `B++` | 绿色 | 底部 | 大 |
| `B+` | 绿色 | 底部 | 中 |
| `B` | 绿色 | 底部 | 小 |
| `S++` | 红色 | 顶部 | 大 |
| `S+` | 红色 | 顶部 | 中 |
| `S` | 红色 | 顶部 | 小 |

#### 图表线条

| 线 | 颜色 | 线宽 | 说明 |
|----|------|------|------|
| RSI | 紫色 | 1 | 原始 RSI 值（沿用 v1） |
| 快均线 (5) | 橙黄色（加深） | 2（加粗） | RSI 的短周期均线（EMA 或 VAR） |
| 70/30 水平线 | 灰色 | — | 超买超卖参考线（沿用 v1） |
| 50 中线 | 灰色半透明 | — | 中线（沿用 v1） |

#### 保留的视觉元素

- RSI 70-100 区域的绿色渐变（超买）
- RSI 0-30 区域的红色渐变（超卖）

#### 去掉的视觉元素

- MOST 粗深红色线
- MOST 的 BUY/SELL 蓝色标签
- Bollinger Bands 相关绘图
- 蓝色慢均线（彻底删除）
- Bull/Bear 文字标签（回溯标记对实盘无意义，已被 B+/B++ 替代）
- 背离连线（依赖 pivot 机制，简化后去掉）

### 均线设置组

| 参数 | 类型 | 默认值 | 可选值 | 说明 |

## 4. v1 → v2 改动对照

| 项目 | v1 | v2 | 改动原因 |
|------|----|----|----------|
| 均线类型 | VAR 固定 | EMA / VAR 可选（默认 EMA） | 保留 VAR 供对比，默认 EMA 更稳定 |
| 均线数量 | 1 条（5日） | 1 条快均线（5日），周期可配置 | 慢均线删除，改用 RSI vs 快均线交叉 |
| MOST 线 | 有 | 去掉 | 三层滞后，对找买卖点没有帮助 |
| 交叉信号 | RSI均线穿越 MOST | RSI 穿越快均线 | 原始信号 vs 一层平滑，最快响应 |
| 触发事件 | 仅 MOST 交叉 | 三个独立事件 + 双向检查 | 左侧+右侧全覆盖 |
| 信号强度 | 无（只有 BUY/SELL） | 三级（B++ / B+ / B） | 通过双向检查联动，信号可升级 |
| 信号区域 | 全域 | 门槛制（交叉需 RSI 曾 < 40 / > 60） | 只抓底部和顶部 |
| 背离检测 | pivot 确认（5根延迟） | 实时检测（价格新低+RSI未新低，零延迟） | 当下可行动，不用等确认 |
| 背离信号 | 仅作背离标记（回溯） | 独立触发 B+，画在当前 bar | 所有信号都在当下 |
| 极端 RSI | 无信号 | RSI 下破 30 触发 B | 最早的左侧预警 |
| 背离参数 | 硬编码 5 个参数 | 1 个参数 `divWindow`(14) | 大幅简化 |
| 标签文字 | BUY / SELL | B / B+ / B++ / S / S+ / S++ | 简洁明了 |

## 5. 伪代码

```python
def MOST_on_RSI_v2(prices,
                   rsi_len=14,
                   ma_type="EMA",
                   fast_len=5,
                   buy_gate=40,
                   sell_gate=60,
                   extreme_buy=30,
                   extreme_sell=70,
                   cross_lookback=5,
                   div_window=14):

    # === 第一层：计算 RSI ===
    rsi = calc_rsi(prices, rsi_len)

    # === 第二层：快均线（仅一条） ===
    fast_ma = calc_ma(rsi, fast_len, ma_type)

    # === 背离检测（实时，零延迟） ===
    MIN_SEP = 2  # 参考点至少在 2 根前，避免相邻 bar 噪音
    # 找 divWindow 范围内的最低价所在 bar
    ref_bar = bar_of_lowest(low[MIN_SEP], div_window - MIN_SEP) + MIN_SEP
    # 价格创新低但 RSI 未创新低，且参考点 RSI 处于超卖区 = 看涨背离
    bull_div_raw = low < low[ref_bar] and rsi > rsi[ref_bar] and rsi[ref_bar] <= extreme_buy
    bull_div = bull_div_raw and not bull_div_raw[1]  # 去重

    # === 追踪近期事件（用于双向检查） ===
    bars_since_bull_div = track(bull_div)     # 距上次背离多少根
    bars_since_buy_cross = track(buy_event2)  # 距上次有效交叉多少根

    # === 第三层：信号生成 ===
    for each bar:

        # ── 事件 1：RSI 下破/上破极端阈值 ──
        if crossunder(rsi, extreme_buy):
            label("B", green, small)

        # ── 事件 2：RSI 与快均线交叉 + 门槛 + 升级 ──
        rsi_cross_up = crossover(rsi, fast_ma)
        gate_pass = lowest(rsi, cross_lookback) < buy_gate

        if rsi_cross_up and gate_pass:
            score = 1                                        # 交叉本身
            if lowest(rsi, div_window) < extreme_buy:
                score += 1                                   # 近期 RSI 极端
            if bars_since_bull_div <= div_window:             # 正向检查
                score += 1                                   # 近期有背离
            bars_since_buy_cross = 0                         # 记录交叉
            label(score_to_label(score))

        # ── 事件 3：背离 + 反向检查（当前 bar，可即时行动）──
        if bull_div:
            score = 2                                        # 背离直接 2 分
            if bars_since_buy_cross <= cross_lookback:        # 反向检查
                score += 1                                   # 近期有交叉
            label(score_to_label(score))

    def score_to_label(score):
        if score >= 3: return "B++", large
        if score >= 2: return "B+",  normal
        return "B", small
```

## 6. 场景示例

### 6.1 典型底部行情

```
时间轴:   T-10  ...  T-5   T-4   T-3   T-2   T-1    T    T+1   T+2
价格:      50        45    43    42    41    40    39    40    42
RSI:       38        28    25    22    25    28    32    36    40

事件 1 (bar T-4): RSI crossunder 30
  → B（左侧预警，用户可轻仓试探）

事件 3 (bar T): 价格 39 < 近14根最低价 40(T-10附近) → 价格新低
               RSI 32 > 那时RSI 38? 否，且参考点 RSI 38 > 30，不满足超卖约束。
               换个场景：假设之前价格低点在 T-10 价格=42, RSI=25
               现在 价格 39 < 42 → 新低，RSI 32 > 25 → RSI 未新低
               参考点 RSI 25 ≤ 30 → 超卖约束满足 → 背离成立!
  → B+（当前 bar，用户可标准仓位）

事件 2 (bar T+2): RSI 上穿快均线
  → gate: lowest(rsi,5) = 22 < 40 ✓
  → extreme: lowest(rsi,14) = 22 < 30 → +1
  → 正向查背离: bars_since_bull_div = 2 ≤ 14 → +1
  → score = 3 → B++（用户可重仓确认）

操作策略:
  看到 B  → 轻仓试探（20-30%）
  看到 B+ → 标准仓位（40-60%）
  看到 B++ → 重仓确认（70-100%）
```

### 6.2 无交叉的纯背离

```
价格持续创新低，RSI 未创新低，但 RSI 一直在快均线下方（没有交叉）
  → 背离触发 B+
  → 反向查交叉: 近期无有效交叉 → +0
  → score = 2 → B+
```

### 6.3 场景汇总表（买入侧）

| 场景 | 触发事件 | 门槛 | 极端 | 背离 | 得分 | 标签 |
|------|---------|------|------|------|------|------|
| RSI 跌破 30 | 事件 1 | — | — | — | 1 | `B` |
| RSI 上穿快均线，RSI 最低 35 | 事件 2 | 35<40 ✓ | 35>30 | 无 | 1 | `B` |

## 7. 信号使用建议

### 7.1 仓位对应

| 信号 | 建议仓位 | 逻辑 |
|------|---------|------|
| `B++` / `S++` | 重仓（70-100%） | 三因子集齐，最高置信度 |
| `B+` / `S+` | 标准仓位（40-60%） | 背离或双因子，较可靠 |
| `B` / `S` | 轻仓（20-30%） | 单因子预警，试探性操作 |

### 7.2 适用场景

| 场景 | 适合程度 | 说明 |
|------|---------|------|
| 深度回调抄底 | 最适合 | 事件 1 + 事件 2 + 事件 3 全面覆盖底部 |
| 顶部逃顶 | 最适合 | 对称设计，RSI > 60/70 区域 |
| 趋势跟踪 | 不适合 | 40-60 区间不产生交叉信号 |
| 震荡市 | 自动回避 | 震荡时 RSI 通常在 40-60，不会触发 |
